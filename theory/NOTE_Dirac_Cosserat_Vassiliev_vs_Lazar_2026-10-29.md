## 1. Что доказано у Васильева [источник]
Chervova & Vassiliev, arXiv:0902.1268 (J. Assoc. Arab Univ. Basic Appl. Sci. 7, 25 (2009)),
файл ref/Chervova_Vassiliev_2009_massless_Dirac_Cosserat_arXiv0902.1268.pdf.
- Среда в R³, точки НЕ смещаются, только поворачиваются (частный случай Коссера =
  телепараллелизм). Переменные: корепер ϑ^j (поле ортонормированных базисов) и плотность ρ.
- Потенциальная энергия P = −∫‖T^ax‖²ρ, где T^ax = −⅓ Σ ϑ^j ∧ dϑ^j — АКСИАЛЬНОЕ кручение
  (ур. 9, 13). Выбор продиктован конформной инвариантностью.
- Кинетическая K = ∫‖ϑ̇‖²ρ, ϑ̇ = ⅓Σϑ^j∧∂₀ϑ^j — дуал угловой скорости (ур. 15–16).
- Лагранжиан L = (‖ϑ̇‖²+‖T^ax‖²)ρ = ‖𝐓^ax‖²ρ (4-мерно, ур. 24). Уравнения поля сильно нелинейны.
- Перевод в спинор ξ (ур. 25–28): ρ = |ξ|²√|g|, (ϑ¹+iϑ²) и ϑ³ — билинейные формы ξ.
  Соответствие один-к-двум: знак спинора физического смысла не имеет.
- Квазистационарные решения ξ = e^{−iωt}ζ(x): лагранжиан факторизуется (Лемма 2)
  L = −(32ω/9)·L₊L₋/(L₊−L₋); Теорема 1: модель ⇔ пара безмассовых уравнений Дирака (Вейля).
- Плоские волны (ур. 54–56): корепер вращается с частотой 2ω при спинорной частоте ω,
  волна идёт со скоростью c. Два типа (по/против часовой) ↔ левое нейтрино / правое антинейтрино.
- Оговорки самих авторов: общий (не квазистационарный) случай и релятивистская версия — только
  гипотеза; вариация по времени «проверена, но не приведена».
Burnett & Vassiliev, arXiv:1007.3481 (Comm. Math. Phys.): массивный Дирак в 1+2 через
калуцу–клейновское лишнее измерение, свёрнутое в окружность; ref/Burnett_Vassiliev_2010_*.pdf
(скачан, детально не прочитан).

## 2. Сопоставление с Лазаром [посчитано]
Энергия дислокаций Лазара W_T = ¼H_ijk T_ijk, H из (13). Численно разложил T_ijk на
неприводимые части (тензорная, векторная, аксиальная; перекрёстные члены = 0 до 1e-16):
  W_тензорн ∝ (c₁ − c₂),  W_вектор ∝ (c₁ − c₂ + 2c₃),  W_аксиал ∝ (c₁ + 2c₂).
Это РОВНО три комбинации из условий устойчивости Лазара (ур. 14) — каждая есть модуль
одной неприводимой части. Лагранжиан Васильева «только аксиальное кручение» ⇔
  c₂ = c₁, c₃ = 0  (аксиальный модуль 3c₁, тензорный и векторный = 0, на границе устойчивости).
Кинетическая часть: при v=0 ток I_ij = β̇_ij; для чисто поворотного β (антисимметричного)
работает только d₃ — энергия угловой скорости, как у Васильева.
Итог: ЛИНЕАРИЗОВАННЫЙ Васильев = Лазар, ограниченный на антисимметричную (поворотную)
дисторсию, с c₂=c₁, c₃=0, γ=0, только d₃.
ОГОВОРКИ: (а) у Васильева повороты конечные (нелинейно), а факторизация, дающая Дирака,
доказана для нелинейной модели — сохранится ли она в линейном пределе, НЕ проверено;
(б) в его модели ρ — отдельная динамическая переменная (конформный вес), у Лазара её нет;
(в) γ (энергия поворота) должна быть 0 — иначе появляется член типа массы; совпадает ли он
с калуца–клейновской массой Burnett–Vassiliev — открыто.

## 3. Пара колец как солитон поля Дирака — НЕТ в этой постановке [аргумент]
- Квазистационарная редукция дала ЛИНЕЙНОЕ уравнение Вейля. У свободного безмассового Дирака
  нет локализованных стационарных решений с конечной энергией (дисперсия, всё уходит со
  скоростью c). Значит пара колец не может быть солитоном этого поля.
- Совместимая картина: пара колец — ДЕФЕКТ (источник, дисклинация с ν=½), а поле Дирака —
  волновое поле поворотов среды вокруг него. Это ровно постановка Кочетова–Осипова
  (Дирак на дисклинации), уже наш предшественник.
- Солитон возможен только в полной нелинейной модели (вне квазистационарного режима) —
  открыто, и сами авторы этого не делали.

## 4. Связь с часами де Бройля [посчитано по ур. 54]
У Васильева физический поворот корепера идёт с частотой 2ω, а спинорная фаза — с ω.
Это классическая реализация «половинного угла» (период 4π). Частота де Бройля = спинорная ω
⇒ физическое вращение 2ω_C, волна со скоростью c — ровно Барут–Занги (§22–23 NOTE о массе).
Подтверждает наш вывод: правильные часы де Бройля даёт светоподобная волна поворотов поля,
а не досветовая прецессия особой точки. Волновая сторона (Дирак/Васильев) и механическая
сторона (пара колец, v=c/2) — две разные компоненты частицы.

## 5. Что это даёт
- Строгая классическая (не квантовая) интерпретация спинора: спинор = параметризация
  корепера (поворотов эфира) + плотность. ħ при этом НЕ выводится.
- Ротационный сектор Лазара при c₂=c₁, c₃=0 — кандидат на «дираковский» сектор нашего эфира.
- g=2 тогда — свойство волнового поля (Паули), не пары колец (у пары g = 4d/ƛ_C).


## 6. Burnett–Vassiliev 2010: откуда масса [источник, ref/Burnett_Vassiliev_2010_*.pdf]
- 1+2 мир расширен до 1+3 лишней координатой x³, свёрнутой в окружность периода π/m (ур. 2.11–2.12).
- Лагранжиан = ‖T^ax‖²ρ в 1+3; распадается на ‖T^ax₍₁₊₂₎‖² + ‖D₃ϑ‖², где D₃ϑ — «угловая скорость»
  корепера вдоль x³ (ур. 2.9–2.10). ЭМ-поле — смешение ∂_α → ∂_α + m⁻¹A_α∂₃ (Калуца–Клейн, 2.13).
- Решения ξ = η e^{∓imx³} антипериодичны: за период π/m корепер делает ПОЛНЫЙ оборот (ур. 4.1).
- Теорема 1: модель ⇔ уравнения Дирака D_{rs}η = 0 (с массой m и полем A); факторизация (5.5).
- Плоские волны (7.9): корепер вращается с частотой 2m (энергия = половина угловой частоты, 7.11).
  Знаки r,s дают электрон/позитрон × спин вверх/вниз (табл. 1). Модель построена на SO(1,2), не Spin.
⇒ МАССА = скорость закрутки корепера вдоль компактного направления (2m рад на единицу длины).
Связь с γ Лазара: γ — энергия антисимметричной части β, не закрутка вдоль направления — НЕ то же.

### Наблюдение [гипотеза]: компактное x³ ↔ азимут нашего кольца
Наш твист — поворот Франка на π за обход 2πa: скорость закрутки π/(2πa) = 1/(2a).
Приравнивая к 2m (ħ=c=1): a = 1/(4m) = ƛ_C/4. Антипериодичность (4π) совпадает по смыслу.
Тогда «масса» в смысле BV возникла бы из твиста по кольцу. Но: у BV x³ — лишнее измерение,
у нас азимут — обычная координата; отождествление НЕ обосновано и даёт a = ƛ_C/4 ≠ ƛ_C (калибровка спина).

## 7. Факторизация в линейном (лазаровском) пределе — НЕ сохраняется [посчитано]
Малые повороты ϑ = R(φ), |φ|=1e-3, численно: *T^ax = 2·div φ (отношение 2.0003).
Линейный лагранжиан ≈ (4(∇·φ)² − |φ̇|²)ρ: восстанавливающая сила только у продольной части φ,
поперечная (rot φ) — без жёсткости (вырождено). Это не Дирак.
Причина: дираковские решения ВСЕГДА имеют корепер, равномерно вращающийся с частотой 2ω (конечный
поворот), а ϑ квадратичен по ξ. Линеаризация около покоящегося корепера выводит из дираковского режима.
ВЫВОД: дираковский сектор существенно НЕЛИНЕЕН (конечные повороты); линейная теория Лазара его не
содержит. Сопоставление §2 (c₂=c₁, c₃=0) верно только как совпадение формы энергии, не динамики.
→ Исправить формулировку в статье: «совпадает по форме энергии; дираковская динамика требует
конечных поворотов».

## 8. Дирак-поле вокруг пары колец [по памяти + аргумент]
- Дисклинация ν=½ (Ω=π) для поля Дирака = коническая особенность со спин-связностью; полный момент
  сдвигается на ½ (Кочетов–Осипов). Безмассовый Дирак на конусе масштабно-инвариантен ⇒ связанных
  состояний нет. Массивный — связанные состояния только при выборе самосопряжённого расширения
  (граничное условие в ядре) — т.е. задаётся ядром, не выводится [по памяти].
- Особые точки — магнитные монополи q_m: Дирак в поле монополя (Kazama–Yang–Goldhaber 1977):
  связанных состояний нет без дополнительного (аномального моментного) члена [по памяти].
- Значит связанное состояние «поле Дирака + пара колец» не возникает автоматически; нужно
  граничное условие в ядре дефекта — это и есть место, где модель ядра (ℓ Лазара) должна войти.
Статус: постановка, не расчёт.
