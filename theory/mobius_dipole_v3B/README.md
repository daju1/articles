# mobius_dipole_v3B — ВЕТКА B: диполь из пары мёбиус-колец

Параллельная ветка к dislocation_rings_v3_vector (ветка A, пара обычных колец).
Диполь из ПАРЫ мёбиус-колец: N-полюс = мёбиус (твист +θ/2), S = анти-мёбиус (-θ/2).

## Ключевое отличие от ветки A (glide)
| Свойство       | A: glide-пара      | B: мёбиус-пара      |
|----------------|--------------------|--------------------| 
| Звено          | обычное кольцо 2π  | мёбиус-кольцо 4π   |
| Период ПАРЫ    | 2π (бозон?)        | 4π (ФЕРМИОН)       |
| Магн. диполь   | q_m·d              | q_m·d              |
| Аннигиляция    | одноступенчатая    | двухступенчатая    |
| Кандидат       | бозон?             | ЭЛЕКТРОН (фермион) |

НЕОЖИДАННЫЙ вывод (24 окт 2026): если период ПАРЫ задаёт статистику, то ЭЛЕКТРОН
(фермион) — это МЁБИУС-диполь (B), а glide-пара обычных колец даёт 2π=бозон.
Переворачивает прежнее предположение. ТРЕБУЕТ дальнейшей проверки.

## Общее с веткой A
- Магнитный заряд q_m=Δb (разрыв в особой точке), [q_m]=длина.
- Магнитный момент = статический диполь q_m·d (не ток).
- Защита прецессией: ω=0 → J=0 → коллапс → аннигиляция.

## Сборка/запуск
    gcc -O3 -shared -fPIC mobius_dipole_v3B.c -o mobius_dipole_v3B.so -lm
    PYTHONIOENCODING=utf-8 python3 mobius_dipole_v3B_tests.py

## Честные оговорки
- Период пары 4π=фермион — СТРУКТУРНЫЙ аргумент (возврат знака Бюргерса за 4π),
  не полный вывод спина/статистики. Требует проверки спин-статистики.
- Двухступенчатая аннигиляция — качественный барьер ∫(db/dθ)², не динамика распада.
- g по-прежнему размерно не определён (q_m=длина, не заряд ЭД) — общая проблема.
- G не выводится (планковский барьер).
