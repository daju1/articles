## 5. Вторая гармоника и укручение продольной волны [посчитано]
Одномерная продольная волна, модель автора (Альманси e=(1−F⁻²)/2, F=1+ε, линейный Гук):
  c(ε)² = c₀²F⁻³  ⇒  c ≈ c₀(1 − βε),  β = 3/2  (численно 1.50005).
Знак: участки сжатия (ε<0) бегут быстрее, растяжения — медленнее.
Простая волна ε = ε₀ sin(k(X − c(ε)t)) (решение Римана), гармоники:
  A₂/A₁ = σ/2,  σ = β ε₀ k x  (численно: 7.5e-5, 2.25e-4, 4.5e-4 при σ = 1.5e-4…9e-4 — точно).
  Вторая гармоника растёт линейно с пройденным расстоянием.
Расстояние образования разрыва (ударного фронта): x_s = 1/(β ε₀ k) = 2/(3ε₀k).
  Пример: ε₀ = 1e-3 ⇒ x_s ≈ 667/k ≈ 106 длин волн.
Оговорки:
- β=3/2 — только геометрическая нелинейность при линейном законе Гука по Альманси. Полный коэффициент
  в теории твёрдых тел β = 3/2 + (A/2+3B+C)/(λ+2μ)-типа добавки с константами Мурнагана (точную
  форму по памяти не привожу) — материальная часть может изменить и знак.
- Выбор меры деформации (Альманси/Грин) меняет β: это свойство модели материала, не выбор координат.
- Поперечная волна: квадратичной самодействующей нелинейности нет (симметрия u→−u), есть только
  продольная сила ∝A² (возбуждение продольной 2-й гармоники) и кубическая поправка к c_T.
Для эфира: при деформациях ε ~ 1 (ядро дефекта при калибровке B, β~2) x_s ~ λ — нелинейность
решающая внутри частицы и пренебрежима в далёком поле.


## 6. Материальная нелинейность (Мурнаган) [по памяти — сверить с Ландау–Лифшицем т.VII §26, Зарембо–Красильников]
Упругая энергия до третьего порядка: W = λ/2 I₁² + μ I₂ + (l+2m)/3 I₁³ − 2m I₁I₂ + n I₃ (Мурнаган),
или в форме ЛЛ: A/3 ε_ik ε_il ε_kl + B ε_ik² ε_ll + C/3 ε_ll³.
Коэффициент нелинейности продольной волны
  β = 3/2 + (A+3B+C)/(λ + 2μ)   (сверено по ЛЛ, см. §11; эквивалентно записи через l, m — см. §17),
где 3/2 — геометрическая часть (совпадает с нашим расчётом §5).
Для твёрдых тел (l+2m)/(λ+2μ) обычно −3…−10 ⇒ материальная часть доминирует и меняет знак.
Для эфира l, m, n — три НОВЫХ параметра, теорией не фиксированы. Вывод: знак укручения в эфире
не определён без модели межатомного взаимодействия решётки эфира.
Поперечная волна: квадратичная самонелинейность запрещена симметрией при любых l,m,n.

## 7. Нелинейное ядро дефекта [посчитано аналитически]
Около особой точки β_эфф ~ |∇u| ~ q_m/(4πr). Нелинейность существенна (|∇u|≳1) при
  r < r_nl = q_m/(4π) = r_e/(4π) ≈ 0.08 r_e.
Сравнение с шириной ядра Лазара ℓ:
- калибровка A (μ_эфир, Δb=r_e): ℓ = √α·ƛ_C ≈ 145 r_e ≫ r_nl ⇒ ядро ЛИНЕЙНО, нелинейность
  несущественна (|∇u|(ℓ) ≈ 0.007).
- калибровка B (c₁=m_ec²/r_e): ℓ = r_e/(8π) ≈ 0.04 r_e < r_nl ⇒ ядро НЕЛИНЕЙНО (|∇u|(ℓ) ≈ 2).
Итог: вопрос «линейна ли частица» эквивалентен вопросу о калибровке ядра. Калибровка B, единственно
дающая m_e (§13 NOTE_mass), требует нелинейного ядра — тогда линейное решение Лазара для ядра
неприменимо, и r0=ℓ перестаёт быть теоремой. Нужна нелинейная задача (Альманси + Мурнаган
или Васильев–Коссера) для профиля ядра. Это открыто.

## 11. β сверен по ЛЛ т.VII §26, задача (стр.156) [источник + посчитано]
references/LandauLifshitz/…Т.7…2003.pdf, стр.156 (§26 «Ангармонические колебания», задача):
  E = μu_ik² + (K/2−μ/3)u_ll² + (A/3)u_ik u_il u_kl + B u_ik² u_ll + (C/3)u_ll³,
и развёрнутая по ∂u_i/∂x_k форма с (26.1) u_ik = ½(∂_k u_i+∂_i u_k+∂_i u_l ∂_k u_l).
Для одномерной продольной волны s = ∂u/∂x собираем [посчитано вручную по формуле ЛЛ]:
  E = (M/2)s² + (N/3)s³,  M = K+4μ/3 = λ+2μ,  N = 3M/2 + A + 3B + C.
  ⇒ c ≈ c₀(1 + βs),  β = N/M = 3/2 + (A + 3B + C)/(λ + 2μ).
Формула по памяти ПОДТВЕРЖДЕНА. ПОПРАВКА 31.10: запись через (l+2m) НЕ неверна — это та же формула
в обозначениях Мурнагана: A+3B+C = l+2m (см. §17).
Знак 3/2: у ЛЛ мера деформации Грина (Лагранж), у Альманси в Эйлере (§5) получилось −3/2 —
модуль совпадает, знак зависит от меры/координат. Физический знак укручения определяется
полным β с константами A,B,C; ЛЛ также подчёркивают (стр.155): σ_ik теперь НЕ симметричен и
не является потоком импульса; момент импульса (x_i+u_i)u̇_k − … — прямая связь с Коссера.

## 12. Обоснование модели насыщения — НЕ получается из Альманси [посчитано]
Альманси e = (1−(1+g)⁻²)/2: при растяжении g→∞ e → 1/2 — насыщение ЕСТЬ, w ≤ M/8.
Но: (а) при сжатии g→−1 e → −∞ — насыщения нет, ветвь сингулярна;
(б) насыщается энергия ПЕРВОГО градиента (μβ²), а расходимость ядра — во ВТОРОМ (c₁T², T ~ ∇β):
для β ~ q/(4πr) интеграл ∫r²β²dr сходится в нуле и расходится на бесконечности (линейно — точечный
трансляционный дефект требует струны), а ∫r²T²dr расходится в нуле как 1/r.
Мой первый численный прогон взял g ~ q/r² (неверная размерность) — отозван.
Вывод: модель насыщения поля T (Борн–Инфельд) из геометрической нелинейности Альманси НЕ следует.
Нужна нелинейность самого градиентного (дислокационного) сектора — теорией Лазара не задана.

## 13. Васильев аналитически [аргумент]
Квазистационарность: ξ = e^{−iωt}ζ(x). Возмущение той же частоты δξ = e^{−iωt}δζ остаётся в классе
⇒ по Теореме 1 удовлетворяет Дираку (линейно). Возмущение другой частоты ω′: сумма двух частот —
не квазистационарна; лагранжиан (41) L = −(32ω/9)·L₊L₋/(L₊−L₋) явно содержит ω и нелинеен по ζ.
⇒ ПРИНЦИП СУПЕРПОЗИЦИИ НАРУШЕН МЕЖДУ ЧАСТОТАМИ: модель ≡ Дирак только помодово (на одной частоте);
моды разных частот взаимодействуют. Это не баг, а предсказание: классический «дираковский» эфир
нелинеен по частотам (отличие от КМ). Авторы заявляют, что член с ∂_t δζ «зануляется», но расчёт
не приведён; при δζ(t) он описывает именно межчастотное смешение. Проверка — открыта.


## 14. Межчастотное смешение у Васильева [посчитано]
Спинор ξ → корепер R(ξ) (вращение ξ/|ξ| ∈ SU(2) → SO(3)), угловая скорость Ω из Ṙ Rᵀ.
Кинетическая энергия Васильева ‖ϑ̇‖² (ур.15–16) — это НЕ полный |Ω|², а только поперечная часть
(ϑ^j∧∂₀ϑ^j проектирует вращение на плоскость, ортогональную ϑ³ — вращение ВОКРУГ ϑ³ не входит).
Численно (период-среднее):
- одна частота ξ=ζe^{−iωt}: |Ω|²=4ω² (=(2ω)², корепер крутится с 2ω — как в ур.54), поперечная часть = 0
  (вращение строго вокруг ϑ³) ⇒ кинетика Васильева от фазы не зависит, ω входит только через (32).
- две частоты, непараллельные спиноры ζ₁, ζ₂ (ω₁=1, ω₂=1.7): поперечная часть ⟨…⟩ = 0.52 ≠ 0
  ⇒ появляется кинетическая энергия, которой нет ни у одной моды по отдельности — межчастотный член.
- две частоты, параллельные спиноры: поперечная часть = 0 (ось вращения не меняется).
ВЫВОД: суперпозиция мод разных частот с разной спиновой ориентацией НЕ решение дираковского типа —
модель Васильева нелинейно смешивает частоты (биения ω₂−ω₁ в ϑ̇). Линейная суперпозиция КМ
воспроизводится только для параллельных спиноров (одна ось вращения) или одной частоты.
Это проверяемое расхождение классического «дираковского эфира» с КМ. Оговорка: проверена только
кинетическая часть; аксиальное кручение (потенциальная часть) для двух частот не посчитано.

## 15. Нелинейность дислокационного сектора у Лазара — НЕТ [источник]

## 16. Полный лагранжиан Васильева для двух волн [посчитано, 30 окт]
Полевое уравнение по ρ: L = ‖ϑ̇‖² − ‖T^ax‖² = 0 на решениях (сигнатура (−−−)).
Проверка на плоских волнах Вейля ξ = ζ e^{−iω(t∓n·x)}:
- одна волна: ‖ϑ̇‖² = ‖T^ax‖² = 1.778 (=16/9 ω²), L = 0 до 1e-10 — решение ✓ (совпадает с ур.32 статьи).
- суперпозиция, та же ось n, разные ω (1 и 1.7): L = 0 — суперпозиция РАБОТАЕТ.
- суперпозиция, разные оси n (z и x), разные ω: L/ρ = 0.05…0.76 ≠ 0 — НЕ решение.
- разные оси (z и (0,.6,.8)), одна ω: L = 0 — работает.
⇒ ПОЛНЫЙ лагранжиан подтверждает §14: суперпозиция ломается ровно при одновременно разных
направлениях и разных частотах. Это нарушение принципа суперпозиции КМ в классическом
дираковском эфире — конкретное, численно установленное. (Теорема 1 у авторов — помодово.)
Оговорка: проверено условие L=0 (уравнение по ρ), не полная система по кореперу.

## 17. Katanaev–Volovich [источник: arXiv:gr-qc/9801081]
Геометрическая теория дефектов = 3D гравитация с кручением (евклидова, Риман–Картан):
триада e_μ^i и SO(3)-связность ω_μ^{ij} — независимые переменные; кручение = плотность
векторов Бюргерса, кривизна = плотность векторов Франка; у чистых дислокаций R=0.
Действие (их работа [10] = Ann. Phys. 216, 1 (1992)) — гильберт-эйнштейновского типа
(линейное по кривизне) + квадратичное по кручению; СТРУКТУРНО это не насыщение.
Насыщения поля кручения нет; нелинейность — геометрическая (конечные повороты, метрика).
Связь с нами: (а) клиновая дислокация = коническая особенность = космическая струна, угол
рассеяния χ = πθ/(1+θ); (б) фононы движутся по экстремалям метрики; (в) диспирация разобрана [25].
Для насыщения T этот путь не даёт; для задачи «поле Дирака/фононы около дисклинации ν=½» —
прямой готовый аппарат.

## 15. Почему Dx/Dt = 0 — по формуле Новацкого [аргумент + проверено численно]
Определения (Новацкий §2.8): x — координаты Лагранжа (начальное положение частицы, её «имя»),
ξ — координаты Эйлера (текущая точка пространства), u = ξ − x, x(ξ,t) = ξ − u(ξ,t).
Формула (5) §2.8 (ячейка 5 Vyvod.ipynb): DG/Dt = ∂G/∂t|_ξ + v_j ∂G/∂ξ_j = ∂G/∂t|_(x=const).
  G = x:  Dx/Dt = ∂x/∂t|_(x=const) = 0;    G = ξ:  Dξ/Dt = v.
Две разные производные:
  ∂x/∂t|_ξ ≠ 0 — в неподвижной точке пространства проходят частицы с разными метками (довод автора верен);
  Dx/Dt = 0 — вдоль одной частицы метка не меняется.
Они связаны: 0 = ∂x/∂t|_ξ + v_j ∂x/∂ξ_j — местная производная гасится конвективной.
∂x/∂ξ — обратный градиент деформации: ∂x_i/∂ξ_j = δ_ij − ∂u_i/∂ξ_j = (I − ∇u), det = ρ/ρ₀.
Отсюда v = −(∂x/∂ξ)⁻¹ ∂x/∂t|_ξ = (I − ∇u)⁻¹ ∂u/∂t; в 1D v = u_t/(1 − u_ξ).
То же из Dξ/Dt = v при ξ = x + u: v = u_t + v·∇u.
В выводе (стр. 2 Equation_of_motion_in_Euler_coordinates.pdf) левая часть Dx/Dt приравнена к v —
на месте (I − ∇u) остаётся ∇u, единица потеряна ⇒ v = −u_t/u_x = −ω/k.
Независимая проверка: при A → 0 частицы должны стоять; старая формула даёт −ω/k при любой A.
Численно (траектория ξ − u(ξ,t) = X, A=0.05, k=2, ω=3): истинная скорость −0.134870 / −0.006198 / 0.157378
при t = 0.1 / 0.7 / 1.3; (1−u_x)⁻¹u_t — то же до 6 знаков; −u_t/u_x = −1.5 всегда.

## 16. Плоские волны с исправленной скоростью и решение во втором порядке [посчитано]
Продольная волна u = A cos θ, θ = kξ + ωt + δ, ω = c_L k, ρ = ρ₀(1 − u_ξ), σ = (λ+2μ)(u_ξ − u_ξ²/2):

  невязка уравнения движения R ≈ (3/2)(λ+2μ)k³A² sin 2θ — член O(A) отсутствует (точно Ламе),

## 17. Обобщение на Мурнагана; эквивалентность записей (l,m) и (A,B,C) [посчитано + источник]
Энергия Мурнагана (Hughes–Kelly 1953): W = (λ+2μ)/2·I₁² − 2μI₂ + (l+2m)/3·I₁³ − 2m I₁I₂ + n I₃, мера Грина.
1D продольная: E = U_X + U_X²/2, I₂ = I₃ = 0 ⇒ P = (1+U_X)∂W/∂E =
  (λ+2μ)U_X + [3/2(λ+2μ) + (l+2m)]U_X² + …  (разложение проверено численно).
Связь с ЛЛ: A = n, B = m − n/2, C = l − m + n/2 ⇒ A + 3B + C = l + 2m — формулы §6/§11 и эта совпадают.
Соглашения о знаке (все три — одна и та же физика):
  β_ЛЛ = 3/2 + (l+2m)/(λ+2μ)   (c ≈ c₀(1 + β_ЛЛ·U_X), мера Грина);
  β_наш = −β_ЛЛ                (в U_tt = c²(1 − 2β U_X)U_XX);
  β_лит = −2β_ЛЛ = −3 − (2l+4m)/(λ+2μ) = −(3 + C₁₁₁/C₁₁),  C₁₁₁ = 2l + 4m  (нелинейная акустика).
Частные случаи: Гук по Грину (l+2m = 0) — β_лит = −3; Гук по Альманси (эквивалент (l+2m)/(λ+2μ) = −3) — β_лит = +3.
Поправка к ответу 30.10: там знак β_лит был взят обратным (β_ac = −2β вместо +2β); правильно β_лит(Альманси) = +3.
