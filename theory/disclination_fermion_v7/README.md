# disclination_fermion_v7 — векторный твист, магн. момент из Осипова, 6 каналов

Развитие v6: вектор Бюргерса b(θ) — полный 3D-ВЕКТОР. Плоскость твиста + winding
n (спин=n/2) + киральность (±). Магнитный момент и магнитная сила ОБОСНОВАНЫ
теорией дисклинаций Кадича-Еделена/Осипова (а не введены руками).

## Теоретическая основа магнитного момента (НОВОЕ, обосновано)
Магнитный момент НЕ выводится из T(3)-теории Лазара 2010 (там B<->T^a=Бюргерс,
и трансляционный ток прецессирующего кольца даёт mu=0 — три независимых расчёта).
mu живёт в ДИСКЛИНАЦИОННОЙ (SO(3), Франк) части:
- Kadic-Edelen 1983: группа SO(3)⋉T(3); дисклинации из SO(3)-сектора.
- Osipov/Kochetov (arXiv:1001.4450, math-ph/9903018): дисклинация = поле SO(3) с
  топологическим потоком ∮W=2πν (ν=индекс Франка). Спин-связность в спинорном
  представлении Ω_φ=iω·σ3 (σ3 — Паули). J_z=j+1/2 (полуцелый). Решение vortex-like
  W_b=-ν·ε_bc·∂_c·log r.
=> mu = (1/2π)∮ω dφ = ν = n/2 (ВЫВЕДЕНО из потока спин-связности, не постулат).
=> плоскость T-R (ось Франка σ3||ẑ) — единственная с ненулевым потоком; обоснование
   численного результата "mu≠0 только в T-R".

## Магнитная сила (исправлено в v7)
Было: Франк×vortex → усреднялась в НОЛЬ (баг). Стало: взаимодействие ПОТОКОВ
дисклинаций (Ааронов-Бом) F∝Φ1Φ2/R³=π²n1n2/R³. Численно |F|·R³=const (диполь-
дипольный закон), сила не зануляется.

## СТАТУС и честные оговорки
- mu=ν=n/2 ВЫВЕДЕНО из потока спин-связности Осипова (не постулат). Пропорц. спину.
- Абсолютное g=2 НЕ доказано: в этих единицах mu/S=1; нужна нормировка заряда/массы.
- Отождествление "наш Франк = SO(3)-поле Осипова, winding=индекс Франка" —
  последовательно и подтверждено формулами, но это НАШЕ сопоставление 3D-кольца
  с 2D-формализмом Осипова, не дословно его результат.
- Магнитная сила 1/R³ — на основе потока Φ=2πν; знак/ориентация упрощены (вдоль
  линии центров), полная тензорная структура диполь-диполь не реализована.
- Слабое/сильное — концепт. G не выводится (планковский барьер).
