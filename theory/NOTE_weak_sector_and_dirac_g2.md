# Слабый сектор (хемитропность) и g=2 из уравнения Дирака

Дата: 24 окт 2026. Проект «Единая геометродинамическая модель».
Основано на прочитанных: Lazar 2009 (arXiv:0903.0990, Higgs/хемитропность),
Kochetov-Osipov 2010 (arXiv:1001.4450, спинор на дисклинации).

## A. Слабое взаимодействие из хемитропных констант B1,B2,B3 (Лазар)

Хемитропный материал = изотропный по SO(3), но НЕцентросимметричный (киральный).
Определяющие соотношения (Lazar 2009, ур.64-65) содержат доп. члены с символом
Леви-Чивиты:

    σ_ij = λδ_ij β_kk + (μ+γ)β_ij + (μ−γ)β_ji
           + B1 δ_ij ε_klm T_klm + B2 ε_jlm T_ilm + B3 ε_ilm T_jlm
    H_ijk = 2B1 ε_ijk β_ll + 2B2 ε_jkl β_il + 2B3 ε_jkl β_li + (c1,c2,c3 члены)

B1,B2,B3 связаны с нецентросимметрией. Частный случай B1=B3=0 → член
Черна-Саймонса (B2), топологический и киральный.

ЧИСЛЕННО ПОДТВЕРЖДЕНО: B-члены (с ε) меняют знак под инверсией координат P,
тогда как обычные упругие члены (λ,μ,γ) — нет. Это псевдотензорная структура =
НАРУШЕНИЕ ЧЁТНОСТИ на уровне определяющих соотношений.

ВЫВОД: хемитропность Лазара даёт легитимную основу для СЛАБОГО сектора
(нарушение P встроено в B-константы), а не ручную cos-вставку как в v7.
Связь со слабым зарядом = знак киральности твиста (±θ/2) ↔ знак B-членов.

ОТКРЫТО: связать величину B с константой Ферми; показать, что W/Z = массивные
киральные моды (Higgs даёт им массу); SU(2)_L структуру не выведена.

## B. g=2 из уравнения Дирака (динамически, не геометрия периода 4π)

Переход: классический твист-контур v7 → квантовый спинор ψ в поле дисклинации.
Уравнение Дирака (Кочетов-Осипов): iγ^α e_α^μ(∂_μ+Ω_μ)ψ=Eψ.

Два эквивалентных вывода g=2:
1. Тождество Лихнеровича: D² = −∇² + R/4 + (1/2)σ^μν F_μν. Член σ^μν F_μν =
   аномальный магнитный момент с g=2 для ЛЮБОГО калибровочного поля F.
2. Нерелятивистская редукция (Паули): (σ·π)² = π² − q σ·B (π=p−qA).
   H = (σ·π)²/2m = π²/2m − (q/2m)σ·B. С S=σ/2: μ_spin=(q/m)S = g(q/2m)S → g=2.

ЧИСЛЕННО ПОДТВЕРЖДЕНО: алгебра Клиффорда {γ^i,γ^j}=2δ^ij и тождество Паули
(σ·a)(σ·b)=a·b+iσ·(a×b). Множитель 2 = структура спинорного уравнения, НЕ
геометрический аргумент про период 4π.

ЦЕНА (честно): g=2 требует ОПИСЫВАТЬ электрон как спинор Дирака в поле
дисклинации (минимальная связь ∂→∂+Ω), как у Осипова. В классической модели
кольца (v7) g=2 не выводится — там μ/S=1 структурно (геометрия). Это смена
уровня описания: классическая струна → квантовый спинор.

СОГЛАСОВАНИЕ: winding=1 (период 4π) классической картины = двузначность спинора
SU(2); поток ∮ω=2πν = фаза Ааронова-Бома спинора. Топологически обе картины
согласованы; g=2 живёт в спинорной.

## Общий статус проекта (четыре взаимодействия)
- Кулон, гравитация (закон 1/R²), обмен, магнитное (1/R³ из потока Осипова) —
  работают численно в v7.
- Слабое — основа найдена (хемитропные B-константы, нарушение P).
- Сильное — концепт (частичный b/3, лента дефекта упаковки); не реализовано.
- g=2 — достижимо на спинорном уровне (Дирак), не на классическом (v7).
- G — НЕ выводится: Higgs даёт комптоновский масштаб кора, планковский (слабость
  гравитации, ~42 порядка) остаётся независимым. Фундаментальный барьер.
