## A. Тезис «механическая и волновая стороны частицы» — развёрнуто

### A1. Что каждая сторона умеет и чего не умеет
| свойство | механическая (пара колец, особые точки) | волновая (поле поворотов эфира, Дирак–Васильев) |
|---|---|---|
| носитель | дефект: скачок Бюргерса ±Δb, твист Франка Ω=π | волна поворотов корепера ϑ |
| скорость | особая точка v=c/2 (досветово) | волна идёт со скоростью c |
| спин ½ | из периода 4π (топология твиста) | из спинорной параметризации (корепер = «квадрат» спинора) |
| заряд/кулон | да (q_m=Δb, поле T) | нет (поле нейтрально) |
| масса | энергия поля особых точек ~c₁q_m²/ℓ (тип 1/r) | закрутка корепера (БВ: 2m рад/длина) |
| часы де Бройля | НЕТ: Ω=ω_C/2 ⇒ λ=2h/p (теорема E/(Jω)=c²/v²) | ДА: спинорная фаза ω, вращение 2ω, λ=h/p |
| g | 4d/ƛ_C — геометрия пары, не фиксировано | 2 (тождество Паули) |
| излучение | излучает (τ~1e-18 с) | свободная волна — не «излучает», она и есть излучение |
| локализация | есть (дефект) | нет (Вейль/Дирак без связанных состояний) |

Каждая сторона закрывает дыры другой: механическая даёт локализацию, заряд и досветовость;
волновая — часы де Бройля и g=2. Ни одна по отдельности не является электроном.

### A2. Почему их нельзя слить в одно движение [посчитано]
Для любого точечного носителя инерции на окружности E/(Jω) = c²/v² ≥ 1. Часы де Бройля
требуют E/(Jω) = 1 ⇒ v = c. Значит «правильные часы» несовместимы с досветовым механическим
носителем — это теорема, а не недоработка. Поэтому часы должны принадлежать полю.

### A3. Как они могут сосуществовать [гипотеза, рабочая картина]
Дефект (пара колец) — источник/граничное условие; волновое поле поворотов эфира — его
«одежда», стоячая волна вокруг ядра. Аналогия: вихрь в сверхтекучей жидкости (ядро) +
фазовое поле вокруг него. Полный момент J = J_дефект + J_поле.
- Если поле несёт часть J за световым цилиндром r>c/ω (вращающийся узор), для этой части
  E/(Jω) может быть <1, и баланс E=Jω для СУММЫ возможен при v<c у дефекта. Это единственный
  известный мне путь совместить досветовой спин и часы де Бройля. НЕ посчитано.
- g тогда — средневзвешенное: g = (μ_деф + μ_поле)/(e/2mc)(S_деф+S_поле). Чтобы g=2, нужна
  доля поля. Это даёт КОНКРЕТНУЮ задачу вместо подгонки d=a/2.
- Связанное состояние «поле + дефект» задаётся граничным условием в ядре (ширина Лазара ℓ) —
  в теории Дирака на дисклинации (Кочетов–Осипов) это выбор самосопряжённого расширения.

### A4. Что из этого проверяемо
1. Момент импульса поля вращающегося твиста: доля J за световым цилиндром.
2. Стоячая волна Дирака–Васильева вокруг конической особенности ν=½ с граничным условием на r=ℓ:
   спектр ω, есть ли состояние с ω=mc²/ħ при m из энергии ядра.
3. g композиции.

## B. «Упругая Вселенная» Чурляева — исследование автора (2018) [источник: science/uprugaya_vselennaya/]
Файлы: «Размышления…Чурляева» (+ «продолжение»), volnovoe_uravnenie (Maple .mw, читал .txt-экспорт;
прочитан частично — комментарии и ключевые результаты).

### B1. Постановка автора
- Чурляев: вакуум — упругая среда, частица («лок») — сферическая стоячая волна
  W = j_l(kr)Y_lm cos(ωt+δ)/√r (Корн, 10.4-48), колебания «параллельно оси Z».
- Автор: для плоских волн уравнение Ламе распадается на продольную (∇·u≠0, c_L) и поперечную
  (∇·u=0, c_T). Для СФЕРИЧЕСКОЙ волны с фиксированным направлением колебаний этого распада нет:
  ∇·u≠0 и ∇×u≠0 одновременно — волна «сама на себя закручена», смешивает обе поляризации.
- Результат автора для лока (0,0): c₀₀ = √((λ+4μ)/(3ρ)).
- Дальше: нормировка 1/r и частота ω₀/r («закон наслоения») — дискретный спектр ω₀ из
  RootOf(tan Z·Z² − 8 tan Z + 5Z); для (1,0),(1,1) — решения без связи скорости и констант.
- Тороидальные и сфероидальные моды (Lamb 1882) построены через rot(r̂·W) и rot rot(r̂·W).
- Вывод автора: нужна нелинейность (тензор Альманси, эйлерово описание), затем Коссера.

### B2. Проверка c₀₀ [посчитано]
u = ẑ·j₀(kr). Численно, усредняя остаток Ламе по сфере: ρω²/k² = 1.3652 при (λ+4μ)/3 = 1.3667.
Итак
  c₀₀² = (λ+4μ)/(3ρ) = (c_L² + 2c_T²)/3
— ровно среднее: одна продольная + две поперечные проекции. Результат автора ВЕРЕН,
и у него ясный смысл: изотропное усреднение по направлениям волнового вектора относительно
фиксированного направления колебаний.
Оговорка: это не точная собственная мода — поточечно отношение меняется (1.3…2.2),
то есть ẑ·j₀(kr) не решает Ламе точно, а лишь «в среднем». Точные моды шара — Lamb:
тороидальная (чистый сдвиг, ∇·u=0) идёт строго с c_T; сфероидальная — связанная, её частоты
задаются граничными условиями, а не одной скоростью.

### B3. Важная деталь: λ = −2μ [посчитано]
Автор кладёт λ=−2μ, чтобы Ламе совпало по форме с волновым уравнением для A (rot rot A).
Тогда c_L² = (λ+2μ)/ρ = 0 — продольной волны НЕТ, а модуль всестороннего сжатия
K = λ+⅔μ = −⁴⁄₃μ < 0 — нарушение устойчивости (3λ+2μ ≥ 0, Лазар ур.14).
c₀₀ = c√(2/3) и множитель 2/3 к ускорению (1.515g → 1.01g) получены именно при λ=−2μ.
Это противоположно более позднему постулату автора c_L ≫ c (ν→½). Нужно выбрать:
(а) λ=−2μ (Максвелл по форме, c_L=0, неустойчиво) или (б) c_L≫c (устойчиво, c₀₀² ≈ c_L²/3 ≫ c²).

### B4. Связь с текущей теорией
- «Сферическая волна, закрученная сама на себя» — то же, что смешение продольного и поперечного
  каналов вокруг дефекта. В наших терминах: поле вокруг пары колец не чисто поперечное (T, I),
  у него есть дилатационная компонента — и её скорость c_L.
- c₀₀² = (c_L²+2c_T²)/3 даёт эффективную скорость «волновой стороны», если её не разложить на
  чистые моды. При c_L≫c это сверхсветовая фазовая скорость — согласуется с фазовой скоростью
  де Бройля c²/v > c? Совпадение формы, не вывод. Проверять.
- Переход автора к Коссера + Альманси (2018) — ровно путь Васильева (2009, повороты + нелинейность),
  который даёт уравнение Дирака. Автор пришёл к этому направлению независимо.
