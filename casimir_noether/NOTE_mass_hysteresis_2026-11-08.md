# Гистерезис массы: цикл «резкий разгон — плавное торможение», импульс и термостат
### 8 ноября 2026 (перенесено из чата про второе начало / МД-столб)

Деление: ПОСЧИТАНО / ТЕЗИС / ОТКРЫТО.

## 1. Модель (ПОСЧИТАНО)
Заряд с голой массой m_b связан пружиной k с «полевой» инерцией m_f = m0 − m_b
(m0 — масса покоя = инертная при малом ускорении; 0 < m_b < m0).
Отставание поля τ = √(μ/k), μ = m_b·m_f/m0. Излучение — трение γ в связи.
Внешняя сила действует только на заряд.

Цикл: толчок за t ≪ τ → свободный полёт (поле догоняет) → торможение за t ≫ τ.
Параметры: m_b=0.2, m_f=0.8, k=50.

| | затрачено | возвращено | отношение |
|---|---|---|---|
| γ = 0 | 0.0988 | 0.0967 | 0.98 (остаток в колебаниях связи) |
| γ = 2 | 0.0957 | 0.0200 | 0.21 ≈ m_b/m0 = 0.20 |

Аналитика: W_in = p²/2m_b, W_out = p²/2m0,
W_in − W_out = (p²/2)(1/m_b − 1/m0) ≥ 0 при m_b > 0.
Малая инерция при резком толчке делает толчок ДОРОЖЕ на единицу импульса.
Платит источник силы; разница уходит в «неупругий удар» заряда с собственным
полем, затем — в излучение. Знак петли диссипативный (как предсказывает
механизм Салля в формулировке пользователя: энергия уходит из частицы в волны).

## 2. Откуда «выигрыш > 100%» в черновиках (ТЕЗИС, черновики не видел)
Если масса задана мгновенной функцией m(a) без поля как отдельного тела:
W_out/W_in = m0/m_fast > 1, НО ∮F dt = (m_fast − m0)·v ≠ 0 за замкнутый цикл.
То есть одновременно нарушается сохранение импульса (безопорная тяга) —
та же ситуация, что у F12 при N≥3 (Лиувилль OK, Гельмгольц нарушен).
Выигрыш исчезает, если учесть импульс поля (m0 − m_fast)·v и его энергию.

Критерий проверки любой модели: за полный цикл посчитать
ΔP_{частица+поле} = ∮F dt и ΔE = W_in − W_out.

## 3. Связь с §105 и Нётер (ТЕЗИС)
Как в NOTE_para105_two_guarantors_2026-10-24.md: импульс не исчезает, а уходит
в поле/эфир (∮⟨T⟩·da). Двигатель с опорой на эфир допустим как идея, но тогда
эфир — тело с импульсом и энергией; без явного его описания модель незамкнута.
Выигрыш энергии требует, чтобы эфир отдавал энергию: при эфире в равновесии
при T это снова вопрос второго начала; вне равновесия — конечный запас.

## 4. Отрицательная голая масса (ПОСЧИТАНО)
m_b = −0.2, m_f = 1.2: формально W_in − W_out < 0, но μ < 0 → внутренняя мода
самоускоряется (инкремент √(k/|μ|) ≈ 14): энергия голого заряда → −∞, поля и
связи → +∞, сумма сохраняется. Аналог убегающих решений ALD. Цикл не замыкается.
Пользователь этот случай для реальных систем не рассматривает.

## 5. Гамильтонов ли термостат с гистерезисом массы (ТЕЗИС + стандартная теория)
- Расширенная система «заряд + поле» (если из действия) гамильтонова, Лиувилль OK.
- Для одного атома — обобщённое уравнение Ланжевена с памятью K(t);
  при поле в равновесии ⟨ξξ⟩ = kT·K (ФДТ) — схема Калдейры–Леггетта.
- Для МД-столба: изотерма, барометрическая плотность и нулевой поток при равных
  стенках НЕ меняются; меняются κ, время релаксации, неупругость удара.
- Если излучение уходит наружу при T≈0: охлаждение, Q_lo + Q_hi > 0 (обе стенки
  отдают тепло) — отличимо от закона q = −κ(dT/dz + Mg/C_v), где Q_lo + Q_hi = 0.
- Реализация в МД: модель Друде/оболочечная (вспомогательная частица m_f на
  пружине к каждому атому, взаимодействует только со своим атомом).
  В ghemical пока нет ни гистерезиса масс, ни кросс-масс.
