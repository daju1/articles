# positronium_v5 — электрон как диполь двух прецессирующих монополей Дирака

Модель С НУЛЯ (не наследует кольца v1-v4). Онтология: фундаментальны только
магнитные монополи ±q_m; электрон = прецессирующая пара; электрический заряд
НЕ фундаментален — кулон выводится из прецессии диполей. Поле — дислокационная
T(3)-теория Лазара, запаздывающее с излучением (мгновенна только поправка Ферми).

## Пять задач (positronium_v5_tests.py)
1. Устойчивость фермиона от самоаннигиляции (прецессионный барьер).
2. Кулон двух фермионов (эффективный 1/R со знаком от Δφ).
3. Гравитация (изотропный член, всегда притяжение).
4. Обмен (cos2Δφ).
5. Боровская орбита монополей (резонанс nλ=2πa, безызлучательность).

## Сборка и запуск
    gcc -O3 -shared -fPIC positronium_v5.c -o positronium_v5.so -lm
    python3 positronium_v5_tests.py

## Режим эффективного заряда (EffChargeMode)
Второй вопрос (откуда e) оставлен ПАРАМЕТРОМ: ECHARGE_DARWIN (из v/c-члена)
или ECHARGE_FERMI (из поправки Ферми) — сравнить численно.
