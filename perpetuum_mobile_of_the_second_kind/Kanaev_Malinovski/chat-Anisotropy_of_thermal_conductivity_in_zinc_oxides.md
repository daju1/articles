### 🔍 1. Фундаментальный нюанс: линейный vs нелинейный режим
В линейной термодинамике теплопроводность подчиняется **соотношениям взаимности Онсагера**. Для однородного объёма это означает:
```
κ(→) = κ(←)   в пределе ΔT → 0
```
Т.е. если вы приложите бесконечно малый градиент температуры, тепловой поток будет строго симметричен. Это не нарушение вашей идеи, а указание на то, что **эффект выпрямления возникает только в нелинейном режиме**, когда:
1. Есть **структурная асимметрия** (отсутствие центра инверсии, полярная ось).
2. Есть **нелинейность решётки** (ангармонизм, температурно-зависимое фонон-фононное рассеяние).
3. Градиент температуры **достаточно велик**, чтобы система вышла за пределы линейного отклика.

В этом случае эффективная теплопроводность становится функцией направления градиента: `κ_eff(+ΔT) ≠ κ_eff(-ΔT)`. Это и есть «храповой механизм» для фононов.

### 🧊 2. Почему ZnO (вюрцит) подходит идеально
- Вюрцитная структура ZnO **не имеет центра инверсии** и обладает выделенной полярной осью `c`.

- Сильная пьезоэлектрическая связь и различие масс Zn/O усиливают **направленную зависимость фононных мод** (особенно акустических/оптических ветвей вдоль `c`).
- В таких условиях вероятность рассеяния фонона `k → k'` может отличаться от `-k → -k'` при наличии градиента `T`, что в сумме даёт направленный перенос энергии.

# Аналитическая оценка коэффициента теплового выпрямления для 2D модели вюрцита (ZnO)

Ниже приведена последовательная аналитическая оценка ожидаемого коэффициента выпрямления `R` для вашей двумерной модели кристалла оксида цинка со структурой вюрцита.

## 1. Определение коэффициента выпрямления

Для стационарного теплового потока `J` вдоль выделенной оси (полярной оси `c`, в модели — ось `y`):

```
R(ΔT) = |J(+ΔT) - J(-ΔT)| / max(|J(+ΔT)|, |J(-ΔT)|)
```

где `+ΔT` означает градиент температуры в направлении полярной оси, `-ΔT` — в противоположном.

В **слабом нелинейном пределе** (`ΔT ≪ T`) коэффициент выпрямления линейно зависит от градиента:

```
R ≈ γ · (ΔT / T)
```

где `γ` — безразмерный параметр, определяемый микроскопическими свойствами решётки.

---

## 2. Микроскопическая модель и параметры

Из ваших ноутбуков (`Lagrange_2d_ZnO.ipynb`, `moldyn_2d_ZnO`):

| Параметр | Значение | Комментарий |
|----------|----------|-------------|
| `M` (масса Zn) | 65.38 а.е.м. | Тяжёлый подрешётка |
| `m` (масса O) | 15.999 а.е.м. | Лёгкий подрешётка |
| `l` (параметр решётки) | 0.458 нм (или масштабированный) | Межатомное расстояние |
| `k` (жёсткость связи) | варьируется, типично 1–10 эВ/нм² | Гармоническая часть потенциала |
| `α, β` (ангармонические коэффициенты) | из разложения потенциала | Асимметрия ямы |

### Асимметрия потенциала

Для атома в несимметричной яме потенциал вдоль полярной оси раскладывается:

```
U(x) = ½ k x² + ⅓ α x³ + ¼ β x⁴ + ...
```

Ключевой параметр асимметрии — **отношение ангармонического члена к гармоническому** при характерном смещении `x₀ ~ √(k_B T / k)`:

```
ε ≡ |α| x₀ / k = |α| / k · √(k_B T / k)
```

Для вюрцита асимметрия противоположна для подрешёток Zn и O (из геометрии): `α_Zn ≈ -α_O`.

## 3. Теоретическая оценка в приближении кинетического уравнения

### 3.1. Фононное время релаксации

В ангармонической решётке вероятность трёхфононного рассеяния зависит от знака волнового вектора при наличии асимметрии потенциала. В первом порядке по `ε`:

```
τ⁻¹(±k) = τ₀⁻¹ [1 ± ε · g(k, ω, T)]
```

где `g(k, ω, T)` — безразмерная функция, зависящая от дисперсии фононов и статистики.

### 3.2. Тепловой поток

В приближении времени релаксации тепловой поток вдоль оси `y`:

```
J = -κ ∇T + δκ (∇T)² / T + ...
```

где:
- `κ` — обычная (симметричная) теплопроводность,
- `δκ` — поправка, ответственная за выпрямление.

Коэффициент выпрямления в линейном по `ΔT` порядке:

```
γ = δκ / κ
```

### 3.3. Оценка `γ` для 2D вюрцита

Для двумерной гексагональной решётки с двумя атомами в ячейке и контрастом масс `μ = (M - m)/(M + m)`:

```
γ ≈ C · ε · μ · η(ω_D / k_B T)
```

где:
- `C ~ O(1)` — геометрический фактор (для вюрцита `C ≈ 0.3–0.5` из-за угла 120°),
- `μ = (65.38 - 15.999)/(65.38 + 15.999) ≈ 0.607` — контраст масс,
- `η(ξ)` — функция, описывающая вклад фононов разных частот; при `T ~ θ_D` (температура Дебая) `η ~ 0.2–0.5`.

### 3.4. Численная подстановка

Возьмём типичные параметры:
- `k = 5 эВ/нм² ≈ 80 Н/м`,
- `α = 10 эВ/нм³ ≈ 16 Н/м²` (оценка из асимметрии вюрцита),
- `T = 300 К`, `k_B T ≈ 0.026 эВ`,
- `x₀ = √(k_B T / k) ≈ √(0.026 / 5) нм ≈ 0.072 нм`,
- `ε = |α| x₀ / k ≈ 10 · 0.072 / 5 ≈ 0.144`.

Тогда:

```
γ ≈ 0.4 · 0.144 · 0.607 · 0.3 ≈ 0.0105
```

И ожидаемый коэффициент выпрямления при `ΔT = 50 К`:

```
R ≈ γ · (ΔT / T) ≈ 0.0105 · (50 / 300) ≈ 1.75 × 10⁻³ ≈ 0.18%
```

## 4. Поправки и уточнения для вашей модели

### 4.1. Влияние размерности (2D vs 3D)
- В 2D плотность фононных состояний `g(ω) ∝ ω` (линейная), а не `ω²` как в 3D.
- Это усиливает вклад низкочастотных акустических мод, для которых `g(k, ω, T)` может быть больше.
- **Ожидаемое усиление**: `γ_2D ≈ 1.5–2 × γ_3D`.

### 4.2. Роль нелинейности третьего порядка
Ваш код (`Lagrange_2d_ZnO.ipynb`) использует разложение Лагранжиана до третьего порядка. Это корректно для оценки `γ`, так как выпрямление возникает именно из кубических членов (`α x³`).

### 4.3. Геометрический фактор вюрцита
В 2D модели вюрцита связи ориентированы под углами ±30° к полярной оси. Проекция асимметрии на ось теплопереноса даёт множитель `cos(30°) = √3/2 ≈ 0.866`.

### 4.4. Уточнённая формула

С учётом всех поправок для вашей конкретной модели:

```
γ ≈ (√3/2) · (|α| / k) · √(k_B T / k) · (M - m)/(M + m) · η_2D(T/θ_D)
```

При `T = 300 К`, `θ_D(ZnO) ≈ 700 К` → `T/θ_D ≈ 0.43`, `η_2D ≈ 0.4`.

Подстановка:
```
γ ≈ 0.866 · 0.144 · 0.607 · 0.4 ≈ 0.030
```

И при `ΔT = 50 К`:
```
R ≈ 0.030 · (50/300) ≈ 0.5%
```

## 🧮 2. Оценка способности кристалла «выпрямлять» флуктуации

### 2.1. Амплитуда температурных флуктуаций

Для кристалла размера `L` число фононных мод `N ~ (L/a)²` (в 2D), где `a ~ 0.458 нм` — параметр решётки.

Относительная флуктуация температуры:
```
δT / T ~ 1 / √N
```

| Размер кристалла | `N` (оценка) | `δT` при `T = 300 К` |
|-----------------|--------------|---------------------|
| `L = 10 нм` | ~ 500 | ~ 13 К |
| `L = 50 нм` | ~ 1.2×10⁴ | ~ 2.7 К |
| `L = 100 нм` | ~ 4.8×10⁴ | ~ 1.4 К |
| `L = 1 мкм` | ~ 4.8×10⁶ | ~ 0.14 К |

### 2.2. Ожидаемый выпрямленный сигнал

Если бы кристалл мог выпрямлять флуктуации с коэффициентом `R ~ 0.003–0.01`, то эффективная разность температур:
```
⟨ΔT_rect⟩ ≈ R · δT
```

| `L` | `δT` | `⟨ΔT_rect⟩` (при `R = 0.005`) |
|-----|------|-------------------------------|
| 10 нм | 13 К | ~ 65 мК |
| 50 нм | 2.7 К | ~ 14 мК |
| 100 нм | 1.4 К | ~ 7 мК |
| 1 мкм | 0.14 К | ~ 0.7 мК |

**Но**: это *мгновенная* оценка. В реальности:

1. **Время релаксации** температурного градиента: `τ ~ L² / α`, где `α` — температуропроводность (~10⁻⁵ м²/с для ZnO).
   - Для `L = 100 нм`: `τ ~ 1 нс`
   - Для `L = 1 мкм`: `τ ~ 100 нс`

2. **Усреднение по времени**: За время измерения `t_meas ≫ τ` сигнал усредняется к нулю:
   ```
   ⟨ΔT_rect⟩_time ≈ ⟨ΔT_rect⟩_instant · √(τ / t_meas)
   ```
   При `t_meas = 1 мкс` и `τ = 1 нс` подавление составляет `√(10⁻³) ≈ 0.03`.

**Итог**: устойчивая разность температур от выпрямления равновесных флуктуаций будет **на 2–3 порядка меньше** приведённых выше оценок — т.е. в диапазоне **микрокельвинов и ниже**, что практически ненаблюдаемо на фоне измерительного шума.

- внешней накачки (периодическое воздействие, градиент, облучение),

- либо обработки информации (как в демоне Максвелла — с энтропийной платой за стирание памяти).

### Почему так происходит?
1. **Принцип детального баланса** справедлив **только для состояния термодинамического равновесия**. Он гласит, что в равновесии скорость каждой элементарной стадии в прямом направлении точно равна скорости обратной стадии. В результате макроскопические концентрации постоянны, а циклические макроскопические превращения невозможны (теорема Вегенштейна-Вант-Гоффа/принцип микроскопической обратимости).

2. **Реакция БЖ — классическая неравновесная система.** Чтобы в ней возникали устойчивые химические колебания или пространственные диссипативные структуры, система должна быть **открытой** и постоянно поддерживаться вдали от термодинамического равновесия за счёт притока свежих реагентов (бромат, кислота, органический субстрат) и отвода продуктов. В таком состоянии детальный баланс **заведомо нарушен**: в системе возникают ненулевые циклические потоки, которые и поддерживают периодические изменения концентраций катализатора (Ce³⁺/Ce⁴⁺ или ферроина/ферриина).

3. **Кинетический аспект (модель Орегонатора).** В упрощённой кинетической модели БЖ (Орегонатор Филд-Кёроша-Нойеса) обязательным математическим условием возникновения автоколебаний является наличие хотя бы одной **необратимой** или сильно неравновесной стадии (например, окисление малоновой кислоты броматом в кислой среде). Именно нарушение детального баланса на кинетическом уровне приводит к потере устойчивости стационарного состояния (бифуркации Хопфа) и запуску колебаний.

4. **Что происходит в конце реакции?** Если реакцию провести в закрытом сосуде без подпитки, реагенты в конце концов исчерпаются, система придёт в состояние термодинамического равновесия, колебания затухнут, и тогда принцип детального баланса **восстановится**: все прямые и обратные скорости элементарных реакций сравняются, а макроскопические изменения прекратятся.

### Итог

Детальный баланс восстанавливается только тогда, когда система полностью расслабляется и приходит в термодинамическое равновесие, после чего колебания прекращаются.

### 📡 2. Выпрямление шума Найквиста: как это работает

Шум Найквиста: $\langle V^2(t) \rangle = 4k_B T R \Delta f$.  
Если сопротивление зависит от мгновенного напряжения: $R = R_0 + R_1 V + R_2 V^2 + \dots$, то ток:
$$I(t) = \frac{V(t)}{R(V)} \approx \frac{V}{R_0} - \frac{R_1}{R_0^2} V^2 + \dots$$
Усредняя по времени:
$$\langle I_{DC} \rangle = -\frac{R_1}{R_0^2} \langle V^2 \rangle \neq 0 \quad \text{при } R_1 \neq 0$$

Здесь $R_1 = \frac{dR}{dV}\big|_{V=0}$ возникает именно из-за **зеркальной асимметрии** кристалла: $R(+V) \neq R(-V) \Rightarrow R_1 \neq 0$.  
Это стандартный результат нелинейной теории флуктуаций (см. Hanggi & Ingold, *Chaos* 2005; Reimann, *Phys. Rep.* 2002). Эффект наблюдается в:
- диодах Шоттки на полярных полупроводниках,
- сегнетоэлектрических тонких плёнках,
- графеновых/вюрцитных гетероструктурах.

Ваша идея переносит этот механизм **в объём монокристалла**, что принципиально важно: выпрямление происходит не на границе раздела фаз, а в каждой элементарной ячейке благодаря структурной нецентросимметрии.

### ⚖️ 3. Термодинамический статус: нарушает ли это 2-е начало?

**Короткий ответ:** Нет. Это проявление **нелинейного флуктуационно-диссипативного отклика**, а не нарушение фундаментальных законов.

**Детали:**
1. В **полном термодинамическом равновесии** (замкнутая система, $T=\text{const}$, нет внешних градиентов) обобщённая ФДТ гарантирует $\langle I_{DC} \rangle = 0$. Асимметрия $R(\pm V)$ компенсируется обратной связью через фононный и электронный термостаты.
2. В **реальной измерительной схеме** всегда есть:
   - конечное сопротивление нагрузки,
   - усилитель с входным импедансом,
   - тепловой контакт с окружающей средой,
   - возможный микроградиент $T$ или внешнее поле.
   Эти условия выводят систему в **неравновесное стационарное состояние (NESS)**, где детальное равновесие не выполняется, и выпрямленный сигнал $\langle I_{DC} \rangle \neq 0$ становится наблюдаемым.
3. Энтропия полной системы (кристалл + цепь + термостат) **растёт**. Выпрямление шума идёт за счёт диссипации в измерительном контуре и не создаёт вечный двигатель.

Это полностью согласуется с позицией, которую мы обсуждали ранее: детальное равновесие нарушается в открытых/неравновесных системах, и именно это позволяет преобразовывать флуктуации в направленный сигнал без нарушения 2-го начала.

### 🔍 1. Почему ФДТ «запрещает» нарушение второго начала?
На самом деле **ФДТ не запрещает второе начало**. Она является его **математическим следствием** для систем в тепловом равновесии. ФДТ выводится из:
- Обратимости микроскопических уравнений движения (T-симметрия)
- Равновесного распределения Гиббса
- Линейности отклика в пределе слабых возмущений

В этом пределе теорема гарантирует:
```
⟨J(t)⟩ = 0   при полном термодинамическом равновесии
S_ω(ω) = 2k_BT Re[Y(ω)]
```
где `S_ω` – спектр флуктуаций, `Y(ω)` – адмиттанс. Это не постулат, а строгая теорема. Если бы в полном равновесии возникал ненулевой средний ток `⟨J⟩≠0`, это действительно означало бы возможность извлечения работы из одного теплового резервуара, т.е. нарушение формулировки Кельвина-Планка. **ФДТ не «охраняет» второе начало, а отражает его в языке корреляционных функций.**

Ваше замечание справедливо: ФДТ применима только к равновесным или слабовозмущённым системам. В сильно нелинейных, неравновесных или измерительных цепях она обобщается, и её простая форма уже не работает. Но обобщённые формы (Кубо, Хэнгги-Ингольд, неравновесные ФДТ) по-прежнему совместимы с производством энтропии `dS/dt ≥ 0` при учёте полной системы.

### 🔋 2. Самозаряжающийся конденсатор: вечный двигатель или нет?
Ваш эксперимент с измерением мощности самозаряда реален, и совпадение с теоретической оценкой выпрямления шума Найквиста закономерно. Но является ли это **вечным двигателем второго рода (ПМ2)**? Термодинамический анализ показывает, что **нет**, и вот почему:

#### ✅ Что действительно происходит
1. **Переходная зарядка, а не непрерывная генерация**  
   Асимметричная нелинейность (вариап, p-n переход, сегнетоэлектрик) действительно выпрямляет тепловые флуктуации напряжения. Конденсатор заряжается до напряжения `V_DC`, при котором обратный ток через нелинейность точно компенсирует выпрямленный шум:
   ```
   I_rect(V_DC) = I_back(V_DC)  →  dV/dt = 0
   ```
   Это **стационарное смещение**, а не источник бесконечной мощности.

2. **Цикл «заряд–разряд» даёт нулевую работу в изотермии**  
   Чтобы извлечь работу, нужно разрядить конденсатор через нагрузку. При разряде выделяется тепло `Q_dis = ∫V·I dt`. В полном цикле при постоянной температуре:
   ```
   ⟨W_cycle⟩ = ⟨Q_in⟩ - ⟨Q_out⟩ = 0
   ΔS_universe = ΔS_sys + ΔS_bath ≥ 0
   ```
   Энергия, которую вы измерили осциллографом, – это **мощность диссипации в измерительном тракте**, а не чистая работа, извлечённая из равновесного теплового резервуара.

3. **Роль измерительной цепи**  
   Входной импеданс осциллографа, кабели, защитные диоды, усилительные каскады сами содержат нелинейности. Часто именно они выступают как выпрямители, а не исследуемый конденсатор. Измеренная мощность совпадает с теорией Найквиста, потому что теория описывает именно **флуктуационно-диссипативный баланс в цепи**, а не нарушение термодинамики.

4. **Скрытые неравновесные условия**  
   Даже микроскопический градиент `ΔT ~ 0.01 К`, разность работ выхода контактов, термо-ЭДС, внешние наводки или нестабильность питания прибора выводят систему в **неравновесное стационарное состояние (NESS)**. В NESS детальное равновесие нарушено, направленный ток возможен, и второе начало не нарушается, потому что энтропия растёт за счёт скрытых градиентов или начального неравновесного состояния.

# Никель-водородный кольцар: монотермическое преобразование тепловой энергии в направленную диффузию водорода

**А. Ю. Дроздов**

## Аннотация
В работе рассматривается схема никель-водородного кольцара, ожидаемый эффект работы которого состоит в монотермическом превращении рассеянного тепла окружающей среды в механическую работу путём возникновения самопроизвольного устойчивого стационарного потока рабочего тела (водорода) сквозь металлическую мембрану. Физическая основа эффекта опирается на кристаллографическую асимметрию поверхностей монокристалла никеля: различие в угловых распределениях десорбирующихся молекул $H_2$ ($\cos\theta$ для Ni(110) и $\cos^5\theta$ для Ni(111)) и коэффициентах прилипания $s_0$. Показано, что при достаточно малом зазоре и низкой концентрации газообразного водорода в промежуточной фазе возникает отклонение от принципа детального равновесия, что приводит к направленному осмотическому потоку. Приведена оценка ожидаемой мощности устройства и обсуждены технологические варианты изготовления несимметричной мембраны.

**Ключевые слова:** водородная проницаемость, несимметричная мембрана, детализованное равновесие, угловая десорбция, коэффициент прилипания, монотермический двигатель, кольцар.

## 1. Введение
В данной работе рассматривается схема водородно-никелевого кольцара, ожидаемый эффект работы которого состоит в монотермическом превращении рассеянного тепла окружающей среды в механическую работу путем возникновения самопроизвольного устойчивого стационарного потока рабочего тела, которым является водород, сквозь металлическую мембрану. Идея была сформулирована с использованием теоретической информации, изложенной в работе Christmann K. *Interaction of hydrogen with solid surfaces* // Surf. Sci. Rep. 1988. Vol. 9. P. 1–163.

Принципиальная осуществимость предлагаемой идеи (но в несколько другой интерпретации) была рассмотрена теоретически и доказана экспериментально в главе 7 *"Chemical Nonequilibrium Steady States"* (Химически неравновесные стационарные состояния) книги В. Чапека *"Challenges to the Second Law of Thermodynamics"* (2005). В указанном разделе автор рассматривает вариант атомно-молекулярного стационарного неравновесия как на поверхности металла, так и в газовой фазе, демонстрируя возможность установления направленного потока при равенстве макропараметров по обе стороны системы.

## 2. Физико-химические основы взаимодействия водорода с поверхностью металла
Для поверхностей, характеризующихся кинетикой десорбции второго порядка, концентрацию молекул водорода в газовой фазе можно записать через предэкспоненциальный множитель кинетики десорбции $\nu_2$ (Frequency factor, см²·с⁻¹·ат⁻¹), коэффициент прилипания $s_0$, активационный барьер процесса десорбции $\Delta E^*_d(\Theta)$, поверхностную концентрацию адсорбированных атомов водорода $n_{ad}$ и среднюю скорость молекул водорода в газовой фазе $\bar{c}$:
$$
s_0 \bar{c} n_g = \nu_2(\Theta) \exp\left(-\frac{\Delta E^*_d(\Theta)}{kT}\right) n_{ad}^2
$$
Отсюда:
$$
n_g = \frac{\nu_2(\Theta)}{s_0} \exp\left(-\frac{\Delta E^*_d(\Theta)}{kT}\right) \frac{n_{ad}^2}{\bar{c}}
$$

Экспериментально установлено, что угловое распределение молекул водорода, десорбирующихся с поверхности монокристалла металла, зависит от кристаллографической грани $hkl$. Если грань имеет плотно упакованную поверхность, как например Ni(111), то угловое распределение десорбирующихся молекул имеет узкий пик $\sin^5\theta$ (или $\cos^5\theta$ относительно нормали). Если же грань имеет более рыхлую упаковку, как например Ni(110), то угловое распределение десорбирующихся молекул имеет более широкий спектр углов разлетания $\sin\theta$ ($\cos\theta$).

Таким образом, молекулы, десорбирующиеся с Ni(111), трансляционно «горячие» и направлены преимущественно перпендикулярно поверхности, тогда как десорбция с Ni(110) происходит в состоянии теплового равновесия с температурой поверхности и с широким угловым спектром.

## 3. Механизм нарушения детального равновесия в несимметричной мембране
Отклонение от принципа детального равновесия в газовой фазе промежутка (зазора) ожидается вследствие того, что десорбирующиеся молекулы $H_2$ с разных кристаллографических поверхностей одного и того же металла имеют разное угловое распределение, уже измеренное в экспериментах: $\cos(\theta)$ с поверхности Ni(110) и $\cos^5(\theta)$ с поверхности Ni(111).

Вследствие различия вероятности прилипания вероятность того, что нормально направленные к поверхности молекулы, которые были десорбированы с верхней поверхности (Ni(111), трансляционно «горячие») и долетели до нижней поверхности (Ni(110)), вероятность их поглощения на нижней поверхности достаточно высока вследствие значения коэффициента прилипания $s_0 \approx 0.96$.

В противоположность этому, вероятность того, что нормально направленные молекулы, которые были десорбированы с нижней поверхности Ni(110) (трансляционно равновесные) и долетели до верхней поверхности Ni(111), уже низкая из-за:
1) их относительно меньшей кинетической энергии;
2) весьма низкого коэффициента прилипания на поверхности Ni(111) $s_0 \approx 0.1$;
3) весьма острого углового распределения $\cos^5(\theta)$ каналов адсорбции-десорбции на поверхности Ni(111), что снижает вероятность захвата наклонно падающих молекул.

На нижней поверхности Ni(110) направленные наклонно молекулы будут достаточно эффективно адсорбироваться из-за широкого углового распределения $\cos(\theta)$ каналов адсорбции-десорбции. Таким образом, именно зазоры могут выступать тем пространством, в котором можно ожидать нарушения принципа детального равновесия. Это нарушение возникает на границе квантового и классически корпускулярного движения молекул водорода.

## 4. Оценка ожидаемой мощности кольцара
Для оценки стационарного потока через мембрану используется классическое соотношение:
$$
J = \frac{\Phi}{L} \left( P_u^{1/2} - P_d^{1/2} \right)
$$
где $J$ — стационарный поток водорода (моль $H_2$·м⁻²·с⁻¹), $\Phi$ — проницаемость (моль $H_2$·м⁻¹·с⁻¹·Па⁻¹/²), $P_u, P_d$ — давления водорода на upstream и downstream сторонах (Па), $L$ — толщина мембраны.

Из экспериментальных данных (Nishimura C. et al., 1991) для температуры $T = 35^\circ\text{C} = 308\,\text{K}$:
- $\Phi_{\text{Pd}} = 6 \cdot 10^{-9}$ моль $H_2$·м⁻¹·с⁻¹·Па⁻¹/²
- $\Phi_{\text{V-10Ni}} = 6 \cdot 10^{-8}$ моль $H_2$·м⁻¹·с⁻¹·Па⁻¹/²

При равновесных давлениях, соответствующих разным граням одного металла (или разным металлам), и толщине мембраны $L = 100\,\text{мкм}$ расчет показывает установление направленного потока. Скорость потока в газовой фазе оценивается как:
$$
v = \frac{J}{c} = J \frac{RT}{p}
$$
При использовании аналогии с жидкокристаллическим осмосом и введении коэффициента полезного действия выпрямления $\eta \approx 0.5$, ожидаемая стационарная мощность на единицу площади мембраны составляет:
$$
w = \eta \cdot p_{\text{осм}} \cdot v_{\text{осм}} \approx 1.3 \, \text{Вт/м}^2
$$
Расчёт произведён для весьма низких давлений газообразного водорода порядка $10^{-4} \dots 10^{-9}$ мм рт. ст. Как изменится оценка ожидаемой мощности при увеличении давления водорода, пока неясно, поскольку отсутствуют изотермы диссоциации для более высоких давлений при комнатных температурах.

## 5. Технологические варианты реализации
Монокристаллический никель известен в виде булей, подобных монокристаллам полупроводников. Предлагается два технологических варианта изготовления несимметричной мембраны:
1. **Механическая сборка:** Разрезание булей на пластинки вдоль требуемых $hkl$ (например, из одной були делают пластинки Ni(111), из другой Ni(110)). После шлифовки в условиях, исключающих образование окислов, пластинки слепляются силами Ван-дер-Ваальса или Казимира, либо сплавляются при контролируемом нагреве.
2. **Ионное напыление:** На пластину требуемой ориентации $hkl$ методом вакуумного ионного напыления наносится слой того же никеля, но под заданным углом к поверхности, что позволяет индуцировать другую кристаллографическую ориентацию на выходе.

Проблема преодоления атомарным водородом спая монокристаллов с разными $hkl$ теоретически связана с зоной дефектов кристаллической структуры. Однако если в этой зоне не будет заметной примеси окислов, существенного барьера ожидать не следует.

## 6. Обсуждение и аналогии
Рассматриваемая идея имеет прямые аналогии с известными физическими системами:
- **Электрофизический кольцар Жвирблиса** демонстрирует принципиальную возможность монотермического преобразования, однако обладает малой энергоэффективностью из-за высокого барьера выхода атомарного водорода из металла.
- **Найквистор Виноградова** использует выпрямление флуктуаций тока утечки на несимметричной вольт-фарадной характеристике конденсатора. В мембранной аналогии резистором выступает диэлектрик (или окисный слой) обкладки, а мощность определяется произведением мощности тока Найквиста на коэффициент выпрямления $\eta < 1$. По расчётам Ю. Виноградова, на подложке площадью 1 см² можно разместить порядка $9.5 \cdot 10^{10}$ элементарных ячеек размером $35 \times 30$ нм.
- **Неэрмитовы квантовые системы** (Тимофеев, Колотинский) указывают на возможность локальных отклонений от классических законов сохранения в открытых диссипативных системах, что коррелирует с ожидаемым нарушением детального баланса на границе квантово-классической дифракции молекул $H_2$ на кристаллической решётке.

Теоретическое рассмотрение кинетики десорбции первого порядка также показало, что стационарный неравновесный поток при равенстве давлений и температур в несимметричной мембране может установиться при определённых условиях, аналогично модели кинетики десорбции второго порядка.

## 7. Заключение
1. Кристаллографическая асимметрия поверхностей монокристалла (различие $hkl$ граней) приводит к несимметричным угловым распределениям десорбирующихся молекул $H_2$ и различным коэффициентам прилипания $s_0$.
2. В системе с двумя разными гранями, разделёнными малым зазором, при равных макроскопических $T$ и $P$ возникает нарушение принципа детального равновесия, приводящее к самопроизвольному стационарному потоку водорода.

Формула для плотности газа при десорбции:
\[

\[
