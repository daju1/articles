# Проверочный ноутбук

`verification_unified_theory.ipynb` — ядро **SageMath 9.6**.

Каждая выкладка из статей — markdown-ячейка, за ней code-ячейка с проверкой,
печатающей `OK / FAIL` и невязку. Последняя ячейка — сводка.
Перед публикацией прогнан в обычном Python (numpy): **48 из 48 проверок OK**, ~2 с.

Запуск:
```
cd ~/articles/theory/verification
sage -n jupyter verification_unified_theory.ipynb
```
Первая ячейка вызывает `preparser(False)`, поэтому код — чистый Python и одинаково работает
в Sage и в обычном Jupyter (нужен только numpy).

Разделы: 1 лагранжиан и C_ijkl · 2 Бьянки, Най · 3 Пич–Кёлер/Эшелби · 4 неприводимые модули
c₁…c₃ · 5 досветовой спин, g · 6 импульс монополя 4/3 · 7 ядро Лазара · 8 излучение, твист,
анаполь · 9 часы де Бройля · 10 Казимир: поля мод, T_zz, приложение B, две пластины ·
11 Эйлер/Альманси, β, вторая гармоника · 12 Васильев: суперпозиция · 13 Чурляев.

Если для какой-то задачи понадобится скорость — код на C компилируется в `.so`
(`gcc -O3 -shared -fPIC x.c -o x.so -lm`) и подключается через `ctypes`, как в
`theory/unified_model_channels/`.
