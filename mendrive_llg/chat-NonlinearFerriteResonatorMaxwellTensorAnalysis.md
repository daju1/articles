## 1. Что уже сделано в линейной модели (первое приближение)

Геометрия: $x\le-a$ — хороший (электрический) проводник, левая стенка, TM‑мода, накачка электрическим током $je_z$; $-a\le x\le a$ — вакуум; $x\ge a$ — «плохой» магнитный проводник (феррит), правая стенка, TE‑мода, накачка магнитным током $jm_z$ [3]. Потери в обеих стенках вводятся через комплексные материальные параметры

$$\epsilon' = \epsilon + i\,\frac{4\pi\sigma_e}{\omega},\qquad \mu' = \mu + i\,\frac{4\pi\sigma_m}{\omega}$$

т.е. у вас уже полностью дуальная система с **двумя** токами — электрическим и магнитным [3]:

$$\mathrm{rot}\,\vec H = -\frac{i\omega}{c}\epsilon'\vec E + \frac{4\pi}{c}\vec j_e,\qquad
\mathrm{rot}\,\vec E = \frac{i\omega}{c}\mu'\vec H - \frac{4\pi}{c}\vec j_m$$

Важная деталь, на которую стоит обратить внимание: тензор $\mu_r$ правой (ферритовой) стенки у вас **не диагональный** — есть компоненты $\mu_{r,yz},\mu_{r,zy}$ [3]. Это структура типа тензора Полдера — она возникает только у **подмагниченного** гиротропного феррита (линеаризация уравнения Ландау–Лифшица вокруг статического смещающего поля $\vec H_0$). Это заранее подсказывает, какая нелинейная модель является «родной» для вашей линейной — см. п. 3.

Два режима:
- **QNM** (затухание): однородная система, $\det M_4(\omega)=0$, $\omega$ комплексная — разница тензора Максвелла $T_{xx}$ на границах вакуумного промежутка $\ne 0$ («опора на вакуум») [3].
- **Драйв** (накачка): неоднородная система $M_4\vec X=\vec B_{ext}(j_0)$ при действительной $\omega$, ток $j_{ext}$ вводится в скин-слое с тем же профилем, что и собственная мода (mode‑matched) [1][3] — и именно в этом режиме интеграл $\Delta T_{xx}$ по вакуумному промежутку у вас обнуляется.

## 2. Уравнения Максвелла для нелинейной среды в СГС (с $j_e$ и $j_m$)

Как только среда нелинейна, метод комплексных амплитуд неприменим — поля перестают быть чисто синусоидальными (генерируются гармоники), поэтому нужно писать уравнения сразу во временной области, без факторизации $e^{-i\omega t}$:

$$\mathrm{rot}\,\vec H = \frac{1}{c}\frac{\partial \vec D}{\partial t} + \frac{4\pi}{c}\big(\vec j_e^{\,cond}+\vec j_e^{\,ext}\big),\qquad
\mathrm{rot}\,\vec E = -\frac{1}{c}\frac{\partial \vec B}{\partial t} - \frac{4\pi}{c}\big(\vec j_m^{\,cond}+\vec j_m^{\,ext}\big)$$

Левая (электрическая) стенка остаётся линейной — на kHz–MHz закон Ома $\vec j_e=\sigma_e\vec E$, $\vec D=\epsilon\vec E$ работает прекрасно, металл не даёт заметного гистерезиса. Меняется только правая стенка.

Для феррита: $\vec B=\vec H+4\pi\vec M$, где $\vec M=\vec M(\vec H,\text{история})$ — нелинейная, гистерезисная функция. Подставляя в уравнение ротора $E$:

$$\mathrm{rot}\,\vec E = -\frac{1}{c}\frac{\partial \vec H}{\partial t} - \underbrace{\frac{4\pi}{c}\frac{\partial \vec M}{\partial t}}_{\text{эффективный }\vec j_m^{\,cond}} - \frac{4\pi}{c}\vec j_m^{\,ext}$$

Это ровно нелинейное обобщение вашего линейного $\vec j_m=\sigma_m\vec H$ — только теперь «магнитный ток проводимости» — это $\dfrac{\partial \vec M}{\partial t}$, не пропорциональный мгновенно $\vec H$, а зависящий от предыстории. Структура уравнения (и знак источника, и место входа в $\mathrm{rot}\,E_z$) сохраняется полностью в соответствии с таблицей дуальности TM/TE, которую вы уже вывели [3].

## 3. Модель $\vec M(\vec H)$: Джилс–Атертон или Ландау–Лифшиц(-Гильберт)?

Диапазон kHz–MHz для мягких ферритов обычно **ниже** частоты ферромагнитного резонанса (для типичных ферритов $f_{FMR}\sim 10^2$ МГц – единицы ГГц, зависит от поля анизотропии и $\gamma\approx1.76\times10^7\,\text{рад}/(с\cdot\text{Э})$). В этом диапазоне динамика намагниченности определяется движением/закреплением доменных стенок, а не прецессией — поэтому скалярная гистерезисная модель Джилса–Атертона (как в решении другой модели [2]) физически оправдана как **макроскопическая замыкающая связь** $B(H)$.

Но у вас в линейной модели уже есть недиагональные $\mu_{r,yz},\mu_{r,zy}$ — а это сигнатура именно **подмагниченного гиротропного** феррита, то есть линеаризованного вокруг смещающего поля уравнения Ландау–Лифшица. Скалярная JA не воспроизводит гиротропию — она даст только диагональный (изотропный) отклик и потеряет ту структуру, которая уже заложена в вашей линейной модели. Поэтому:

- Если недиагональные $\mu_{r,yz/zy}$ у вас — результат подмагничивающего поля (а не просто анизотропии формы), то **естественным** нелинейным обобщением является именно **уравнение Ландау–Лифшица–Гильберта**:

$$\frac{d\vec M}{dt} = -\gamma\,\vec M\times\vec H_{eff} - \frac{\gamma\alpha}{M_s}\,\vec M\times(\vec M\times\vec H_{eff}),\qquad \vec H_{eff}=\vec H+\vec H_{anis}+\vec H_{0}$$

При малых переменных возмущениях $\vec H_1$ вокруг статического $\vec M_0\|\vec H_0$ линеаризация LLG **точно** восстанавливает тензор Полдера — то есть ваш существующий комплексный $\mu'_r$ с недиагональными членами получается как частный (линейный) предел LLG. Это даёт естественную проверку калибровки: подобрать $\gamma, M_s, \alpha, H_0$ так, чтобы малосигнальный предел LLG совпал с уже подобранными численными значениями `mu_r_xx_d, mu_r_yy_d, mu_r_zz_d, mu_r_yz_d, mu_r_zy_d`.

- Скалярную JA стоит держать как **дополнительный/альтернативный** блок — она дешевле и хороша, если основной интересующий эффект — потери на перемагничивание доменных стенок при больших амплитудах (а не гиротропия), либо как модель для сравнения порядка величины гистерезисных потерь.

Рекомендация: основной путь — LLG (сохраняет вашу гиротропную структуру и превращается в неё при линеаризации); JA — контрольная/более простая модель для быстрой оценки.

## 5. Численная схема

Комплексная амплитуда больше не работает, но зависимость от $y,z$ можно оставить факторизованной ($e^{ik_zz}$, $k_z$ — то же, геометрия резонатора не меняется), поэтому задача редуцируется к **1D по $x$ + время** — как раз то, что нужно для FDTD:

1. Сетка по $x$ той же дискретизации скин-слоёв, что у вас (`h_conductor_l`, `h_conductor_r`), явная leapfrog-схема (Yee-подобная) для $E,H$; для LLG — норм-сохраняющая схема (midpoint/Cayley), чтобы $|\vec M|=M_s$ не «уплывал».
2. Источник — тот же mode-matched скин-профиль $je_{ext,y}(x), jm_{ext,z}(x)$, что и в вашей неоднородной задаче [1][3], но теперь как явная функция времени $\sin(\omega t)$, не комплексный вектор $B_{ext}$.
3. Прогон по времени до установления периодического режима (время установления — порядка обратной добротности, т.е. связано с вашим $\omega_{im}$ из QNM-расчёта).
4. Расчёт тензора Максвелла $T_{xx}(x,t)$ на обеих границах вакуума **во временной области** (не через $\overline{E}\cdot E$ для гармоник, а прямым произведением мгновенных полей) — и его усреднение по периоду, плюс спектральный анализ на выход в гармоники.
5. **Обязательная регрессионная проверка**: с $\vec M\to \chi_m\vec H$ (линейный предел LLG/JA) численная FDTD-схема должна воспроизвести ваш частотный результат — обнуление $\Delta T_{xx}$ в вакууме в режиме драйва. Без этого шага новому нелинейному результату нельзя доверять.

## 6. Тензор Максвелла и магнитные токи в нелинейном случае

У вас в модели уже разделены «жёсткий» тензор Максвелла и конвективный (абрахамо-подобный) тензор с членами $I$ (намагниченность) и $P$ (поляризация) [3]. ## Важное уточнение к плану, которое я обнаружил по ходу

Собранный прототип — только $(E_z,\,H_y)$, одна поперечная пара. Для чисто омического $\vec j_m=\sigma_m\vec H$ этого достаточно. **Но для уравнения Ландау–Лифшица это недостаточно.** Прецессионный крутящий момент $-\gamma\,\vec M\times\vec H_{eff}$ тождественно равен нулю, если $\vec M\parallel\vec H$ — а именно так вырождается задача с одной компонентой $H$. Гиротропный отклик (те самые недиагональные $\mu_{r,yz},\mu_{r,zy}$ в вашей линейной модели) физически возникает только когда есть **статическое подмагничивающее поле** (скорее всего вдоль $z$) и **переменная rf-компонента поперёк него** (вдоль $y$) — то есть нужны **одновременно** $H_y$ и $H_z$ (а с ними и $E_x$), как в полном TE-режиме с $k_z\neq0$ из вашей задачи [3], а не урезанная пара $(E_z,H_y)$.

Значит следующий шаг численно — не просто "вставить LLG в правую стенку этого прототипа", а **расширить прототип до полного набора полей** $(E_x,H_y,H_z)$ с $k_z$-связью, как у вас в TE-моде с $jm_z$-накачкой, и только в такую схему вставлять LLG с бисовым полем $H_0\hat z$. Иначе прецессия математически не включится и результат будет тривиально совпадать с чисто резистивной моделью.

```python
import numpy as np
import matplotlib
matplotlib.use("Agg")            # для headless-режима; в Jupyter можно убрать
import matplotlib.pyplot as plt
import os

# =====================================================================
# Линейный FDTD-прототип (регрессионный чек-пойнт), топология MenDrive:
# слева -- лоссовая "электрическая" стенка (sigma_e на Ez),
# посередине -- вакуум,
# справа -- лоссовая "магнитная" стенка (sigma_m на Hy, дуальный аналог
#           комплексного mu' = mu + i*4*pi*sigma_m/omega),
# возбуждение -- магнитный ток jm с mode-matched скин-профилем справа.
# Единицы: СГС-подобная нормировка c=1, размеры O(1) (масштабная модель,
# НЕ реальные сантиметровые размеры резонатора -- это пока только
# проверка связки "лоссовый FDTD + тензор Максвелла + усреднение по t").
# =====================================================================

c = 1.0
a, h_l, h_r = 1.0, 0.2, 0.2        # половина вакуумного зазора, толщины стенок
sigma_e, sigma_m = 3.0, 3.0        # электрическая / "магнитная" проводимости стенок

x_min, x_max = -(a + h_l), (a + h_r)
N = 1200
dx = (x_max - x_min) / N
dt = 0.4 * dx / c                   # CFL

x_Ez = x_min + dx * np.arange(N + 1)          # узлы Ez (целые)
x_Hy = x_min + dx * (np.arange(N) + 0.5)      # узлы Hy (полуцелые), Yee-сетка

left_E, right_E = x_Ez < -a, x_Ez > a
left_H, right_H = x_Hy < -a, x_Hy > a

sigma_e_arr = np.where(left_E, sigma_e, 0.0)
sigma_m_arr = np.where(right_H, sigma_m, 0.0)

# Коэффициенты полуявной лоссовой схемы (Taflove-подобные Ca/Cb, Da/Db)
Ca = (1 - 2*np.pi*sigma_e_arr*dt) / (1 + 2*np.pi*sigma_e_arr*dt)
Cb = (dt/dx) / (1 + 2*np.pi*sigma_e_arr*dt)
Da = (1 - 2*np.pi*sigma_m_arr*dt) / (1 + 2*np.pi*sigma_m_arr*dt)
Db = (dt/dx) / (1 + 2*np.pi*sigma_m_arr*dt)
Ds = (4*np.pi*dt) / (1 + 2*np.pi*sigma_m_arr*dt)

skin_r = 0.06
src_profile = np.where(right_H, np.exp(-(x_Hy - a)/skin_r), 0.0)  # mode-matched скин-профиль jm

i_left  = np.argmin(np.abs(x_Ez + a))   # индекс левой границы вакуума
i_right = np.argmin(np.abs(x_Ez - a))   # индекс правой границы вакуума

def run(omega0, n_periods=90, ramp_periods=15, J0=1.0, record_last=6.0):
    """Прогон FDTD на действительной частоте omega0 до установления,
    возвращает временные ряды T_xx на границах вакуума за последние record_last периодов."""
    Ez = np.zeros(N + 1)
    Hy = np.zeros(N)
    T = 2*np.pi / omega0
    nsteps = int(n_periods * T / dt)
    t = 0.0
    rec_t, rec_TxxL, rec_TxxR = [], [], []
    for _ in range(nsteps):
        ramp = min(1.0, t / (ramp_periods * T))         # плавный разгон источника
        jm = J0 * ramp * np.sin(omega0 * t) * src_profile
        Hy = Da*Hy - Db*(Ez[1:] - Ez[:-1]) + Ds*jm
        Ez[1:-1] = Ca[1:-1]*Ez[1:-1] - Cb[1:-1]*(Hy[1:] - Hy[:-1])
        Ez[0] = 0.0; Ez[-1] = 0.0                        # PEC на внешних границах
        t += dt
        if t > (n_periods - record_last) * T:
            Hy_at = np.interp(x_Ez, x_Hy, Hy)
            Txx = -(Ez**2 + Hy_at**2) / (8*np.pi)         # тензор Максвелла T_xx (СГС)
            rec_t.append(t); rec_TxxL.append(Txx[i_left]); rec_TxxR.append(Txx[i_right])
    return np.array(rec_t), np.array(rec_TxxL), np.array(rec_TxxR)

def peak_Ez_in_vacuum(omega0, n_periods=18, ramp_periods=4):
    """Быстрый прогон только для оценки амплитуды отклика (для скана резонанса)."""
    Ez = np.zeros(N + 1); Hy = np.zeros(N)
    T = 2*np.pi / omega0
    nsteps = int(n_periods * T / dt)
    t, peak = 0.0, 0.0
    for _ in range(nsteps):
        ramp = min(1.0, t / (ramp_periods * T))
        jm = ramp * np.sin(omega0 * t) * src_profile
        Hy = Da*Hy - Db*(Ez[1:] - Ez[:-1]) + Ds*jm
        Ez[1:-1] = Ca[1:-1]*Ez[1:-1] - Cb[1:-1]*(Hy[1:] - Hy[:-1])
        Ez[0] = 0.0; Ez[-1] = 0.0
        t += dt
        if t > (n_periods - 1.5) * T:
            peak = max(peak, abs(Ez[i_left]))
    return peak

# --- 1) грубый скан по частоте, чтобы найти резонанс ---
omegas = np.linspace(0.6, 2.6, 11)
amps = np.array([peak_Ez_in_vacuum(w) for w in omegas])
w_res = omegas[np.argmax(amps)]
print("Скан omega:", np.round(omegas, 3))
print("Пик |Ez| в вакууме:", np.round(amps, 4))
print("Оценка резонансной omega:", w_res)

# --- 2) длинный прогон на резонансе, расчёт разницы тензора Максвелла ---
t_h, TxxL, TxxR = run(w_res, n_periods=90, ramp_periods=15, record_last=6.0)
dTxx = TxxR - TxxL
amp_scale = np.max(np.abs(dTxx)) / 2

print("\nСреднее по времени <T_xx(a) - T_xx(-a)> =", dTxx.mean())
print("Характерный масштаб колебаний dTxx      =", amp_scale)
print("Относительная величина среднего:", dTxx.mean() / amp_scale)

# --- 3) график ---
os.makedirs("outputs", exist_ok=True)
cum_avg = np.cumsum(dTxx) / np.arange(1, len(dTxx) + 1)
fig, axs = plt.subplots(2, 1, figsize=(7, 6), sharex=True)
axs[0].plot(t_h, dTxx, lw=0.8)
axs[0].set_ylabel(r"$\Delta T_{xx}(t)=T_{xx}(a)-T_{xx}(-a)$")
axs[0].set_title("Линейный драйв-режим: разница тензора Максвелла\nна границах вакуумного промежутка")
axs[1].plot(t_h, cum_avg, color="darkred")
axs[1].axhline(0, color="k", lw=0.5)
axs[1].set_ylabel("накопленное среднее")
axs[1].set_xlabel("t")
plt.tight_layout()
plt.savefig("outputs/dTxx_linear_baseline.png", dpi=130)
```

## Важная поправка к плану — прежде чем писать код 3-полевого ядра

Пока разбирался с остатком, обнаружил концептуальную проблему в том пути, который предложил в прошлый раз (3 поля $E_x,H_y,H_z$ с огибающей $e^{ik_zz}$), и хочу её проговорить, а не молча кодить неправильно.

**Проблема.** У вас резонатор конечной длины $L_z$ — то есть $k_z$ не бегущая волна в бесконечном $z$, а **стоячая волна**, квантованная граничными условиями на торцах $z=0,L_z$. В линейной среде эта стоячая волна остаётся чистой синусоидой по $z$ на любой частоте. Но как только правая стенка становится нелинейной (Ландау–Лифшиц), намагниченность $\vec M(x,z,t)$ — это **локальная по $z$** динамика: в каждой точке $z$ поле $H(x,z,t)$ имеет свою мгновенную амплитуду вдоль профиля $\sin(k_zz)$, и нелинейный отклик в разных точках $z$ проходит по-разному. Это неизбежно **генерирует новые гармоники по $z$** ($3k_z, 5k_z,\dots$), аналогично тому, как нелинейность генерирует гармоники по времени. Комплексная огибающая одной моды $e^{ik_zz}$ для линейной теории — это ровно то приближение, которое **не годится**, если мы всерьёз считаем гистерезис.

Из этого следует два варианта:
- **Строгий путь** — полноценный 2D FDTD по $(x,z,t)$ (не 1D с огибающей), чтобы честно ловить любое перемешивание гармоник по $z$. Дороже по вычислениям, но при ваших нормированных масштабах — не критично.
- **Приближённый путь** — "гармонический баланс" по одной моде $z$ (игнорировать генерацию $3k_z$ и т.д.), что физически оправдано только при слабой нелинейности — нужно будет явно проверять малость отбрасываемых гармоник постфактум.

Я предлагаю сразу делать строгий путь (2D), пока задача маленькая — если позже окажется, что перекачка в высшие $k_z$-гармоники пренебрежимо мала, всегда можно вернуться к дешёвой 1D-огибающей моделe с полным основанием.

**Второе уточнение, более приятное.** Пересматривая структуру ваших мод, понял, что для главного вопроса исследования — как нелинейность **правой (ферритовой)** стенки влияет на $\Delta T_{xx}$ в вакууме — вообще не нужен магнитный ток накачки $j_m^{ext}$ на правой стенке. У вас уже есть режим **mode 1** ("`je_y, k_y=0, TE`" — по вашим словам, "текущая реализация" [1]): накачка электрическим током $j_{e,y}^{ext}$ **в левой (электрической) стенке**, поля $H_x,H_z,E_y$, а правая (ферритовая) стенка остаётся **пассивной** — она просто откликается на приходящее из вакуума поле. Именно это — естественная постановка "заменим линейный $\mu'_r$ на реальный гистерезисный отклик феррита, отвечающего на наведённое поле", без необходимости выдумывать отдельную магнитную накачку. Структура вставки внешнего тока и модификации граничных условий (`eq_Ey_l` → добавление $j_{ext}$, метод `get_field`) у вас уже готова и подробно описана [1] — по такой же логике я вставлю нелинейный член в уравнение для правой стенки.

**Третье — про корректность самого тензора Максвелла.** Уже проверено (в решении другой модели, но аргумент общий и верный): интеграл тензора Максвелла по **вакуумному** объёму остаётся математически корректным даже при гистерезисе в соседнем феррите, потому что мы берём поверхность интегрирования целиком внутри линейной вакуумной области — там связи $D=E$, $B=H$ линейны безусловно, и никаких проблем с "памятью материала" на самой поверхности интегрирования не возникает [2]. Это снимает опасение, что переход к нелинейной среде обесценивает саму методику расчёта силы через $T_{xx}$.

## 4. Направление подмагничивания — тензор Полдера как явная функция оси, плюс отдельный режим "off"

Написал и проверил `mu_tensor_polder(axis, omega, H0, Ms, gamma, alpha)` — СГС, линеаризация LLG без предположения о конкретной оси, через циклическую перестановку индексов:

```python
def polder_plane(omega, H0, Ms, gamma=1.76e7, alpha=0.0):
    """(mu, kappa) в плоскости, поперечной оси подмагничивания. СГС."""
    omega_H = gamma*H0
    omega_M = 4*np.pi*gamma*Ms
    if alpha != 0.0:
        omega_H = omega_H - 1j*alpha*omega   # приближённая гильбертовская подстановка
    denom = omega_H**2 - omega**2
    mu    = 1.0 + omega_H*omega_M/denom
    kappa = omega*omega_M/denom
    return mu, kappa

def mu_tensor_polder(axis, omega, H0, Ms, gamma=1.76e7, alpha=0.0):
    """
    3x3 тензор mu' в базисе (x,y,z). axis in {'x','y','z','off'}.
    'off' -> изотропная mu=1 (без гиротропии) -- НЕ предел H0->0 тензора
    Полдера (там при H0->0 kappa расходится как 1/omega -- это артефакт
    линеаризации вокруг единственного направления M0, которое перестаёт
    быть выделенным без bias; физически при H0=0 нужна другая модель --
    см. п.5).
    """
    if axis == 'off':
        return np.eye(3, dtype=complex)
    mu, kappa = polder_plane(omega, H0, Ms, gamma, alpha)
    idx = {'x':0,'y':1,'z':2}
    ax = idx[axis]
    i1, i2 = (ax+1) % 3, (ax+2) % 3
    T = np.eye(3, dtype=complex)
    T[i1,i1] = mu;  T[i2,i2] = mu
    T[i1,i2] =  1j*kappa
    T[i2,i1] = -1j*kappa
    return T
```

Проверка на реалистичных числах для мягкого феррита ($M_s=140$ Гс, $H_0=20$ Э, $f=1$ МГц): частота Лармора $f_H=\gamma H_0/2\pi\approx56$ МГц — то есть при возбуждении в кГц–МГц диапазоне вы работаете **сильно ниже** ферромагнитного резонанса ($f\ll f_H$), где $\mu\approx89$, $\kappa\approx0.5{-}5$ — заметная, но не аномально большая гиротропия. Годограф $\mu(\,f\,)$ я также посчитал вблизи $f_H$ — там резонансный пик (без потерь — расходимость, с $\alpha=0.02$ — конечный, но большой пик), что можно использовать позже как проверку на непопадание рабочей точки в ФМР при выборе $H_0$.

## 5. Важный нюанс — почему нужен явный режим "off", а не предел $H_0\to0$

При $H_0\to0$ у тензора Полдера $\kappa\to-\omega_M/\omega\to\infty$ — это не физический эффект, а признак того, что линеаризация вокруг $\vec M_0\parallel\vec H_0$ перестаёт иметь смысл без выделенного направления (реальный ненамагниченный феррит — многодоменный, там своя, немагнитная по гиротропии, но всё равно нелинейная физика домен­ных стенок). Поэтому режим "подмагничивание выключено" в коде я делаю **отдельной веткой**, а не частным случаем формулы — она возвращает изотропный комплексный скаляр $\mu'=\mu+i\,4\pi\sigma_m/\omega$, то есть в точности вашу исходную линейную модель без гиротропии [2]. Так у вас будет чистый переключатель из четырёх состояний: `off / x / y / z`, и `off` строго совпадает с уже проверенным регрессионным эталоном.

## 6. Скрытая сложность, которую нужно проговорить: TE/TM-связь зависит от выбранной оси

Это важно для оценки объёма работы по коду. В вашей редукции $k_y=0$ поля естественно делятся на TE ($H_x,H_z,E_y$) и TM ($E_x,E_z,H_y$) — независимые наборы в линейной изотропной среде. Гиротропия связывает *конкретную пару* компонент $H$:

- **bias по $y$** → связывает $H_z$-$H_x$ — это **обе компоненты уже внутри чистого TE-набора**. Значит для этой оси достаточно расширить существующее TE-ядро (Mode 1, $j_{e,y}$) — TM не нужен, код проще.
- **bias по $x$** → связывает $H_y$-$H_z$. Но $H_y$ есть только в TM-наборе, а $H_z$ — в TE. Значит при этой оси подмагничивания **правая стенка неизбежно перемешивает TE и TM** (нереципрокная конверсия мод в намагниченном феррите — известный физический эффект, не ошибка модели) — понадобится полный 6‑компонентный набор полей даже если возбуждение чисто TE.
- **bias по $z$** → связывает $H_x$-$H_y$, тоже смешивает TE и TM (аналогично).

Вывод: раз вы хотите проверить **все три** оси на равных правах, экономичнее сразу строить FDTD-ядро с полным набором из 6 компонент (обе TE и TM пары одновременно, при $k_y=0$), а не пытаться обойтись урезанным TE-only ядром и доращивать его по частям — иначе для осей $x$ и $z$ придётся переписывать структуру заново. Дороже по счёту, но избавляет от риска "выкинуть лишнее и потом жалеть", о чём вы просили заботиться.

**Первый прототип (1 пара $E_z,H_y$, использованный для регрессии)** — да, был на настоящей сетке Йе (Yee): $E_z$ на целых узлах $x_i$, $H_y$ на полуцелых $x_i+dx/2$. А вот $H_y$ на границе $x=\pm a$ **не имеет** узла — она смещена на полклетки, поэтому для расчёта тензора Максвелла $T_{xx}=-(E_z^2+H_y^2)/8\pi$ ровно на границе я интерполировал $H_y$ на сетку $E_z$ (`np.interp`). Это законный приём для энергетических величин, но источник небольшой погрешности — и вероятно, это одна из причин той самой немонотонной сходимости остатка $\overline{\Delta T_{xx}}$ по сетке, которую мы обсуждали ранее.

**Второй код (6 компонент, только что показанный)** — вот здесь я должен вас поправить: он **не на шахматной сетке**. ## Вопрос 3. `axis='off'` — это выключение подмагничивания или выключение гистерезиса?

Вы правильно почувствовали здесь неточность в моей терминологии, и хочу разобрать это до конца честно, потому что ответ важнее, чем кажется.

В текущем коде **ни одна** из четырёх веток (`off`, `x`, `y`, `z`) не содержит гистерезиса в строгом смысле — то есть зависимости от **истории** поля, необратимых потерь на перемагничивание доменных стенок. Смотрите, что там на самом деле есть:

- `axis='off'` → изотропная омическая $\sigma_m$ — линейная, безынерционная, без памяти;
- `axis='x'/'y'/'z'` → **линеаризованное** уравнение Ландау–Лифшица–Гильберта — это тоже линейный отклик (просто не изотропный, а гиротропный, с прецессией вокруг подмагничивающего поля), при $\alpha=0$ обратимый (без потерь), при $\alpha>0$ — с диссипацией через затухание Гильберта, но это **вязкое** затухание (пропорциональное скорости), а не гистерезисное (пропорциональное площади петли $B(H)$, зависящее от предыстории и амплитуды, а не от частоты).

То есть да — `axis='off'` означает выключение именно подмагничивания/прецессии, а не переключатель гистерезиса. Но и включённое подмагничивание (`x/y/z`) само по себе гистерезиса не даёт — линеаризация LLG вокруг равновесия $\vec M_0\parallel\vec H_0$ по определению не может воспроизвести нелинейную петлю $B(H)$, она даёт только резонансный (полдеровский) отклик.

Ваш физический вопрос про "неподмагниченный феррит с гистерезисом" совершенно справедлив: реальный размагниченный (многодоменный) феррит действительно гистерезисен — за счёт движения и закрепления доменных стенок, а не за счёт прецессии [упомянутый в решении другой модели тест на воспроизведение петли гистерезиса и её сравнение с моделью Джилса–Атертона отражает именно эту, отдельную физику [2]]. Значит правильная архитектура — **не одна ось `axis`**, а **два независимых переключателя**:

1. **ось смещающего поля** (`off/x/y/z`) — определяет, есть ли гиротропная связь компонент и в какой плоскости;
2. **модель диссипации/памяти** — отдельный флаг: `linear_ohmic` (то, что сейчас в `off`) / `LLG_precession` (то, что сейчас в `x/y/z`, линейно) / `LLG_with_saturation` (нелинейная LLG с насыщением $|\vec M|=M_s$, без предположения о малости $\vec h$) / `Jiles-Atherton` (скалярная гистерезисная модель, без прецессии, для неподмагниченного случая).

Сейчас в коде это два понятия слиты в одну ось, что и вызвало ваш совершенно правильный вопрос. Буду перепроектировать именно так — с двумя независимыми осями выбора, чтобы можно было отдельно смотреть "гиротропия без гистерезиса", "гистерезис без гиротропии" (неподмагниченный, домен-стеночный феррит) и их комбинацию.

```python
            grid2, h2_native = H_on_grid[c2]
            h1_A, h2_A = to_A(h1_native, grid1), to_A(h2_native, grid2)
            h1_B, h2_B = to_B(h1_native, grid1), to_B(h2_native, grid2)
            dmA1 = (-omega_H*mA2 + omega_M*h2_A + alpha*omega_M*h1_A - alpha*omega_H*mA1) * ferrite_A
            dmA2 = ( omega_H*mA1 - omega_M*h1_A - alpha*omega_H*mA2 + alpha*omega_M*h2_A) * ferrite_A
            dmB1 = (-omega_H*mB2 + omega_M*h2_B + alpha*omega_M*h1_B - alpha*omega_H*mB1) * ferrite_B
            dmB2 = ( omega_H*mB1 - omega_M*h1_B - alpha*omega_H*mB2 + alpha*omega_M*h2_B) * ferrite_B

        dHx = -c*rotE_x_A - 4*np.pi*sm_A*Hx
        dHy = -c*rotE_y_B - 4*np.pi*sm_B*Hy
        dHz = -c*rotE_z_B - 4*np.pi*sm_B*Hz - 4*np.pi*jm_z

        if axis != 'off':
            dM_dict = {c1: (grid1, dmA1 if grid1=='A' else dmB1),
                       c2: (grid2, dmA2 if grid2=='A' else dmB2)}
            if 'x' in dM_dict:
                g, dm = dM_dict['x']; dHx = dHx - 4*np.pi*(dm if g=='A' else to_A(dm,'B'))
            if 'y' in dM_dict:
                g, dm = dM_dict['y']; dHy = dHy - 4*np.pi*(dm if g=='B' else to_B(dm,'A'))
            if 'z' in dM_dict:
                g, dm = dM_dict['z']; dHz = dHz - 4*np.pi*(dm if g=='B' else to_B(dm,'A'))

        return dEy,dEz,dHx,dEx,dHy,dHz, dmA1,dmA2, dmB1,dmB2

    t=0.0
    rec_t=[]; rec_TxxL=[]; rec_TxxR=[]

    for n in range(nsteps):
        args = (Ey,Ez,Hx,Ex,Hy,Hz, mA1,mA2, mB1,mB2)
        k1 = deriv(*args, t)
        args2 = tuple(a_+dt/2*b_ for a_,b_ in zip(args,k1)); k2 = deriv(*args2, t+dt/2)
        args3 = tuple(a_+dt/2*b_ for a_,b_ in zip(args,k2)); k3 = deriv(*args3, t+dt/2)
        args4 = tuple(a_+dt*b_ for a_,b_ in zip(args,k3));   k4 = deriv(*args4, t+dt)
        new = tuple(a_ + dt/6*(b1+2*b2+2*b3+b4) for a_,b1,b2,b3,b4 in zip(args,k1,k2,k3,k4))
        Ey,Ez,Hx,Ex,Hy,Hz, mA1,mA2, mB1,mB2 = new
        Ey[0]=0.0; Ey[-1]=0.0                   # PEC: Ey=0 на внешних границах (grid A)
        Ez[0]=0.0; Ez[-1]=0.0                   # PEC: Ez=0 на внешних границах (grid A)
        t += dt

        if t > (n_periods-record_last)*T:
            Hy_A = np.zeros(N+1,dtype=complex); Hy_A[1:-1]=0.5*(Hy[1:]+Hy[:-1])
            Hz_A = np.zeros(N+1,dtype=complex); Hz_A[1:-1]=0.5*(Hz[1:]+Hz[:-1])
            Ex_A = np.zeros(N+1,dtype=complex); Ex_A[1:-1]=0.5*(Ex[1:]+Ex[:-1])
            Txx = -(np.abs(Ex_A)**2 - np.abs(Ey)**2 - np.abs(Ez)**2
                    + np.abs(Hx)**2 - np.abs(Hy_A)**2 - np.abs(Hz_A)**2) / (8*np.pi)
            rec_t.append(t); rec_TxxL.append(Txx[iL_A].real); rec_TxxR.append(Txx[iR_A].real)

    return np.array(rec_t), np.array(rec_TxxL), np.array(rec_TxxR)
```

## Ответы на ваши три вопроса

### 1. Как удовлетворяются граничные условия на смещённой сетке — какой узел, какая компонента

Раскладку узлов я вывел напрямую из вида $\mathrm{rot}$ при $k_y=0$ и зависимости $e^{ik_zz}$:

$$(\mathrm{rot}\,F)_x=-ik_zF_y,\qquad(\mathrm{rot}\,F)_y=ik_zF_x-\frac{\partial F_z}{\partial x},\qquad(\mathrm{rot}\,F)_z=\frac{\partial F_y}{\partial x}$$

Требование самосогласованности (производная по $x$ должна консистентно переводить "целую" сетку в "полуцелую" и обратно, без интерполяции чисто полевых уравнений) даёт единственно возможное разбиение на две группы:

- **Сетка A (целые узлы $x_i$)**: $E_y,\,E_z,\,H_x$
- **Сетка B (полуцелые узлы $x_i+dx/2$)**: $E_x,\,H_y,\,H_z$

Проверка непосредственно по уравнениям (в коде это отражено построчно): $\partial E_y/\partial t\sim ik_zH_x(A)-\partial H_z/\partial x$ — $H_z$ на B, производная по соседним B-узлам даёт результат ровно на A, поэтому обновление $E_y$ полностью на своей сетке без интерполяции. Аналогично для остальных пяти компонент — все шесть уравнений проверены и согласованы (см. комментарий в начале кода).

**Какой узел — граница резонатора.** Как и в первом одно-парном прототипе, я подобрал $N$ так, чтобы $a$ и толщины стенок были кратны шагу $dx$ точно — тогда узел **сетки A** (целые узлы) попадает в $x=\pm a$ буквально с точностью до машинного нуля ($xA[iL\_A]-(-a)=0$, второй край — $2.2\times10^{-16}$, то есть машинный эпсилон). **Компоненты поля, вычисляемые прямо на границе** — это $E_y,E_z,H_x$ (сетка A), поскольку граница резонатора — плоскость постоянного $x$, и это именно тангенциальные к ней компоненты, для которых имеет физический смысл ставить условие PEC ($E_y=E_z=0$ на внешних торцах стенок). Компоненты сетки B ($E_x,H_y,H_z$) на границе вакуума не имеют узла — они интерполируются на сетку A простым усреднением соседей при расчёте тензора Максвелла $T_{xx}$ ровно на границе (как и в исходном прототипе, где $H_y$ интерполировалась на узлы $E_z$).

Нет — это уже отвечал, но подтверждаю ещё раз чётко: самый первый одно-парный прототип ($E_z,H_y$, регрессионный эталон) был **чисто линейным, безынерционным**: слева омический $\sigma_e$ на $E_z$, справа омический $\sigma_m$ на $H_y$. Никакой памяти материала, никакой динамики намагниченности там не было.

### 3. `axis='off'` — выключение подмагничивания, а не выключение гистерезиса

Вы правы, и это важное разграничение, которое я хочу зафиксировать явно. Ни в одной из веток кода (`off`, `x`, `y`, `z`) гистерезиса пока нет вообще:

- `off` — изотропная линейная $\sigma_m$ (без памяти, без прецессии);
- `x`/`y`/`z` — **линеаризованное** LLG: прецессия намагниченности вокруг подмагничивающего поля. При $\alpha=0$ это обратимый (лоссless) резонансный отклик, при $\alpha>0$ — с **вязким** (гильбертовским) затуханием, пропорциональным скорости, а не площади петли $B(H)$.

Настоящий гистерезис — зависимость от предыстории, необратимые потери на движение и закрепление доменных стенок в неподмагниченном (многодоменном) феррите — это отдельная, третья физика, которая не появится ни в одной из четырёх текущих осей. У неё нет выделенного направления $\vec M_0$, поэтому её нельзя вывести из линеаризации LLG вокруг равновесия — нужна отдельная скалярная модель (например, Джилса–Атертона [2]), не привязанная к оси подмагничивания вовсе.

Правильная архитектура — **два независимых переключателя**, а не один:
1. ось смещающего поля: `off / x / y / z` (гиротропия);
2. модель диссипации/памяти: `linear_ohmic` (сейчас в `off`) / `LLG_precession` (сейчас в `x/y/z`, без гистерезиса) / `Jiles-Atherton` (скалярный гистерезис для неподмагниченного случая, без гиротропии) / комбинация обоих для намагниченного феррита с реальными потерями.

## 1. Схема интегрирования по времени: уходим от RK4 к специализированным устойчивым схемам

Сейчас я использовал явный RK4 и на несмещённой сетке, и (частично) на сетке Йе — просто чтобы быстро проверить идею. Но для системы Максвелл+LLG это не лучший выбор по точности:

- Для лоссовых и дисперсных сред явные схемы (в том числе RK4) склонны к численной неустойчивости, и стандартный ответ на это в литературе по FDTD — переход на неявные или полуявные схемы, а также методы «очистки дивергенции», которые дополнительно следят, чтобы законы Гаусса выполнялись не только аналитически, но и на сеточном уровне [2]. ## 2. Нашёл и исправил ошибку в собственном аналитическом коде

## 3. Общий вывод из сохранения импульса поля — ключевой результат этого шага

В вакууме (область без зарядов и токов, по определению) закон сохранения импульса поля в 1D-редукции даёт точное тождество:

$$\frac{\partial g_x}{\partial t} + \frac{\partial T_{xx}}{\partial x} = 0$$

где $g_x$ — плотность импульса поля. Если поле в вакууме **строго периодично** во времени (в точности такая ситуация в стационарном режиме реальной частоты, где потери в стенках точно компенсируются подкачкой), то усреднение по одному периоду даёт $\langle\partial g_x/\partial t\rangle=0$ (периодическая величина за период не меняется), и отсюда:

$$\frac{d\langle T_{xx}\rangle}{dx}=0 \text{ в вакууме} \quad\Rightarrow\quad \langle T_{xx}\rangle=\text{const по всему вакуумному промежутку}$$

то есть $\Delta T_{xx}=T_{xx}(a)-T_{xx}(-a)=0$ **точно**, а не просто "мало". И это справедливо **независимо от того, что происходит в правой стенке** — линейный омический феррит, гиротропный (LLG), гистерезисный — до тех пор, пока (а) сам вакуумный промежуток остаётся строго без источников (это гарантировано геометрией) и (б) вся система, включая нелинейный феррит, выходит на **строго периодический** установившийся режим с периодом внешней накачки (пусть даже с высшими гармониками — важна периодичность, а не гармоничность).

Для режима QNM (комплексная $\omega$) картина меняется принципиально: огибающая поля **экспоненциально затухает** во времени, то есть строгой периодичности нет — усреднение $\langle\partial g_x/\partial t\rangle$ за характерный "период" **не** равно нулю (есть чистая убыль запасённого в вакууме импульса поля со скоростью, пропорциональной $\omega_{im}$), и поэтому $d\langle T_{xx}\rangle/dx\ne0$ — отсюда и наблюдаемая вами ненулевая опора на вакуум именно в затухающем режиме. Это объясняет вашу трихотомию (QNM/волноводное затухание — ненулевой $\Delta T_{xx}$; строго периодический драйв — нулевой) как **одно и то же явление**, а не как отдельные случайные совпадения.

## 4. Что это значит для гипотезы про гистерезис — честно, даже если это не то, что хотелось услышать

Из пункта 3 следует нежелательный, но логически неизбежный вывод: **если** ферритовая стенка с гистерезисом (или с LLG) под периодической накачкой действительной частоты выйдет на строго периодический предельный цикл — закон сохранения импульса **запрещает** $\Delta T_{xx}$ быть отличным от нуля, каким бы нелинейным ни был отклик феррита. Гистерезис сам по себе, если он даёт устойчивый периодический ответ (пусть даже искажённый, с гармониками), не может "включить" опору на вакуум — потому что вакуум остаётся строго безисточниковым, а строгая периодичность гарантирует нулевой сток импульса.

Это меняет постановку задачи. Чтобы получить ненулевой $\Delta T_{xx}$ при действительной частоте возбуждения, нужно искать **нарушение строгой периодичности**, а не просто "нелинейность самого феррита". Реалистичные кандидаты для такого нарушения — и это теперь главные гипотезы для дальнейшей проверки:

- **Переходный процесс до выхода на предельный цикл** — прямой аналог вашего QNM, но внутри временной эволюции нелинейной системы: до того как гистерезисная петля "устоится", есть окно, где периодичность ещё не достигнута и импульс вакуума реально стекает/накапливается.
- **Медленная магнитная релаксация (магнитное послеедействие)** — если у феррита есть релаксационные процессы с постоянной времени, отличной от периода накачки (характерно для реальных ферритов на низких частотах — кГц–МГц диапазон, который вы и просили), строгая периодичность может не устанавливаться вовсе, а деградировать в квазипериодический или дрейфующий режим.
- **Субгармоническая генерация / бифуркации предельного цикла** — сильно нелинейные магнитные системы под интенсивной накачкой известны тем, что могут терять простую периодичность с периодом накачки в пользу периода $2T, 3T,\dots$ или квазипериодичности с несоизмеримой частотой; тогда усреднение по "неправильному" периоду не даст точного нуля.

```python
import numpy as np

c = 1.0
a, h_l, h_r = 1.0, 0.2, 0.2
sigma_e = 3.0
x_min, x_max = -(a + h_l), (a + h_r)
N = 600
dx = (x_max - x_min) / N
xA = x_min + dx*np.arange(N+1)
xB = x_min + dx*(np.arange(N)+0.5)
leftA, rightA = xA < -a, xA > a
leftB, rightB = xB < -a, xB > a
sigma_e_A = np.where(leftA, sigma_e, 0.0)

def make_source_A(mode, skin=0.06):
    if mode == 'je_y':
        return np.where(leftA, np.exp((xA + a)/skin), 0.0)
    return np.zeros_like(xA)

def rodrigues_rotate(M, Heff, gamma, dt):
    """Точный поворот M вокруг оси Heff (сохраняет |M| аналитически точно)."""
    Hnorm = np.linalg.norm(Heff, axis=0)
    Hnorm_safe = np.where(Hnorm > 1e-300, Hnorm, 1.0)
    axis_ = Heff / Hnorm_safe
    theta = gamma * Hnorm * dt
    ct, st = np.cos(theta), np.sin(theta)
    dot = np.sum(axis_*M, axis=0)
    cross = np.array([axis_[1]*M[2]-axis_[2]*M[1],
                       axis_[2]*M[0]-axis_[0]*M[2],
                       axis_[0]*M[1]-axis_[1]*M[0]])
    M_new = M*ct + cross*st + axis_*dot*(1-ct)
    return np.where(Hnorm > 1e-300, M_new, M)

def llg_step(M, Heff, gamma, alpha, dt, Ms):
    """Точный поворот + явное затухание Ландау-Лифшица + перенормировка |M|=Ms."""
    M1 = rodrigues_rotate(M, Heff, gamma, dt)
    cross1 = np.array([M1[1]*Heff[2]-M1[2]*Heff[1],
                        M1[2]*Heff[0]-M1[0]*Heff[2],
                        M1[0]*Heff[1]-M1[1]*Heff[0]])
    damp_term = np.array([M1[1]*cross1[2]-M1[2]*cross1[1],
                           M1[2]*cross1[0]-M1[0]*cross1[2],
                           M1[0]*cross1[1]-M1[1]*cross1[0]])
    M2 = M1 - dt*(gamma*alpha/Ms)*damp_term
    norm2 = np.linalg.norm(M2, axis=0)
    norm2_safe = np.where(norm2 > 1e-300, norm2, 1.0)
    return M2 * (Ms/norm2_safe)

def run_long(dt_frac=0.1, H0=4.0, Ms=0.3, gamma=1.0, alpha=0.1,
             omega0=2.2, ramp_periods=20, cutoff_period=40,
             n_periods=70, J0=0.3, drive_mode='je_y', record_every=None):
    """cutoff_period: после какого числа периодов внешняя накачка J0 обнуляется --
    диагностика затухания/устойчивости автономной подсистемы M<->H."""
    T = 2*np.pi/omega0
    dt = dt_frac*dx/c
    nsteps = int(n_periods*T/dt)
    cutoff_t = cutoff_period*T
    if record_every is None:
        record_every = max(1, int(0.2*T/dt))
    Ey = np.zeros(N+1); Ez = np.zeros(N+1)
    Hy = np.zeros(N);   Hz = np.zeros(N)
    M = np.zeros((3, N)); M[0, rightB] = Ms
    src_A = make_source_A(drive_mode)
    Ca_e = (1 - 2*np.pi*sigma_e_A*dt) / (1 + 2*np.pi*sigma_e_A*dt)
    Cb_e = (dt/dx) / (1 + 2*np.pi*sigma_e_A*dt)
    src_coef = (dt/(1+2*np.pi*sigma_e_A*dt))*4*np.pi
    Db = (dt/dx)
    t = 0.0
    rec_t=[]; rec_E=[]
    for n in range(nsteps):
        s = min(1.0, t/(ramp_periods*T))*np.sin(omega0*t) if t < cutoff_t else 0.0
        je_y = J0*s*src_A
        Ey_new = np.zeros_like(Ey); Ez_new = np.zeros_like(Ez)
        Ey_new[1:-1] = Ca_e[1:-1]*Ey[1:-1] - Cb_e[1:-1]*(Hz[1:]-Hz[:-1]) - src_coef[1:-1]*je_y[1:-1]
        Ez_new[1:-1] = Ca_e[1:-1]*Ez[1:-1] + Cb_e[1:-1]*(Hy[1:]-Hy[:-1])
        Ey_new[0]=0.0; Ey_new[-1]=0.0
        Ez_new[0]=0.0; Ez_new[-1]=0.0
        Ey, Ez = Ey_new, Ez_new
        Heff = np.zeros((3, N))
        Heff[0, rightB] = H0
        Heff[1, rightB] = Hy[rightB]
        Heff[2, rightB] = Hz[rightB]
        M_old = M.copy(); M_new = M.copy()
        M_new[:, rightB] = llg_step(M[:, rightB], Heff[:, rightB], gamma, alpha, dt, Ms)
        dMy_dt = np.zeros(N); dMz_dt = np.zeros(N)
        dMy_dt[rightB] = (M_new[1, rightB] - M_old[1, rightB]) / dt
        dMz_dt[rightB] = (M_new[2, rightB] - M_old[2, rightB]) / dt
        M = M_new
        Hy_new = Hy + Db*(Ez[1:]-Ez[:-1]) - dt*4*np.pi*dMy_dt
        Hz_new = Hz - Db*(Ey[1:]-Ey[:-1]) - dt*4*np.pi*dMz_dt
        Hy, Hz = Hy_new, Hz_new
        t += dt
        if n % record_every == 0:
            Etot = np.sum(Ey**2)+np.sum(Ez**2)+np.sum(Hy**2)+np.sum(Hz**2)
            rec_t.append(t); rec_E.append(Etot)
    return np.array(rec_t), np.array(rec_E), cutoff_t
```

Моя реализация вычисляет отклик $M(H_{new})$ через **один** явный шаг Эйлера по переменной $H$ (не по времени!):
$$M_{irr}^{new} = M_{irr}^{old} + \frac{dM_{irr}}{dH}\cdot(H_{new}-H_{old})$$

Это соотношение справедливо только при **малом** $H_{new}-H_{old}$ — знаменатель $k\delta-\alpha(M_{an}-M_{irr})$ в правой части может проходить близко к нулю на пути интегрирования, и тогда $dM_{irr}/dH$ резко скачет. Внутри одного шага физического времени (когда $H_{new}-H_{old}$ мало по построению) это работает. Но **внутри итераций Ньютона** пробное значение $H_{new}$ временно уходит далеко от $H_{old}$ (пока Ньютон ищет корень) — и именно в этот момент однократный шаг Эйлера даёт мусор, ломая саму функцию, которую Ньютон пытается обнулить.

Настоящие ферриты помимо гистерезисных потерь всегда имеют дополнительный вязкий канал (вихревые токи, релаксационные потери) — в файле с моделью автора отмечено, что параметры JA включают именно 5-7 физически осмысленных величин, но чисто скалярная JA-модель без дополнительного члена вихревых потерь не описывает полный набор диссипативных механизмов реального материала [2]. Поэтому следующим шагом нужно **не отбрасывать JA**, а добавить к ней реалистичный маленький омический канал $\sigma_{m,leak}$ (параллельно гистерезису), как это обычно делается на практике — это устранит нефизическую ситуацию "нулевая диссипация при насыщении" и должно дать ограниченный установившийся режим, на котором уже можно будет корректно считать $\overline{\Delta T_{xx}}$.

```python
import numpy as np

def langevin_L(x):
    x = np.asarray(x, dtype=float)
    small = np.abs(x) < 1e-6
    return np.where(small, x/3.0 - x**3/45.0,
                     1.0/np.tanh(np.where(small,1.0,x)) - 1.0/np.where(small,1.0,x))

class JASmooth:
    """Модель Джилса-Атертона с интегрированием необратимой части ПОДРАЗБИЕНИЕМ
    по H (RK2/midpoint, n_sub мелких подшагов) -- гладкая функция M(H_new)
    при любом |H_new-H_old|, что необходимо для устойчивости метода Ньютона."""
    def __init__(self, Ms, a, alpha, k, c, n_sub=8, n_fp=3):
        self.Ms, self.a, self.alpha, self.k, self.c = Ms, a, alpha, k, c
        self.n_sub, self.n_fp = n_sub, n_fp

    def _M_of_Mirr(self, M_irr, H, M_guess):
        M = M_guess
        for _ in range(self.n_fp):
            He = H + self.alpha*M
            Man = self.Ms*langevin_L(He/self.a)
            M = (1-self.c)*M_irr + self.c*Man
        He = H + self.alpha*M
        Man = self.Ms*langevin_L(He/self.a)
        return M, Man

    def _rhs(self, M_irr, H, delta, M_guess):
        M, Man = self._M_of_Mirr(M_irr, H, M_guess)
        denom = self.k*delta - self.alpha*(Man - M_irr)
        denom_safe = np.where(np.abs(denom) < 1e-9, 1e-9*np.sign(denom+1e-30), denom)
        return (Man - M_irr) / denom_safe, M

    def integrate(self, M_irr_old, H_old, H_new, M_guess_old):
        """RK2 подразбиение пути [H_old,H_new] на n_sub шагов; знак delta
        фиксируется один раз на весь путь (обязательно для гистерезисной модели)."""
        Htot = H_new - H_old
        delta = np.where(Htot >= 0, 1.0, -1.0)
        h = Htot / self.n_sub
        M_irr = M_irr_old.copy(); M_guess = M_guess_old.copy(); H_cur = H_old.copy()
        for _ in range(self.n_sub):
            k1, M1 = self._rhs(M_irr, H_cur, delta, M_guess)
            M_irr_mid = M_irr + 0.5*h*k1
            k2, M2 = self._rhs(M_irr_mid, H_cur + 0.5*h, delta, M1)
            M_irr = M_irr + h*k2
            H_cur = H_cur + h
            M_guess = M2
        M_final, _ = self._M_of_Mirr(M_irr, H_new, M_guess)
        return M_irr, M_final

    def dM_dH(self, M_irr_old, H_old, H_new, M_guess_old):
        eps = 1e-6*np.maximum(1.0, np.abs(H_new))
        _, M0 = self.integrate(M_irr_old, H_old, H_new, M_guess_old)
        _, M1 = self.integrate(M_irr_old, H_old, H_new+eps, M_guess_old)
        return (M1-M0)/eps, M0

    def implicit_step(self, M_irr_old, H_old, M_old, rhs_extra, n_newton=6):
        """Решает H_new-H_old+4*pi*(M(H_new)-M_old)+rhs_extra=0 методом Ньютона."""
        H_new = H_old - rhs_extra
        for _ in range(n_newton):
            dMdH, Mc = self.dM_dH(M_irr_old, H_old, H_new, M_old)
            F = H_new - H_old + 4*np.pi*(Mc - M_old) + rhs_extra
            Fp = 1.0 + 4*np.pi*dMdH
            Fp_safe = np.where(np.abs(Fp) < 1e-6, 1e-6*np.sign(Fp+1e-30), Fp)
            H_new = H_new - F/Fp_safe
        M_irr_final, M_final = self.integrate(M_irr_old, H_old, H_new, M_old)
        return H_new, M_irr_final, M_final

# --- геометрия (та же, что во всех предыдущих валидированных прогонах) ---

    if mode == 'je_y':
        return np.where(leftA, np.exp((xA + a)/skin), 0.0)
    return np.zeros_like(xA)

    if mode == 'jm_z':
        return np.where(rightB, np.exp(-(xB - a)/skin), 0.0)

def run_ja_smooth(material='off', drive_mode='jm_z', omega0=2.2, J0=1.0,
                   n_periods=10, ramp_periods=3, sigma_m_off_val=3.0, dt_frac=0.1,
                   ja_params=(1.0,0.3,0.001,0.15,0.15), record_every=None):
    """material: 'off' (линейная Омическая правая стенка, регрессия) или
                 'ja'  (гистерезис Джилса-Атертона; ВАЖНО -- пока без
                        дополнительного вязкого канала потерь, см. текст)."""
    T = 2*np.pi/omega0
    dt = dt_frac*dx/c
    nsteps = int(n_periods*T/dt)
    if record_every is None:
        record_every = max(1, int(0.05*T/dt))
    Ey = np.zeros(N+1); Ez = np.zeros(N+1)
    Hy = np.zeros(N);   Hz = np.zeros(N)
    n_fer = int(rightB.sum())
    if material == 'ja':
        Ms_ja,a_ja,alpha_ja,k_ja,c_ja = ja_params
        ja = JASmooth(Ms_ja,a_ja,alpha_ja,k_ja,c_ja)
        M_irr = np.zeros(n_fer)
        M_field = np.zeros(n_fer)
    sm_arr = np.where(rightB, sigma_m_off_val if material == 'off' else 0.0, 0.0)
    Da = (1 - 2*np.pi*sm_arr*dt) / (1 + 2*np.pi*sm_arr*dt)
    Db = (dt/dx) / (1 + 2*np.pi*sm_arr*dt)
    src_A = make_source_A(drive_mode)
    src_B = make_source_B(drive_mode)
    Ca_e = (1 - 2*np.pi*sigma_e_A*dt) / (1 + 2*np.pi*sigma_e_A*dt)
    Cb_e = (dt/dx) / (1 + 2*np.pi*sigma_e_A*dt)
    src_coef = (dt/(1+2*np.pi*sigma_e_A*dt))*4*np.pi
    t = 0.0
    rec_t=[]; rec_TxxL=[]; rec_TxxR=[]

    for n in range(nsteps):
        ramp = min(1.0, t/(ramp_periods*T))
        s = ramp*np.sin(omega0*t)
        je_y = J0*s*src_A if drive_mode == 'je_y' else np.zeros(N+1)
        jm_z = J0*s*src_B if drive_mode == 'jm_z' else np.zeros(N)

        Ey_new = np.zeros_like(Ey); Ez_new = np.zeros_like(Ez)
        Ey_new[1:-1] = Ca_e[1:-1]*Ey[1:-1] - Cb_e[1:-1]*(Hz[1:]-Hz[:-1]) - src_coef[1:-1]*je_y[1:-1]
        Ez_new[1:-1] = Ca_e[1:-1]*Ez[1:-1] + Cb_e[1:-1]*(Hy[1:]-Hy[:-1])
        Ey_new[0]=0.0; Ey_new[-1]=0.0
        Ez_new[0]=0.0; Ez_new[-1]=0.0
        Ey, Ez = Ey_new, Ez_new

        Hy_new = Da*Hy + Db*(Ez[1:]-Ez[:-1])
        Hz_new = np.zeros_like(Hz)
        rotE_z_term = (Ey[1:]-Ey[:-1])/dx     # ВАЖНО: без лишнего минуса (исправленный знак)
        if material == 'off':
            Hz_new = Da*Hz - Db*(Ey[1:]-Ey[:-1]) - dt*4*np.pi*jm_z
        else:
            Hz_new[~rightB] = Hz[~rightB] - dt*rotE_z_term[~rightB] - dt*4*np.pi*jm_z[~rightB]
            rhs_extra = dt*rotE_z_term[rightB] + dt*4*np.pi*jm_z[rightB]
            Hz_ferrite_new, M_irr_new, M_new = ja.implicit_step(M_irr, Hz[rightB], M_field, rhs_extra)
            Hz_new[rightB] = Hz_ferrite_new
            M_irr = M_irr_new
            M_field = M_new
        Hy, Hz = Hy_new, Hz_new

        t += dt
        if n % record_every == 0:
            Hy_A = np.zeros(N+1); Hy_A[1:-1] = 0.5*(Hy[1:]+Hy[:-1])
            Hz_A = np.zeros(N+1); Hz_A[1:-1] = 0.5*(Hz[1:]+Hz[:-1])
            Txx = -(Ey**2 + Ez**2 + Hy_A**2 + Hz_A**2) / (8*np.pi)
            rec_t.append(t); rec_TxxL.append(Txx[iL_A]); rec_TxxR.append(Txx[iR_A])
            if not np.isfinite(Hz).all():
                break

    return np.array(rec_t), np.array(rec_TxxL), np.array(rec_TxxR)
```

```python
import numpy as np

def langevin_L(x):
    x = np.asarray(x, dtype=float)
    small = np.abs(x) < 1e-6
    return np.where(small, x/3.0 - x**3/45.0,
                     1.0/np.tanh(np.where(small,1.0,x)) - 1.0/np.where(small,1.0,x))

class JASmoothRK4Robust:
    """Джилс-Атертон с RK4-подразбиением и робастным Ньютоном:
    (1) delta фиксируется один раз до начала итераций Ньютона;
    (2) шаг Ньютона ограничен (damping) для избежания скачков возле F_p=0;
    (3) при неудаче -- пробуем противоположный знак delta;
    (4) физический предохранитель |M|<=Ms.
    Плюс параллельный вязкий канал потерь sigma_m_leak (backward Euler,
    безусловно устойчив), нужен чтобы диссипация не исчезала при насыщении."""
    def __init__(self, Ms, a, alpha, k, c, sigma_m_leak=0.0, n_sub=6, n_fp=3):
        self.Ms, self.a, self.alpha, self.k, self.c = Ms, a, alpha, k, c
        self.sigma_m_leak = sigma_m_leak
        self.n_sub, self.n_fp = n_sub, n_fp

    def _M_of_Mirr(self, M_irr, H, M_guess):
        M = M_guess
        for _ in range(self.n_fp):
            He = H + self.alpha*M
            Man = self.Ms*langevin_L(He/self.a)
            M = (1-self.c)*M_irr + self.c*Man
        He = H + self.alpha*M
        Man = self.Ms*langevin_L(He/self.a)
        return M, Man

    def _rhs(self, M_irr, H, delta, M_guess):
        M, Man = self._M_of_Mirr(M_irr, H, M_guess)
        denom = self.k*delta - self.alpha*(Man - M_irr)
        denom_safe = np.where(np.abs(denom) < 1e-9, 1e-9*np.sign(denom+1e-30), denom)
        return (Man - M_irr) / denom_safe, M

    def integrate_rk4(self, M_irr_old, H_old, H_new, M_guess_old, delta):
        """delta -- ПАРАМЕТР, фиксирован снаружи (не пересчитывается здесь)."""
        Htot = H_new - H_old
        h = Htot / self.n_sub
        M_irr = M_irr_old.copy(); M_guess = M_guess_old.copy(); H_cur = H_old.copy()
        for _ in range(self.n_sub):
            k1, M1 = self._rhs(M_irr, H_cur, delta, M_guess)
            k2, M2 = self._rhs(M_irr + 0.5*h*k1, H_cur + 0.5*h, delta, M1)
            k3, M3 = self._rhs(M_irr + 0.5*h*k2, H_cur + 0.5*h, delta, M2)
            k4, M4 = self._rhs(M_irr + h*k3, H_cur + h, delta, M3)
            M_irr = M_irr + (h/6.0)*(k1 + 2*k2 + 2*k3 + k4)
            M_irr = np.clip(M_irr, -self.Ms, self.Ms)   # физический предохранитель
            H_cur = H_cur + h
            M_guess = M4
        M_final, _ = self._M_of_Mirr(M_irr, H_new, M_guess)
        M_final = np.clip(M_final, -self.Ms, self.Ms)
        return M_irr, M_final

    def dM_dH(self, M_irr_old, H_old, H_new, M_guess_old, delta):
        eps = 1e-6*np.maximum(1.0, np.abs(H_new))
        _, M0 = self.integrate_rk4(M_irr_old, H_old, H_new, M_guess_old, delta)
        _, M1 = self.integrate_rk4(M_irr_old, H_old, H_new+eps, M_guess_old, delta)
        return (M1-M0)/eps, M0

    def _newton_branch(self, M_irr_old, H_old, M_old, rhs_extra, dt, delta, n_newton, max_step):
        H_new = H_old - rhs_extra
        leak_coef = 4*np.pi*self.sigma_m_leak*dt
        for _ in range(n_newton):
            dMdH, Mc = self.dM_dH(M_irr_old, H_old, H_new, M_old, delta)
            F = H_new - H_old + 4*np.pi*(Mc - M_old) + leak_coef*H_new + rhs_extra
            Fp = 1.0 + 4*np.pi*dMdH + leak_coef
            Fp_safe = np.where(np.abs(Fp) < 0.5, 0.5*np.sign(Fp+1e-30), Fp)
            step = np.clip(F/Fp_safe, -max_step, max_step)
            H_new = H_new - step
        dMdH, Mc = self.dM_dH(M_irr_old, H_old, H_new, M_old, delta)
        F_final = H_new - H_old + 4*np.pi*(Mc - M_old) + leak_coef*H_new + rhs_extra
        return H_new, F_final

    def implicit_step(self, M_irr_old, H_old, M_old, rhs_extra, dt, n_newton=6,
                       max_step_factor=0.25, tol=1e-5):
        max_step = max_step_factor * self.a
        delta_pred = np.where(-rhs_extra >= 0, 1.0, -1.0)
        H_new_a, F_a = self._newton_branch(M_irr_old, H_old, M_old, rhs_extra, dt, delta_pred, n_newton, max_step)
        bad = np.abs(F_a) > tol
        H_new = H_new_a.copy()
        delta_final = delta_pred.copy()
        if np.any(bad):
            delta_alt = -delta_pred
            H_new_b, F_b = self._newton_branch(M_irr_old, H_old, M_old, rhs_extra, dt, delta_alt, n_newton, max_step)
            use_b = bad & (np.abs(F_b) < np.abs(F_a))
            H_new = np.where(use_b, H_new_b, H_new_a)
            delta_final = np.where(use_b, delta_alt, delta_pred)
        M_irr_final, M_final = self.integrate_rk4(M_irr_old, H_old, H_new, M_old, delta_final)
        return H_new, M_irr_final, M_final
```

| $\text{Ratio}_{code} = \overline{\Delta T_{xx}}/\overline{P}$ | $7.6\times10^{-5}$ |
| **$F/P$** | $2.5\times10^{-10}$ Н/кВт |
| Эталон (фотонный парус, $1/c$) | $3.3\times10^{-6}$ Н/кВт |

**Важная оговорка**: это **не сходящийся результат** — всего 2 периода записи, между ними значение упало втрое ($2.18\times10^{-4}\to7.3\times10^{-5}$), то есть система ещё не вышла на установившийся режим. Считать это окончательной оценкой нельзя — это лишь демонстрация того, что формула Н/кВт работает и даёт разумный по порядку величины (не абсурдный) результат: эффект на 4 порядка слабее идеальной световой опоры, что физически правдоподобно для диссипативного гистерезисного механизма на такой грубой сетке.

Гистерезис-петлю и график динамики $\Delta T_{xx}(t)$/Н-кВт построить не успел — сессия оборвалась на следующем шаге. Ниже — весь код, чтобы вы могли прогнать его самостоятельно (в вашей среде это не составит проблемы) или чтобы я вернулся к этому в следующем сообщении, когда песочница стабилизируется.

```python
import numpy as np

def langevin_L(x):
    """Функция Ланжевена L(x) = coth(x) - 1/x, с безопасной асимптотикой при x->0."""
    x = np.asarray(x, dtype=float)
    small = np.abs(x) < 1e-6
    return np.where(small, x/3.0 - x**3/45.0,
                     1.0/np.tanh(np.where(small, 1.0, x)) - 1.0/np.where(small, 1.0, x))


class JASmoothRK4Robust:
    """
    Скалярная модель гистерезиса Джилса-Атертона (JA) с:
      - подразбиением RK4 внутри каждого FDTD-шага (n_sub),
      - неявным (Newton) решением самосогласованной связки Максвелл<->JA,
      - двойным перебором ветви delta=sign(dH/dt) при плохой сходимости,
      - параллельным вязким каналом магнитных потерь sigma_m_leak,
      - продольным DC-подмагничиванием H0_bias (только вдоль оси JA-отклика).

    ФИЗИЧЕСКОЕ ОГРАНИЧЕНИЕ: модель скалярна (M вдоль одной оси, совпадающей с
    рабочей RF-компонентой H, которую видит эта ось). Подмагничивание по
    нормали к стенкам или по второй поперечной оси потребовало бы векторной
    модели с прецессией (уравнение Ландау-Лифшица, гиротропный тензор
    Полдера) -- этого здесь НЕТ. См. класс MenDriveFDTD, bias_orientation.
    """
    def __init__(self, Ms, a, alpha, k, c, sigma_m_leak=0.0, H0_bias=0.0, n_sub=4, n_fp=3):
        self.Ms, self.a, self.alpha, self.k, self.c = Ms, a, alpha, k, c
        self.sigma_m_leak = sigma_m_leak
        self.H0_bias = H0_bias          # DC-подмагничивание, входит только в аргумент Ланжевена
        self.n_sub, self.n_fp = n_sub, n_fp

    def _M_of_Mirr(self, M_irr, H, M_guess):
        M = M_guess
        for _ in range(self.n_fp):
            He = (H + self.H0_bias) + self.alpha * M
            Man = self.Ms * langevin_L(He / self.a)
            M = (1 - self.c) * M_irr + self.c * Man
        He = (H + self.H0_bias) + self.alpha * M
        Man = self.Ms * langevin_L(He / self.a)
        return M, Man

    def _rhs(self, M_irr, H, delta, M_guess):
        M, Man = self._M_of_Mirr(M_irr, H, M_guess)
        denom = self.k * delta - self.alpha * (Man - M_irr)
        denom_safe = np.where(np.abs(denom) < 1e-9, 1e-9 * np.sign(denom + 1e-30), denom)
        return (Man - M_irr) / denom_safe, M

    def integrate_rk4(self, M_irr_old, H_old, H_new, M_guess_old, delta):
        h = (H_new - H_old) / self.n_sub
        M_irr, M_guess, H_cur = M_irr_old.copy(), M_guess_old.copy(), H_old.copy()
        for _ in range(self.n_sub):
            k1, M1 = self._rhs(M_irr, H_cur, delta, M_guess)
            k2, M2 = self._rhs(M_irr + 0.5*h*k1, H_cur + 0.5*h, delta, M1)
            k3, M3 = self._rhs(M_irr + 0.5*h*k2, H_cur + 0.5*h, delta, M2)
            k4, M4 = self._rhs(M_irr + h*k3, H_cur + h, delta, M3)
            M_irr = np.clip(M_irr + (h/6.0)*(k1 + 2*k2 + 2*k3 + k4), -self.Ms, self.Ms)
            H_cur = H_cur + h
            M_guess = M4
        M_final, _ = self._M_of_Mirr(M_irr, H_new, M_guess)
        return M_irr, np.clip(M_final, -self.Ms, self.Ms)

    def dM_dH(self, M_irr_old, H_old, H_new, M_guess_old, delta):
        eps = 1e-6 * np.maximum(1.0, np.abs(H_new))
        _, M0 = self.integrate_rk4(M_irr_old, H_old, H_new, M_guess_old, delta)
        _, M1 = self.integrate_rk4(M_irr_old, H_old, H_new + eps, M_guess_old, delta)
        return (M1 - M0) / eps, M0

    def _newton_branch(self, M_irr_old, H_old, M_old, rhs_extra, dt, delta, n_newton, max_step):
        H_new = H_old - rhs_extra
        leak_coef = 4*np.pi*self.sigma_m_leak*dt
        for _ in range(n_newton):
            dMdH, Mc = self.dM_dH(M_irr_old, H_old, H_new, M_old, delta)
            F = H_new - H_old + 4*np.pi*(Mc - M_old) + leak_coef*H_new + rhs_extra
            Fp = 1.0 + 4*np.pi*dMdH + leak_coef
            Fp_safe = np.where(np.abs(Fp) < 0.5, 0.5*np.sign(Fp + 1e-30), Fp)
            H_new = H_new - np.clip(F/Fp_safe, -max_step, max_step)
        dMdH, Mc = self.dM_dH(M_irr_old, H_old, H_new, M_old, delta)
        F_final = H_new - H_old + 4*np.pi*(Mc - M_old) + leak_coef*H_new + rhs_extra
        return H_new, F_final

    def implicit_step(self, M_irr_old, H_old, M_old, rhs_extra, dt,
                       n_newton=6, max_step_factor=0.25, tol=1e-5):
        max_step = max_step_factor * self.a
        delta_pred = np.where(-rhs_extra >= 0, 1.0, -1.0)
        H_a, F_a = self._newton_branch(M_irr_old, H_old, M_old, rhs_extra, dt, delta_pred, n_newton, max_step)
        bad = np.abs(F_a) > tol
        H_new, delta_final = H_a.copy(), delta_pred.copy()
        if np.any(bad):
            delta_alt = -delta_pred
            H_b, F_b = self._newton_branch(M_irr_old, H_old, M_old, rhs_extra, dt, delta_alt, n_newton, max_step)
            use_b = bad & (np.abs(F_b) < np.abs(F_a))
            H_new = np.where(use_b, H_b, H_a)
            delta_final = np.where(use_b, delta_alt, delta_pred)
        M_irr_f, M_f = self.integrate_rk4(M_irr_old, H_old, H_new, M_old, delta_final)
        return H_new, M_irr_f, M_f


class MenDriveFDTD:
    """
    1D FDTD резонатора МенДрайв (СГС), TE-канал (Ey, Hz) с нелинейным ферритом
    справа (x>a) и металлом (проводимость sigma_e_left) слева (x<-a).

    excitation_mode:
      'magnetic_right' -- поверхностный магнитный ток j_m в скин-слое феррита,
                           модифицирует закон Фарадея: dH/dt = -c*rotE - 4*pi*j_m.
      'electric_left'  -- импрессионный электрический ток j_e в скин-слое левого
                           металла, модифицирует закон Ампера: dE/dt = c*rotH - 4*pi*j_e.
                           (см. теорию j_ext_rot_H_theory.md [1])

    bias_orientation:
      'none'     -- без подмагничивания.
      'parallel' -- DC подмагничивание вдоль оси Hz (той же, что несёт RF и
                    участвует в JA) -- физически корректно в скалярной модели.
      'x' / 'y'  -- ПРИНИМАЮТСЯ, но ИГНОРИРУЮТСЯ с этой моделью: требуют
                    векторной динамики M с прецессией (Ландау-Лифшиц), которая
                    здесь не реализована. Это следующий шаг разработки, если
                    нужен честный гиротропный эффект нормального подмагничивания.

    Отношение сила/мощность (см. run(...) -> P) даётся в универсальных единицах:
      F/P [Н/Вт] = Ratio_code / c_phys[м/с],  Ratio_code = mean(dTxx)/mean(P)
    Это отношение НЕ зависит от выбора линейного масштаба L0 или амплитуды
    поля -- оба квадратичны и сокращаются (аналог F/P=1/c для фотонного паруса).
    """
    C_PHYS_M_S = 3e8

    def __init__(self, N, a=1.0, h_l=0.2, h_r=0.2, dt_frac=0.1,
                 excitation_mode='magnetic_right', bias_orientation='none', H0_bias=0.0,
                 sigma_m_leak=3.0, sigma_e_left=3.0, sigma_e_ferrite=0.0,
                 Ms=1.0, a_JA=0.3, alpha_JA=0.001, k_JA=0.15, c_JA=0.15,
                 n_sub=4, n_fp=3, n_newton=6, skin_depth=0.06):
        self.N, self.a, self.h_l, self.h_r = N, a, h_l, h_r
        self.excitation_mode, self.n_newton = excitation_mode, n_newton
        x_min, x_max = -(a + h_l), (a + h_r)
        self.dx = (x_max - x_min) / N
        self.xA = x_min + self.dx * np.arange(N + 1)
        self.xB = x_min + self.dx * (np.arange(N) + 0.5)
        self.leftA, self.rightA = self.xA < -a, self.xA > a
        self.leftB, self.rightB = self.xB < -a, self.xB > a
        self.iL_A = np.argmin(np.abs(self.xA + a))
        self.iR_A = np.argmin(np.abs(self.xA - a))
        self.dt = dt_frac * self.dx
        self.n_fer, self.n_left = int(self.rightB.sum()), int(self.leftB.sum())

        H0_eff = H0_bias if bias_orientation == 'parallel' else 0.0
        if bias_orientation in ('x', 'y'):
            print(f"[ПРЕДУПРЕЖДЕНИЕ] bias_orientation='{bias_orientation}' не реализовано "
                  f"физически (нужна векторная модель Ландау-Лифшица). Подмагничивание проигнорировано.")
        self.bias_orientation = bias_orientation

        self.ja = JASmoothRK4Robust(Ms, a_JA, alpha_JA, k_JA, c_JA,
                                     sigma_m_leak=sigma_m_leak, H0_bias=H0_eff, n_sub=n_sub, n_fp=n_fp)

        sigma_e_A = np.where(self.leftA, sigma_e_left, np.where(self.rightA, sigma_e_ferrite, 0.0))
        self.Ca_e = (1 - 2*np.pi*sigma_e_A*self.dt) / (1 + 2*np.pi*sigma_e_A*self.dt)
        self.Cb_e = (self.dt/self.dx) / (1 + 2*np.pi*sigma_e_A*self.dt)

        self.src_mag_B = np.where(self.rightB, np.exp(-(self.xB - a)/skin_depth), 0.0)
        self.src_el_A = np.where(self.leftA, np.exp(-(-a - self.xA)/skin_depth), 0.0)
        self.reset_state()

    def reset_state(self):
        N = self.N
        self.Ey, self.Ez = np.zeros(N+1), np.zeros(N+1)
        self.Hy, self.Hz = np.zeros(N), np.zeros(N)
        self.M_irr, self.M_field = np.zeros(self.n_fer), np.zeros(self.n_fer)
        self.t = 0.0

    def _step(self, omega0, amp, ramp_periods, T):
        dt, dx = self.dt, self.dx
        ramp = min(1.0, self.t / (ramp_periods * T))
        s = amp * ramp * np.sin(omega0 * self.t)

        j_e_y_A = np.zeros(self.N + 1)
        j_m_z_B = np.zeros(self.N)
        if self.excitation_mode == 'magnetic_right':
            j_m_z_B = s * self.src_mag_B
        elif self.excitation_mode == 'electric_left':
            j_e_y_A = s * self.src_el_A
        else:
            raise ValueError(f"неизвестный excitation_mode={self.excitation_mode}")

        Ey, Ez, Hy, Hz = self.Ey, self.Ez, self.Hy, self.Hz
        Ey_new = np.zeros_like(Ey); Ez_new = np.zeros_like(Ez)
        Ey_new[1:-1] = (self.Ca_e[1:-1]*Ey[1:-1] - self.Cb_e[1:-1]*(Hz[1:]-Hz[:-1])
                        - dt*4*np.pi*j_e_y_A[1:-1])
        Ez_new[1:-1] = self.Ca_e[1:-1]*Ez[1:-1] + self.Cb_e[1:-1]*(Hy[1:]-Hy[:-1])
        Ey_new[0] = Ey_new[-1] = 0.0
        Ez_new[0] = Ez_new[-1] = 0.0

        # мощность источника эл. тока: сток энергии в теорему Пойнтинга = -j_e . E
        P_e = -np.sum(j_e_y_A * 0.5*(Ey + Ey_new)) * dx
        Ey, Ez = Ey_new, Ez_new

        Hy_new = Hy + (dt/dx)*(Ez[1:]-Ez[:-1])
        Hz_new = np.zeros_like(Hz)
        rotE_z = (Ey[1:]-Ey[:-1]) / dx
        rightB = self.rightB
        Hz_new[~rightB] = Hz[~rightB] - dt*rotE_z[~rightB] - dt*4*np.pi*j_m_z_B[~rightB]
        rhs_extra = dt*rotE_z[rightB] + dt*4*np.pi*j_m_z_B[rightB]
        Hz_f, M_irr_new, M_new = self.ja.implicit_step(self.M_irr, Hz[rightB], self.M_field,
                                                         rhs_extra, dt, n_newton=self.n_newton)
        Hz_new[rightB] = Hz_f

        # мощность магнитного источника: -j_m . H
        P_m = -np.sum(j_m_z_B * 0.5*(Hz + Hz_new)) * dx

        self.M_irr, self.M_field = M_irr_new, M_new
        self.Ey, self.Ez, self.Hy, self.Hz = Ey, Ez, Hy_new, Hz_new
        self.t += dt
        return P_e + P_m   # энергия за шаг; поделить на dt -> мощность

    def Txx_at(self, iA):
        """Плотность энергии (=T_xx компонента тензора Максвелла) в узле A-сетки iA."""
        Hy_A = 0.5*(self.Hy[iA-1]+self.Hy[iA]) if 0 < iA < self.N else 0.0
        Hz_A = 0.5*(self.Hz[iA-1]+self.Hz[iA]) if 0 < iA < self.N else 0.0
        return (self.Ey[iA]**2 + self.Ez[iA]**2 + Hy_A**2 + Hz_A**2) / (8*np.pi)

    def run(self, omega0, n_periods, record_from_period, amp=1.0, ramp_periods=2, probe_idx=0):
        """Возвращает t, dTxx (=Txx(right)-Txx(left), сила/площадь), Hn/Mn (проба в феррите),
        P (мощность источника, код.ед.), T, dt, blew_up."""
        T = 2*np.pi/omega0
        nsteps = int(n_periods*T/self.dt)
        record_start = int(record_from_period*T/self.dt)
        rec_t, rec_dTxx, rec_Hn, rec_Mn, rec_P = [], [], [], [], []
        blew_up = False
        for n in range(nsteps):
            P = self._step(omega0, amp, ramp_periods, T)
            if n >= record_start:
                rec_t.append(self.t)
                rec_dTxx.append(self.Txx_at(self.iR_A) - self.Txx_at(self.iL_A))
                rec_Hn.append(self.Hz[self.rightB][probe_idx])
                rec_Mn.append(self.M_field[probe_idx])
                rec_P.append(P/self.dt)
            if not np.isfinite(self.Hz).all():
                blew_up = True
                break
        return dict(t=np.array(rec_t), dTxx=np.array(rec_dTxx), Hn=np.array(rec_Hn),
                    Mn=np.array(rec_Mn), P=np.array(rec_P), T=T, dt=self.dt, blew_up=blew_up)

    def force_per_power(self, res, last_frac=0.5):
        """Возвращает (Ratio_code, F/P в Н/кВт), усреднённые по последней доле прогона."""
        T, dt = res['T'], res['dt']
        spp = int(round(T/dt))
        n_rec = len(res['t']) // spp
        pm_F = np.array([res['dTxx'][i*spp:(i+1)*spp].mean() for i in range(max(n_rec,1))])
        pm_P = np.array([res['P'][i*spp:(i+1)*spp].mean() for i in range(max(n_rec,1))])
        k = max(1, int(len(pm_F)*last_frac))
        mean_F, mean_P = pm_F[-k:].mean(), pm_P[-k:].mean()
        ratio_code = mean_F/mean_P if mean_P != 0 else np.nan
        return ratio_code, ratio_code/self.C_PHYS_M_S*1000  # Н/кВт


def scan_resonance_cheap(N, freqs, excitation_mode='magnetic_right',
                          sigma_m_leak=0.3, sigma_e_left=3.0,
                          n_periods=3, ramp_periods=1, amp=0.3):
    """Дешёвый скан для локализации резонанса: ПОНИЖЕННОЕ демпфирование
    (нужно для чёткого пика) и упрощённый (неточный) JA-решатель.
    НЕ использовать эти настройки для финальных физических выводов."""
    resp = []
    for w in freqs:
        sim = MenDriveFDTD(N, excitation_mode=excitation_mode,
                            sigma_m_leak=sigma_m_leak, sigma_e_left=sigma_e_left,
                            n_sub=1, n_fp=1, n_newton=3)
        res = sim.run(w, n_periods=n_periods, record_from_period=n_periods-1,
                      amp=amp, ramp_periods=ramp_periods)
        a_resp = (res['Hn'].max()-res['Hn'].min())/2 if (len(res['Hn'])>0 and not res['blew_up']) else np.nan
        resp.append(a_resp)
    return np.array(resp)
```

## Что осталось честно проговорить

1. **Подмагничивание по x/y** — в коде принимается параметр, но физически ничего не делает (явное предупреждение печатается). Для настоящего гиротропного эффекта нужна векторная модель с прецессией — отдельная существенная доработка.
2. **N=120/240** — при текущей скорости (~0.015 с/шаг при N=60, растёт быстрее линейного с N) и сегодняшней нестабильности песочницы (реальный лимит ~100–120с на вызов, без сохранения состояния между вызовами) эти расчёты либо нужно делать в вашей локальной среде по этому коду, либо ждать восстановления нормальной работы песочницы и запускать по частям.
