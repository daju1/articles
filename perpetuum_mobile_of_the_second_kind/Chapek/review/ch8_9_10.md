## 1. Глава 8. Plasma Paradoxes

### 1.1 Plasma I (§8.2, с. 240–251)

**Суть модели.** Чёрнотельная полость при T ≈ 1500–2000 K содержит разреженную термическую плазму: термоэлектронная (Ричардсоновская) эмиссия со стенок плюс поверхностная ионизация K. В полости висит зонд, соединённый со стенкой через нагрузку R_L. Потенциал плазмы V_pl ≠ 0 относительно стен. Авторы утверждают, что зонд «плавает» при V_f ≠ 0, поэтому на нагрузке есть V_L ≠ 0 и выделяется мощность P_L = V_L²/R_L, взятая из термостата.

Ключевые уравнения:
* (8.1), с. 241: A T² exp(−eΦ/kT) exp(eV_pl/kT) = n v_e/4. Это баланс ричардсоновской эмиссии стенки и электронного потока из плазмы на стенку.
* (8.2): критическая плотность n_c = (4AT²/e v_e) exp(−eΦ/kT). Проверка (моя): Ta, T = 1500 K, A = 6–12·10⁵ A/(m²K²) дают n_c = 1.1–2.2·10¹² м⁻³. Это совпадает с книгой («≃ 2×10¹² м⁻³»).
* Пять пунктов «crux», с. 243. Логика такая: второе начало нарушено ⇔ V_L ≠ 0, а V_L ≠ 0 ⇐ V_f ≠ 0. Цитата: «If VL = 0, there is no paradox; if VL ≠ 0, the second law is violable» (с. 243).
* Посылка (ii) V_f ≤ V_pl опирается на формулу холодного ленгмюровского зонда «Vf − Vpl ≃ kT/2e[ln(2πme/mi) − 1]. This quantity is negative definite» (с. 244). Для эмиссионного зонда авторы берут «Vf ≃ Vpl» и ссылаются на Hershkowitz: «self-emissive probes should electrically float near the plasma potential» (с. 242).

**Откуда, по авторам, нарушение.** Из того, что V_f ≠ 0 «подтверждено бесчисленными экспериментами с зондами», и из того, что сохраняется стационарная оболочка (sheath): энергия поля оболочки, отданная нагрузке, должна восполняться из термостата.

**Критический анализ.**

1. **Ошибка в посылке (ii)–(iii): V_f = 0 следует из собственного уравнения (8.1) книги.** Возьмём зонд из того же материала, что стенка (так и было в Эксп. 7–8, всё из Ta), при той же T. Его ток при V_pr = 0 равен
   I(0) = S·[A T² e^{−eΦ/kT} e^{eV_pl/kT} − n v_e/4] = 0 *ровно по (8.1)*.
   Для ионов аналогично работает Саха–Ленгмюр (8.5). Зонд — просто ещё один кусок стенки, поэтому плавает он там же, где стенка, т.е. при 0. Формула V_f − V_pl < 0 (с. 244) выведена для **холодного поглощающего** зонда. Правило «эмиссионный зонд плавает около V_pl» относится к зонду **горячее стенок** в плазме, созданной другим источником. Обе ситуации неравновесны (зонд и стенка при разных T). Подстановка этих формул в изотермическую чёрнотельную полость и есть нарушение детального равновесия, внесённое руками.
2. **Разные материалы зонда (W, Hf, LaB₆) ничего не меняют.** Между зондом и стенкой есть вольта-разность электростатических потенциалов, (Φ_пр − Φ_ст)/e. Но вольтметр и нагрузка чувствуют разность **электрохимических** потенциалов, а она в равновесии равна нулю (уровни Ферми выровнены через нагрузку). В терминах критерия: в контуре «стенка → оболочка → плазма → оболочка зонда → зонд → нагрузка → стенка» сумма скачков μ̃ равна 0, т.е. W = 1. Ток при Δμ̃ = 0 невозможен.
3. **Эквивалентная схема Рис. 8.8b (с. 263–264) содержит заключение в посылке.** Шиэн вставляет ЭДС V_p с внутренним сопротивлением R_p. Для неё (8.21) P_L = V_p²/((R_p/R_L + 1)(R_L + R_p)) = V_p² R_L/(R_L + R_p)², это просто формула батарейки. Но ЭДС Тевенена — это напряжение холостого хода, т.е. V_f, а в равновесии V_f = 0 (п. 1). Шиэн упрекает Крудена в petitio principii: «In Cruden's analysis, apparently the sheath is able to provide energy indefinitely without exhaustion» (с. 263). На деле круговое рассуждение у самого Шиэна: он постулирует V_p ≠ 0. Схема Крудена (8.8a, ЭДС последовательно с ёмкостью) даёт нулевой постоянный ток. Это правильная структура: оболочка — ёмкость, а не источник.
4. **Вариант с ключом (Рис. 8.1)** — зонд заряжается до V_f и потом разряжается через нагрузку. Он не спасает модель: заряд до V_f = 0 равен нулю.
5. **Изотермичность и замкнутость в эксперименте нарушены, и авторы это сами документируют:**
   * «with the center temperature consistently lower than the walls, typically by 5-50 K» (с. 245);
   * «Point C temperatures were 70 - 100 K below wall temperature» (с. 245); отверстие для зонда, теплоотвод по алундовому стержню;
   * атомы K вводились пучком из внешней печи. Полость открыта, работает вакуумный насос: «Pressure measurements inside the cavity were not made» (с. 245).

**Количественная проверка (моя): ΔT объясняет и знак, и величину V_PW.** Пусть зонд холоднее стенки на ΔT, материал тот же. Баланс эмиссии зонда и электронного потока, заданного стенкой, A T_p² e^{−Φ/kT_p} = A T_w² e^{−Φ/kT_w} e^{eV/kT_w}, даёт напряжение холостого хода термоэмиссионного «термоэлемента»:

```python
import numpy as np
kB=8.617e-5
def Voc(Tw,dT,Phi):              # зонд холоднее стенки на dT, одинаковая работа выхода
    Tp=Tw-dT
    return kB*Tw*(2*np.log(Tp/Tw) - Phi/(kB*Tp) + Phi/(kB*Tw))
for dT in (5,20,50,100,200): print(dT, round(1e3*Voc(1450,dT,4.2),1),'mV')
# 5 -15.4 | 20 -62.2 | 50 -158.8 | 100 -329.0 | 200 -709.1  (мВ)
```

Сравнение с экспериментом (Ta/Ta, Эксп. 7): плато «VPW also stabilizes at approximately -150mV, varying only 5 % during this time» (с. 249) соответствует ΔT ≈ 50 K, а это ровно тот разброс, который авторы измерили между стенкой и центром полости. V_min = −720 мВ (Табл. 8.1, с. 248) соответствует ΔT ≈ 200 K, что сравнимо с перепадом 70–100 K у отверстия, если учесть локальный теплоотвод по стержню зонда. **Знак тоже сходится:** более холодный зонд эмитирует меньше, собирает избыток электронов и заряжается отрицательно. Авторы видели именно это: «the tantalum probe begins to develop a negative potential» (с. 249).

Дополнительный довод (мой анализ Табл. 8.1). Величины V_PW **не коррелируют с разностью работ выхода**. У LaB₆/Ta (Φ = 2.66 против 4.2 В) получено +140/−64 мВ, у Ta/Ta +56/−720 мВ. Если бы эффект был внутренним равновесным свойством оболочек, порядок величин определялся бы ΔΦ. На деле картина такая, какую дают неконтролируемые температурные и газовые неоднородности.

**Внутренняя арифметика.** Для Эксп. 7 приведено «RL = 3.3Ω and IL = 17.5µA», P_L = 9.3×10⁻¹¹ Вт (с. 250). Но I²R = 1.0×10⁻⁹ Вт, расхождение в 11 раз. dS/dt = 5.4×10⁻¹⁴ Вт/К посчитано из неверного P. Кроме того, V_L = I·R_L = 58 мкВ, это на 3–4 порядка меньше V_PW (сотни мВ). Значит, почти всё напряжение падает не на «нагрузке». Оценка 1200 Вт / 2.73 К ≈ 440 Вт/К верна.

**Опубликованные возражения и ответ.**
* Jones [Phys. Plasmas 3, 705 (1996)]: (i) температурные градиенты, (ii) холодные атомы из отверстия, (iii) термо-ЭДС. Ответ Шиэна (там же, 706) в книге только упомянут. Сами авторы признают: «Jones' suggested systematic errors of this magnitude cannot be ruled out, and more conclusive experiments should be conducted» (с. 262). Моя оценка выше показывает, что возражение (i) **количественно достаточно**. Зеебек по Ta-выводам, наоборот, мал (S_Ta ~ мкВ/К × ΔT ~ 50 K → < 1 мВ), и тут авторы правы.
* Cruden [Phys. Plasmas 8, 5323 (2001)]: первый закон (8.19)–(8.20) и анализ зонда. Цитата: «Sheehan made no formal response in the open literature» (с. 262). Ответ дан только в книге, через схему 8.8b; см. п. 3, он неубедителен.
* Итог авторов: «These criticisms are serious but inconclusive» (с. 262).

**Экспериментальный статус.** Измерено: V_PW ≠ 0 (до −720 мВ), квазистационарность ~20 мин при ≈ −150 мВ, падение R_PW от >300 кОм до 40 Ом. Нарушения второго начала не заявлено: авторы оговаривают «were the universe at T = 1710 K, were no vacuum, ancillary apparatus, or experimenter required» (с. 250). Условия неравновесны (ΔT, внешний пучок K, открытая полость).

**Вердикт: (а), ошибка найдена.** V_f = 0 в равновесии следует из (8.1) и Саха–Ленгмюра (W = 1 для контура зонд–стенка). Авторы подставили формулы для неравновесных зондов. Наблюдённое V_PW количественно объясняется измеренными самими авторами ΔT = 5–100+ K; это скрытый внешний источник, тепловой поток.

### 1.2 Plasma II (§8.3, с. 251–262)

**Суть модели.** Поршень в чёрнотельной полости с плазмой K. Большая часть поршня из материала стен (S1, Hf, Φ = 3.5 В), на одной грани есть пятно S2 (W, Φ = 4.5 В), причём Φ₂ ≳ I.P. > Φ₁. S2 лучше ионизует K, а S1 сильнее эмитирует электроны. Уходящие потоки ионов, электронов и нейтралов различаются, и авторы получают стационарную разность давлений ΔF ≠ 0.

Ключевые уравнения:
* (8.3)–(8.4), Саха–Ленгмюр: n_i/n_n = (g_i/g_n) exp[e(Φ − I.P.)/kT], P_i = [1 + (g_n/g_i) e^{e(I.P.−Φ)/kT}]⁻¹.
* (8.5)–(8.6): j⃗_i,k = P_i,k j⃖_B,k, с пометкой «From the principle of detailed balance, one can infer that, in steady state» (с. 253).
* (8.7): j⃗_e,k = J_R,k exp(eV_pl/kT). **Один и тот же V_pl для обеих поверхностей.** То же в (8.10)–(8.16): «The velocity distributions for S1 and S2 are distinguished only by their work functions which fold into JR,k» (с. 255).
* (8.17)–(8.18): ΔF_net. В Табл. 8.2 (с. 258) при T = 2200 K: ΔF_n = −4.8·10⁻⁵, ΔF_e = −6.3·10⁻⁷, ΔF_i = +1.8·10⁻⁴, итого ΔF_net = +1.3·10⁻⁴ Па, мощность 6·10⁻⁷ Вт. Арифметику (P_i,1 = 7.3·10⁻³, P_i,2 = 0.59, ΔF_n, ΔF_i, ΔF_e) я пересчитал, она **внутренне согласована**.
* Физическая мотивировка: «equipartition of energy does not imply equipartition of linear momentum» (с. 256).

**Откуда, по авторам, нарушение.** Из различия работ выхода. По их словам, ΔF исчезает только при Φ₁ = Φ₂.

**Критический анализ.**

1. **Пропущена контактная (патч-)разность потенциалов.** Поршень заземлён, поэтому уровни Ферми S1 и S2 совпадают. Тогда вакуумный уровень над S2 ниже, чем над S1, на ΔΦ/e = 1.0 В: это стандартные патч-поля, их измеряет зонд Кельвина. Уходящие с S2 ионы ускоряются только на |V_pl| − ΔΦ = 1.1 В, а не на 2.1 В. До поверхностей типа S1 (там потенциальная энергия иона 0) доходит только доля exp(−eΔΦ/kT) ионов с S2, остальные отражаются и возвращаются на S2. Утверждение «the excess ions are effectively neutralized on a type-1 surface after a single pass» (с. 256) поэтому неверно. Для электронов всё зеркально: барьер над S2 на ΔΦ ниже. Проверка (моя):

```python
kT=8.617e-5*2200
Pi=lambda Phi: 1/(1+2*np.exp((4.3-Phi)/kT))
r1,r2=[Pi(F)/(1-Pi(F)) for F in (3.5,4.5)]
print(Pi(4.5)/Pi(3.5))                 # 80.8  — «асимметрия» Шиэна
print(r2/r1, np.exp(1.0/kT))           # 195.4 = e^{ΔΦ/kT}  (Саха–Ленгмюр)
print(r2/r1*np.exp(-1.0/kT))           # 1.000 — уходящий в плазму ионный поток S2/S1
print(np.exp(-1/kT)*np.exp(1/kT))      # 1.000 — то же для электронов
```

   Общий вид сокращения такой. «Плотностный параметр» ν = n_s·exp(z e φ_s/kT) одинаков для всех поверхностей, потому что по Саха–Ленгмюру n_s ∝ e^{±eΦ/kT}, а φ_s = −(E_F + Φ)/e. Это и есть равенство электрохимических потенциалов, т.е. **W = 1**. У Шиэна в контуре «нейтрал → ион на S2 → ион в газе → нейтрал на S1» W_eff = e^{eΔΦ/kT} ≈ 195. Нарушение Вегшайдера возникло из-за общего V_pl, поставленного в (8.7)/(8.14).
2. **Общая теорема, без кинетики.** Пусть полость, газ и поршень находятся в гиббсовском состоянии (стены при одной T, кернели поверхностей удовлетворяют реципрокности/микрообратимости). Тогда средняя сила на координату поршня X равна ⟨F_X⟩ = −∂F/∂X. При сдвиге поршня вдоль трансляционно-инвариантной полости или по тору (такие варианты предложены на с. 257) имеем ∂F/∂X = 0, поэтому ∮⟨F_X⟩dX = 0. Тезис о «неравнораспределении импульса» в равновесии не работает: полный тензор потока импульса (кинетический плюс максвелловский) бездивергентен, и сила электрического поля патча на заряды поверхности компенсирует разницу кинетических потоков.
3. **Ответ авторов на «resolutions» (с. 264).** Шиэн отвергает (1) «все работы выхода эффективно равны» словами «Resolution (1) is not supported either by theory or experiment». Правильная формулировка другая: равны не Φ, а **эффективные барьеры с учётом контактного поля**, т.е. электрохимические потенциалы. Это следует из той же термодинамики, из которой Ричардсон выводил универсальность A. Варианты (2) и (3) авторы называют «no motivation aside from preservation of the second law, which begs the question» (с. 264). Механизм (п. 1) конкретен и не требует постулата.

**Эксперимент (§8.3.2).** Давления не мерились. Цитата: «there does not appear to be any unambiguous experimental evidence for it» (с. 258). Радиометрические опыты «deemed inconclusive due to confounding effects of outgassing, temperature, and thermal gradients» (с. 258). Измерены дифференциальные токи зондов ΔI ~ 100 мкА для пар Ta/Hf и Ta/ZrO₂ против ≈ 0 для Ta/Ta и Hf/Hf (Рис. 8.7, с. 261). Но в равновесии ток любого зонда на землю равен 0, так что ненулевой ΔI свидетельствует о неравновесности (ΔT, дегазация: «Differential current values on successive thermal cycles were smaller, probably due to outgassing», с. 261). Критерий «разные давления над поверхностями» эти опыты не проверяют.

**Вердикт: (а).** Пропущена вольта/патч-разность ΔΦ/e. С ней уходящие потоки обоих видов заряженных частиц равны, W = 1 и ΔF = 0. Это тот же структурный дефект, что в Plasma I и у твердотельных устройств (см. §4).

### 1.3 Звёздное применение (с. 264–265)

Предложение: «sealed tungsten cavity … buried shallowly in a red dwarf star». Оно наследует ошибку §1.1–1.2. Замечание о космологии («Sadly, the universe has simply cooled below the temperature required», с. 265) прямо зависит от ошибочного V_f ≠ 0.

## 2. Глава 9. MEMS/NEMS Devices

### 2.1 Thermal capacitors (§9.2, с. 268–276)

**Суть модели.** Две П-образные половины, n и p (Рис. 9.1): в J-I они в контакте, в J-II разделены вакуумным зазором x_g ≪ x_dr. В равновесии на зазоре J-II висит V_bi. Это следует из контурного правила: «there must be a counter-potential somewhere else in the loop» (с. 270). Стандартное устройство: N = 10²¹ м⁻³, x_dr = 1.2 мкм, x_g = 30 нм, V_bi ≈ 0.6 В.

* (9.1) V_bi = (kT/q) ln(N_A N_D/n_i²); (9.2) x_dr = [2κε₀V_bi(N_A+N_D)/(qN_AN_D)]^{1/2}.
* (9.3) ΔE_es ≃ (ε₀/2)[x_dr(kT/q)ln(N_AN_D/n_i²)]²·[1/x_g − κ/(3x_dr)] (с. 272, проверено по картинке).
* По авторам, устройство «can remain energized indefinitely; they can also recharge thermally under appropriate circumstances» (с. 269). Энергия разряда ≈ 5.2·10⁻¹⁷ Дж ≈ 320 эВ.

**Проверки (мои).** V_bi = 0.586 В и x_dr = 1.24 мкм совпадают с книгой. (9.3) даёт 7.0·10⁻¹⁷ Дж (книга 5.2·10⁻¹⁷), это в пределах грубости модели. Размерность (9.3): ε₀V²x_dr²/x_g [Дж], т.е. неявно взята площадь ≈ x_dr². Порог x_g = 3x_dr/κ ≈ 0.31 мкм ≈ x_dr/4 совпадает. Энергия ≈ 1.7·10⁴ kT, флуктуации тут ни при чём.

**Что верно.** Поле в зазоре J-II в равновесии существует. Это контактная (вольта) разность, физически то же, что поле между двумя разными металлами с зазором (принцип зонда Кельвина). Энергия поля реальна, и при замыкании зазора она частично выделяется: «simply the relaxation of the system from a higher to a lower energy equilibrium state» (с. 272).

**Где ошибка.**
1. **V_bi — это не ЭДС.** Авторы сами пишут: «in the depletion region, a balance is struck between electrostatic and chemical potentials» (с. 306). Электрохимический потенциал однороден, и сумма скачков μ̃ по любому замкнутому контуру равна 0. Это закон напряжений Вольты, т.е. Кирхгоф для μ̃ и Вегшайдер для зарядов.
2. **«Thermally recharge» = повторное открытие зазора, и работа на него не посчитана.** Ни в §9.2, ни дальше нет расчёта работы на разведение замкнутого J-II (нет в тексте). При замыкании образуется новый p-n-переход: «the electric field and electrostatic energy in the gap is lost upon gap closure as a new depletion region forms» (с. 298–299). Его заряды обеднения при разведении остаются на поверхностях, и разводить их приходится против притяжения. Состояния «открыто» и «закрыто» равновесны при заданной геометрии, поэтому существует однозначная функция F(x_g). Работа за цикл ≤ −∮dF = 0. При конечной скорости разница уходит в диссипацию.
3. **Энергия ≠ свободная энергия.** Везде используется электростатическая энергия E_es (Рис. 9.3–9.5, 9.10), а не F = E_es + F_chem(носителей). Обеднённый слой образуется именно потому, что выигрыш в F_chem больше проигрыша в E_es. Поэтому «ΔE_es» не равна максимальной работе.

**Вердикт по «тепловому конденсатору» как объекту: (б), это корректная равновесная физика** (заряженный контактной разностью конденсатор). **Как источнику работы: (а).** Ошибка в шаге «recharge thermally» без учёта работы на повторное разделение и встречного перехода при контакте.

**Связь с ноутбуком `capacitor_self_charge.ipynb`.** В рабочем каталоге сессии этого файла нет: поиск `*.ipynb` дал `weg*.ipynb`, `kin.ipynb`, `sup*.ipynb` и др., но не его. Поэтому связь описываю по смыслу, а содержание ноутбука проверить не мог. Тепловой конденсатор гл. 9 — это **не «самозаряд»** в смысле накопления работы. Это равновесный заряд q_eq = C·V_CPD (у Шиэна V_bi) с тепловым разбросом ⟨δq²⟩ = kTC. В любой модели «самозаряжающегося конденсатора» должны выполняться четыре проверки:
* (i) средний заряд выходит на q_eq = C·V_CPD, а не растёт без предела;
* (ii) при подключении нагрузки постоянный ток ⟨I⟩ = 0;
* (iii) шум резистора удовлетворяет 4kTR, и тогда ФДТ выполнена;
* (iv) сумма контактных ЭДС по контуру, включая место механического контакта, равна 0 (W = 1).

Если ноутбук моделирует разряд через «чистое» замыкание (короткое без встречного перехода), в него неявно встроена батарейка с ЭДС V_CPD. Это та же ошибка, что у hammer-anvil (см. численный пример в §2.3). Предлагаю добавить в ноутбук функцию Ляпунова H = p²/2m + F(y,q) и проверить, что dH/dt ≤ 0.

### 2.2 Linear electrostatic motor (LEM) (§9.3, с. 277–291)

**Суть модели.** Полупроводниковый диэлектрический «поршень» в канале J-II локально закорачивает поле. Впереди поле сильнее, сзади слабее, и поршень, по словам авторов, «perpetually 'surfs' an electrostatic wave that it itself creates» (с. 277).
* (9.5) a_es ≃ (ε−ε₀)/(2l_yρ)·(E₁² − E₂²). Размерность верна: [Дж/м³]/[кг/м²] = м/с². Численно (моё) a_es = 6.5·10⁷ м/с² при (α₁²−α₂²) = 0.5, совпадает с книгой (6.7·10⁷).
* (9.6) a_es = (ε−ε₀)/(2ρl_y)·E₀²·e^{−βη}(1 − e^{−η}), η = 2σl_y/(εv_y) (безразмерно, проверено). β назван «a phenomenological constant that is a measure of how far ahead of the moving piston the electric field is affected» (с. 280), взято β = 0.1.
* RC-аналог (Рис. 9.9) **питается батареей V_s**: «As long as it overcomes friction, the piston will run perpetually for the life of the battery» (с. 284). Затем делается ключевой шаг: «Via the substitution Vs → Vbi, the piston in Figures 9.9 and 9.10 may now be identified as the semiconductor piston in Case 3» (с. 284).
* Вывод: «Since the device operates in a thermodynamic cycle, heat is transformed solely into work, in violation of the second law» (с. 286).

**Критический анализ.**
1. **Подстановка V_s → V_bi и есть скрытый источник.** В RC-цепочке энергию даёт батарея. Встроенный потенциал — контактная разность с нулевой контурной ЭДС (§2.1, п. 1), поэтому замена батареи на V_bi меняет W ≠ 1 на W = 1. Это ровно пункт (1) нашего критерия: кинетическая асимметрия (быстрый разряд, медленная перезарядка) без W ≠ 1 тока не даёт.
2. **Модель (9.6) построена на J = σE без диффузии.** В p-n-структуре равновесие держится балансом дрейфа и диффузии с эйнштейновским D = μkT/q. Это соотношение — частный случай ФДТ. Модель, в которой есть дрейф по равновесному полю, а диффузионного противотока нет, нарушает детальное равновесие по построению.
3. **Собственная 2-D симуляция авторов противоречит «неустойчивому равновесию».** На Рис. 9.10 (с. 285, проверено по картинке) полная энергия падает от ≈ 16 до ≈ 13·10⁻¹² Дж/м к середине канала. Авторы пишут: «decrease significantly and symmetrically as the piston enters the channel from either direction» (с. 286) и «should reside in a potential well approximately 3 × 10⁻¹⁸ J deep» (с. 286). **Минимум энергии означает устойчивое равновесие.** Тем не менее на с. 285 утверждается: «a resting piston would experience roughly no net force, but it would be in the unstable equilibrium position». Глубина ямы 3·10⁻¹⁸ Дж ≈ 700 kT, т.е. поршень заперт. В квазистатике сила консервативна (−∂F/∂y), и шарик в чаше качается без подкачки. Конечное запаздывание («поле восстанавливается позади») в пассивной системе с гиббсовским равновесием даёт только трение (Im χ ≥ 0), а не антизатухание.
4. **Динамики не моделировали.** Цитата: «It is strongly emphasized that this is not a dynamical simulation in which the piston is modeled as moving» (с. 284). Все 2-D результаты — равновесные решения Atlas. Движение выводится только из 1-D феноменологии с β и батареей.
5. **Флуктуации** («statistical fluctuations should not play a primary role», с. 290) — отвлекающий довод. Ошибка не флуктуационная, а в средней силе.

**Мелкие числовые несоответствия (мои проверки):**
* F_s «< 2.3 × 10¹⁴ N/atom» (с. 287) — опечатка, должно быть 10⁻¹⁴.
* Средняя скорость √(2L_y a_p) = 6.2 м/с, а не «≃ 2 m/s» (с. 289), и τ_osc ≈ 1·10⁻⁷ с.
* ΔQ_rms = √(4RC²kTΔf) = 5.7e (книга: «≃ 2»); √(kTC) = 4e. Порядок вывода (<2% от 330 e) не меняется.
* ⟨P⟩ = m√(2a³L_y) = 1.7·10⁻⁹ Вт (книга 2·10⁻⁹) — сходится. R_b = 1.25·10⁸ Ом — сходится.

**Экспериментальный статус.** Нет. Цитата: «We predict laboratory tests for the LEM will become feasible within 5 years» (с. 300). Сведений о проведённых тестах в книге нет.

**Вердикт: (а).** Скрытый источник — батарея RC-аналога, переименованная в V_bi. Квазистатическая сила по собственным расчётам авторов возвращающая (потенциальная яма).

### 2.3 Hammer-anvil (§9.4, с. 291–300)

**Суть модели.** Полупроводниковый плоский конденсатор: «молот» на двойном кантилевере, «наковальня» неподвижна. При τ_e ~ τ_m и большой Q_m авторы ожидают резонансные автоколебания с питанием от V_bi.
* (9.11) C(y) = ε₀A/(y_gap − y).
* (9.12) mÿ = −(1/Q)ẏ − ky − q²/(2ε₀A). Член −(1/Q)ẏ **размерно неверен**: Q безразмерна, нужно −(mω₀/Q)ẏ.
* (9.13) q̇ = (V_o − q(y_gap − y)/(ε₀A))/R, где q̇ = 0 при q ≥ q_sat.
* (9.16)–(9.17) — решение «for homogeneous initial conditions», т.е. q(0) = 0 в момент контакта (с. 296). (9.18) ΔE_es = ∫q²/(2ε₀)[−(1/τ_m)y_gap sin(t/τ_m)]dt; аргумент синуса должен быть 2πt/τ_m (опечатка, проверено по картинке). (9.19) ΔE_diss ≃ πky²_gap/Q_m.
* (9.24) — критерий (Q/η)·(P_es/P_vdW) > 1.
* Макро-модель: «power supply (500 V ≤ Vo ≤ 2000V)», R = 5·10⁴ – 2·10⁷ Ом (с. 293–294). Для микроверсии: «Note it should be viable using Vo = Vbi ≃ 0.6V» (с. 299).

**Критический анализ.**
1. **Макромодель — это обычный электрический звонок (прерыватель Вагнера) с источником 0.5–2 кВ.** Её работа ничего не говорит о тепловом питании. Авторы сами пишут, что она «converting electrical into mechanical energy» (с. 293).
2. **Гладкая динамика (9.12)–(9.13) даже с настоящей батареей не автоколеблется.** Функция Ляпунова H = p²/2m + ky²/2 + q²/2C(y) − V_o q удовлетворяет dH/dt = −γp²/m − (V_o − q/C)²/R ≤ 0 (мой вывод). Положительный ΔE_es в (9.18) возникает **только из-за сброса q → 0 при контакте**, т.е. из начального условия (9.17). Сброс означает, что заряд прошёл через контакт мимо батареи. С батареей это оплачивается её работой. С V_bi это означает, что при контакте нет встречного перехода. Но авторы сами пишут, что при смыкании образуется «a new depletion region» (с. 299), т.е. встречная контактная ЭДС, и сумма по контуру равна 0. Сброса нет, и подкачки нет.
3. **Проверка на численной игрушке (моя).** Безразмерные единицы m = k = ε₀A = y_gap = 1, C(y) = 1/(1 − y + 0.02), насыщение q_sat (как в книге), Q = 1000, упругий удар с e = 0.98. Сравниваются две ветви контакта:
   * «battery»: контакт — чистое короткое (ЭДС 0), источник V_o в колонке; это модель книги;
   * «cpd»: контакт — встречный переход с той же ЭДС V_o, т.е. сумма ЭДС по контуру = 0, W = 1.

```python
def sim3(mode,T_end=1500,dt=1e-3,V0=0.6,R=3.0,Q=1000.,ymin=0.02,rest=0.98,qsat=0.6,v0=1.05):
    y,v=0.,v0; q=V0/(1+ymin); b=1/Q; Esrc=0.; hits=0; ys=[]
    for i in range(int(T_end/dt)):
        C=1/(1-y+ymin); I1=(V0-q/C)/R; dq=I1*dt
        if q>=qsat and dq>0: dq=0; I1=0
        v+=(-y-b*v+q*q/2)*dt; y+=v*dt; q+=dq; Esrc+=V0*I1*dt
        if y>1:
            y=1; v=-rest*abs(v); hits+=1
            q = 0.0 if mode=='battery' else min(V0/ymin,qsat)   # короткое vs встречный переход
        if i*dt>1400: ys.append(y)
    return min(ys),max(ys),hits,Esrc
# battery R=1: y∈[-1.77,1.00], ударов 350, работа источника 121
# battery R=3: y∈[-1.92,0.91], ударов 355, работа источника  74
# cpd     R=1: y∈[0.08,0.28],  ударов 3,   работа источника 0.01   → затухает
# cpd     R=3: y∈[0.08,0.28],  ударов 2,   работа источника 0.00   → затухает
```

   Автоколебания есть только тогда, когда источник реально совершает работу (∫V_o I dt ≫ 0). При W = 1 (контактная разность вместо ЭДС) колебания затухают за 2–3 удара. Это просто численная иллюстрация теоремы из п. 2. Тот же механизм у зонда Кельвина: при вибрации обкладки в контактном поле механическая работа расходуется на джоулево тепло в цепи, и самовозбуждения нет. Это известная практика (не из книги).
4. **Время зарядки.** Цитата: «τe = RCo need not be an RC time constant … rather it will likely be set by microscopic thermal processes» (с. 296). Оно задаётся генерацией-рекомбинацией. В равновесии эти процессы подчиняются детальному балансу (W = 1), и постоянного тока через диодные колонки нет: I = I_s(e^{qV₁/kT} − 1) через колонку и встречный переход при контакте дают только I = 0 при нулевой суммарной ЭДС (моя проверка уравнений двух диодов в кольце).
5. **Нужен «kick start»:** «will almost certainly require a kick start» (с. 299). Это не опровергает модель, но показывает, что её автоколебательная устойчивость не продемонстрирована.

**Экспериментальный статус.** Макромодель работала от высоковольтного источника, Рис. 9.14 [ref 19: unpublished data]. Микроустройство не построено: «tests of the hammer-anvil concept are feasible today» (с. 300). Результатов в книге нет.

**Вердикт: (а).** Энергия цикла по (9.17)–(9.18) берётся из сброса заряда при контакте. Этот сброс эквивалентен батарее с ЭДС V_bi, т.е. W = e^{qV_bi/kT} ≈ e²³ вместо 1. Встречный переход при контакте, который авторы сами упоминают, уничтожает эффект.

## 3. Глава 10. Special Topics

### 3.1 Macroscopic potential gradients (MPG) (§10.1.1, с. 304–306)

**Общая схема Шиэна.** Каждый «USD challenge» состоит из четырёх частей: (i) чёрнотельная полость в термостате; (ii) рабочее тело; (iii) механизм отбора работы; (iv) **равновесный MPG**. Цикл устроен так: тело «падает» по MPG и создаёт направленный поток, совершая работу, а возвращается «via thermal processes (e.g., diffusion, evaporation)» (с. 305). Ключевые фразы:
* «equilibrium MPG derive their energy from purely thermal processes (or none at all)» (с. 305);
* «They differ from their nonequilibrium counterparts only in that they are generated and maintained under equilibrium conditions» (с. 306);
* про гравитационный случай: «No thermodynamic processes are required to sustain this MPG» (с. 306).

Табл. 10.1 (с. 304, с картинки) даёт оценки плотности мощности (Вт/м³): Plasma I и II по 10⁻² (T > 1500 K, P < 10⁻³ Торр), Chemical 10⁻³, Gravitational 10⁻⁹, Solid State >10⁸.

**Общий слабый пункт класса MPG** (мой анализ, тут сходится всё разобранное выше):
1. В гиббсовском равновесии однороден не электростатический (или гравитационный) потенциал, а **полный** потенциал каждого сорта: μ̃_j = μ_j^chem + z_j eφ + m_j g h = const. «MPG» ∇φ (или g) в каждой точке ровно компенсирован ∇μ^chem: дрейф плюс диффузия дают 0. Авторы сами это признают для p-n: «a balance is struck between electrostatic and chemical potentials» (с. 306).
2. «Падение» тела по MPG и его «тепловой возврат» — это **один и тот же транспортный процесс в двух направлениях**. Работа, полученная на первой ветви, равна свободной энергии, затраченной на второй: ∮dμ̃ = 0. Для контура это **Вегшайдер / закон Вольты / Кирхгоф для μ̃**: произведение констант по циклу W = exp(−∮dμ̃/kT) = 1.
3. Во всех моделях Шиэна ветви считаются **разными, несогласованными эффективными законами**, и поэтому W_eff ≠ 1 появляется по построению:

| Модель | «Падение» считается по… | «Возврат» считается по… | Что пропущено | W_eff |
|---|---|---|---|---|
| Plasma I | V_pl, формулы холодного или горячего зонда | Ричардсон (8.1) для стенки | зонд = кусок стенки ⇒ V_f = 0 | ≠1 по ΔT в эксперименте |
| Plasma II | общий V_pl для S1 и S2 | Саха–Ленгмюр (8.3) | вольта/патч-разность ΔΦ/e | e^{eΔΦ/kT} ≈ 195 |
| Thermal cap / LEM | V_bi как ЭДС (V_s → V_bi) | «thermal recharge» | встречный переход при контакте; работа на разведение | e^{qV_bi/kT} ≈ e²³ |
| Hammer-anvil | V_o = V_bi в (9.13) | сброс q → 0 при контакте (9.17) | то же | то же |
| Gravitator (гл. 6; здесь только по с. 306) | падение в поле g | испарение/диффузия | барометрический ∇n как компенсирующий ∇μ | по гл. 6 |
| Chemical (гл. 7; здесь только по с. 305) | разные P_dissoc у S1/S2 | газофазный обмен | реципрокность кернелей обеих поверхностей к одному гиббсовскому газу | по гл. 7 |

   DSPG в главах 8–10 не описан (нет в тексте), в Табл. 10.1 его нет. Его, как гравитатор и химическую модель, надо проверять тем же тестом в разборе гл. 6–7. Вопрос всегда один: удовлетворяют ли все граничные кернели детальному балансу по отношению к **одному** гиббсовскому состоянию?
4. **Неэкстенсивность и подход Gross (с. 306) не спасают.** Пассивность гиббсовского состояния (никакой циклический гамильтонов процесс не извлекает работу) и тождество ⟨F_X⟩ = −∂F/∂X выполняются для **любого** конечного N и любых границ. Термодинамический предел для них не нужен. Ссылка на «Microcanonical approaches … might be more fruitful» (с. 306) — это пожелание, а не довод.
5. **Связь с нашими пунктами (1)–(3).** MPG-устройства — это ровно «кинетический выпрямитель при W = 1». Асимметрия границ есть, но все её «обходы» замыкаются через равновесный μ̃. Шум в них внутренний, т.е. испытывает обратное влияние, так что пункт (2) не срабатывает. ФДТ (эйнштейновское D = μkT/q, реципрокность кернелей) в моделях Шиэна каждый раз нарушена эффективным описанием, а не физикой. Это пункт (3): постулат гиббсовости термостата и границ используется неявно, когда он удобен, и отбрасывается на «возвратной» ветви.

**Вердикт по MPG как классу: (а).** Общий дефект: электростатический или гравитационный потенциал отождествляется с термодинамической силой, а компенсирующий химический градиент на «рабочей» ветви игнорируется. Отсюда W_eff ≠ 1 по построению.

### 3.2 Zhang–Zhang flows (§10.1.2, с. 307–308)

**Суть.** Zhang & Zhang (PRA 46, 4598, 1992): Кельвин–Планк ⇔ «in any isolated system, no spontaneous momentum flow exists» (с. 307). Теорема о несуществовании SMF для N классических частиц (10.1) при двух условиях: E(q,p) = E(q,−p) и инвариантность фазового объёма. Пример — частица в поле Лоренца (10.2).

**Позиция авторов:** «The several challenges in this volume stand as counterexamples to this claim» (с. 308) и «rather than refuting them, it gives insight into their common basis» (с. 308).

**Критика (моя).** Это логическая непоследовательность. Микроскопическая динамика всех USD-систем — кулоновские и гравитационные взаимодействия ядер и электронов, т.е. гамильтонова система, чётная по p и с сохранением фазового объёма. **Обе посылки теоремы выполнены.** Значит, если эти системы дают SMF, то неверна либо теорема (это строгий результат), либо эффективные модели. Теорема прямо **указывает место ошибки**: эффективные граничные условия Шиэна сжимают фазовый объём, т.е. нарушают реципрокность. Это поверхностные вероятности без обратных процессов, закон Ома без диффузии, «сброс» заряда при контакте. Итог: SMF ⇔ W ≠ 1 ⇔ нарушение лиувиллевости эффективной модели. Квантовая версия теоремы, по книге, «has not been pursued» (с. 307), но устройства гл. 8–9 полуклассические.

**Вердикт: (а).** Теорема Zhang–Zhang скорее опровергает классические USD-модели, чем «объясняет» их.

### 3.3 Thermosynthetic life (§10.2, с. 308–319)

**Суть.** Мембранный конденсатор (d = 100 нм, V_m = 0.8 В). Заряды диффундируют «вверх» по пирамиде переносчиков, с вершины (1 молекула) к основанию (10⁶ молекул), где их ведёт кратность состояний. Затем они падают по проводящей «лестнице» через реакционный центр и совершают химическую работу (≈ ATP).
* (10.3) p_rel ≃ (g_base/g_vertex)·exp(−ΔE/kT), где g-отношение = 10⁶ и ΔE = 0.8 эВ.
* Ключевое утверждение: «detailed balance need not — and in this case, does not — apply» (с. 316). Обоснование: процесс «inherently nonequilibrium (a 0.8eV electrons driving a chemical reaction)».

**Критика.**
1. **Это прямое и явное отрицание детального баланса без механизма.** Цикл «вершина → основание (диффузия) → лестница + реакция A → B → вершина» возвращает заряд в исходное состояние. Значит, вся машина — **катализатор** реакции A ⇌ B, а катализатор не сдвигает равновесие: Вегшайдер, W = 1. Сделать лестницу «molecular electronic diode» — это кинетическая асимметрия при W = 1 (наш п. 1), и тока при Δμ_chem = 0 она не даёт. Сами авторы отмечают сходство с диодом Бриллюэна: «this biochemical diode bears resemblance to the solid state diode considered by Brillouin» (с. 317). Отговорка «relies on quantum molecular processes» не работает: квантовая микрообратимость тоже даёт детальный баланс для переходов в равновесии с термостатом (KMS / гиббсовость бани, наш п. 3).
2. **Кратность в пирамиде не помогает.** Лестница стыкуется с **одним** узлом основания, и вероятность заселения именно этого узла равна p_rel/10⁶ = e^{−ΔE/kT}. Выигрыш в кратности теряется. Свободная энергия заряда в основании относительно вершины: ΔF = 0.8 − kT·ln10⁶ = +0.32 эВ при 400 K (моё). Работы при обратном спуске больше этой величины не получить, а в равновесии и её съедает обратная реакция.
3. **Арифметика (мои проверки):**
   * p_rel(400 K) = 10⁶·e^{−0.8/0.0345} = 8.3·10⁻⁵, а не «∼10⁻³» (с. 315). При 300 K выходит 3.6·10⁻⁸, совпадает с «4×10⁻⁸».
   * P_m = p_rel N_q ΔE/τ = 1.1·10⁻¹⁶ Вт (книга 2·10⁻¹⁶): с p_rel = 10⁻³ книжное P_m не согласовано, с моим согласовано.
   * σ_max = κε₀E_max = 2.7·10⁻⁴ Кл/м², а не «2.5 × 10⁴ C/m²» (опечатка на 10⁸). Значение 1.5·10³ e/мкм² сходится.

**Эксперимент:** «there is no experimental evidence that life violates the second law in the least» (с. 308). Прогноз авторов: «we predict that thermosynthetic life will be discovered in the deep subsurface realm» (с. 319). Предложенный тест (организмы без отходов в бедной породе) почти неопровержим: отсутствие находки ничего не доказывает.

**Вердикт: (а).** Нарушение детального баланса постулировано («does not apply»). Устройство по построению — катализатор при W = 1.

### 3.4 Physical eschatology (§10.3, с. 319–327)

**Суть.** Обзор эпох (Adams–Laughlin), энтропийного бюджета (Табл. 10.2, по Frautschi) и сценариев «Matrix», «Outpost», «Thermal Life», которые работают при условии нарушимости второго начала.

**Проверки (мои):**
* (10.6) T_H = 6.17·10⁻⁸ K для M_⊙ — верно.
* (10.4) S_BH/k = 1.05·10⁷⁷ — верно.
* **(10.7) τ_H ≃ 16π²GM³/(ħc³) размерно неверна** (с. 324, проверено по картинке). Комбинация GM³/(ħc³) имеет размерность кг·с²/м², а не время. Правильно τ ≈ 5120πG²M³/(ħc⁴) ≈ 2·10⁶⁷ лет для M_⊙; книга даёт 10⁶² лет.
* «Matrix»: N_s ∼ N_b r²/(nR²) = 10⁶ при N_b = 10⁷⁹, r = 1 Å, n = 10, R = 10²⁶ м, расстояние между перегородками ~10⁴ св. лет — арифметика верна. Но это целиком условная конструкция: «if these partitions were antennae and second law violators».

**Вердикт: вне физической проверки.** Раздел целиком условен на результатах §1–3.3 и не содержит самостоятельных доводов против второго начала. Авторы сами пишут: «make eschatological studies largely moot» (с. 327). Ошибки размерности в (10.7) — частные.

### 3.5 The Second Law Mystique (§10.4, с. 327–330)

Подборка цитат (Эйнштейн, Эддингтон, Ферми, Клаузиус, Максвелл, Lieb–Yngvason и др.) и литература. Тезисы авторов: «it has become a sociological neurosis of Western civilization» (с. 321) и «It has been a goal of this volume to shake this faith» (с. 330).

**Критика.** Риторика, физической заявки нет. Утверждение, что вера во второе начало «ultimately, is also rooted in faith» (с. 330), неверно описывает его статус. Второе начало в изотермической постановке — это **теорема** для гиббсовских начальных состояний бани (пассивность, ФДТ, детальный баланс) плюс эмпирика. Разобранные модели гл. 8–10 нарушают именно эти математически проверяемые условия. Дело не в «вере».

## 5. Общий вывод

1. Все работоспособные модели гл. 8–10 — это варианты одной схемы MPG: «падение» рабочего тела по равновесному электростатическому (гравитационному) градиенту и «тепловой возврат». Ошибка у них общая: термодинамической силой считается ∇φ, а не ∇μ̃. В равновесии ∇μ̃ = 0, и ∮dμ̃ = 0, т.е. W = 1.
2. В каждой модели W_eff ≠ 1 вносится конкретным шагом, и его можно указать. Plasma I: формулы неравновесных зондов. Plasma II: общий V_pl без патч-разности ΔΦ/e (W = e^{eΔΦ/kT} ≈ 195). Твердотельные устройства: V_bi трактуется как ЭДС (V_s → V_bi; сброс q → 0 при контакте), W = e^{qV_bi/kT}.
3. С учётом пропущенного элемента эффект исчезает **точно**, а не приближённо. Это видно в моих численных проверках: равенство уходящих потоков в Plasma II (1.000) и затухание hammer-anvil при нулевой контурной ЭДС.
4. Единственное измеренное «аномальное» явление — V_PW ≠ 0 в Plasma I. Оно количественно и по знаку согласуется с перепадами температуры 5–100+ K, которые измерили сами авторы. Это неизотермичность, т.е. внешний источник.
5. Теорема Zhang–Zhang, которую книга приводит в свою поддержку, при честном применении опровергает классические USD-модели. Её посылки выполнены, значит, ошибка в нелиувиллевых эффективных граничных условиях.
6. Термосинтетическая жизнь построена на явном отказе от детального баланса и является частным случаем «катализатор не сдвигает равновесие». Эсхатология и «mystique» не содержат проверяемых заявок.
7. Сильных заявок, которые я не сумел бы опровергнуть (категория (б)), в главах 8–10 нет. Корректна только равновесная физика: оболочки, контактное поле в зазоре p-n и его энергия. Работы она не даёт.
8. Что проверить дальше: (i) гравитатор (гл. 6), DSPG и химическую модель (гл. 7) на реципрокность граничных кернелей относительно одного гиббсовского состояния; (ii) добавить в `capacitor_self_charge.ipynb` функцию Ляпунова H = p²/2m + F(y,q), проверку ⟨I⟩ = 0 при нагрузке и учёт встречной контактной ЭДС при смыкании.
