# Неполнота §105 Тамма и два гаранта асимметрии: MenDrive и сотовый Казимир
### 24 октября 2026

Фиксация общего тезиса: стандартное применение §105 (баланс импульса ЭМ-поля)
неполно для систем с ⟨S⟩=0 и асимметричными границами. MenDrive и сотовый
Казимир — два примера одного механизма. Деление ДОКАЗАНО / ТЕЗИС / ОТКРЫТО.

## 1. Суть неполноты §105 (методологически, не «Тамм ошибся»)
Полный баланс импульса ЭМ-поля (§105):
    ∇·T = ∂g/∂t + f_vol,   g = S/c² = (1/4πc)[E×H].
Для систем со СТОЯЧЕЙ волной или нулевыми колебаниями среднее ⟨S⟩≈0, значит
⟨∂g/∂t⟩=0 в установившемся режиме. Тогда весь несбалансированный импульс
сидит в ПОВЕРХНОСТНОМ интеграле тензора натяжений ∮⟨T⟩·da, а НЕ в потоке
Пойнтинга. Школьное применение §105 (импульс = g=S/c²) этот член опускает.
ТОЧНАЯ формулировка: «стандартное ПРИМЕНЕНИЕ §105 неполно», а не «Тамм ошибся»
(в полном тензорном виде член есть).

## 2. Строгий выбор поверхности для Казимира (отвечает на «v_сист — скорость чего»)
Для ПОКОЯЩЕЙСЯ системы слагаемое Рорлиха (переопределение импульса поля
движущегося заряда, 4/3-парадокс) вырождается — v_сист не нужна. Остаётся
чистый поверхностный интеграл по границе ВАКУУМНОЙ области.
Геометрия: пластина z=0 (соты в +z, гладкая в −z). Замкнутая pillbox-поверхность
S с гранями при z=±d В ЧИСТОМ ВАКУУМЕ, пластина целиком ВНУТРИ:
    F_z = ∮_S ⟨T_zz⟩da = [⟨T_zz⟩(+d) − ⟨T_zz⟩(−d)]·A.
⟨T_zz⟩ на сотовой грани ≠ на гладкой из-за асимметрии мод → F_z≠0.
Это поток импульса вакуумного поля через ВАКУУМНУЮ границу (не сила на вещество
напрямую). Оценка ~ħc/a⁴·(π²/720) для a~2мкм даёт порядок единиц дин/м²
(согласуется со статьёй 2024: 8.55 дин/м² при точном коэффициенте).

## 3. Два гаранта асимметрии (общий тезис)
Один механизм (∮⟨T⟩da≠0 по асимметричной вакуумной границе при ⟨S⟩=0),
два разных ГАРАНТА ненулевого интеграла:

| | MenDrive | Сотовый Казимир |
|--|----------|-----------------|
| Источник T | классическое поле (накачка) | ⟨T_μν⟩ вакуума (нулевые колебания) |
| ⟨E⟩,⟨H⟩ | ≠0 | =0 (но ⟨E²⟩,⟨H²⟩≠0) |
| Гарант асимметрии | ДИССИПАТИВНЫЙ (металл/феррит, σ_e/σ_m) | ГЕОМЕТРИЧЕСКИЙ (соты/гладкая) |
| Без гаранта | тяга→0 (функция Рэлея) | — (статика, тяга есть и без потерь) |
| Статус T | бесспорен (реальное поле) | ⟨T_μν⟩ ИЗМЕРЕН (Lamoreaux 1997) |

ВЫВОД: Казимир методологически ДАЖЕ ЧИЩЕ — опирается на экспериментально
подтверждённый ⟨T_μν⟩ вакуума, НЕ требует постулата материального эфира.
MenDrive нуждается в диссипации (без потерь ∮ по полному периоду =0);
Казимир — нет (геометрическая асимметрия статична).

## 4. Статус «импульса вакуума» — честно
В стандартной КТП ⟨P_вакуум⟩=0 (однородный вакуум). Но:
• Казимир: сила на асимметричную границу РЕАЛЬНА и измерима — спора нет,
  интерпретация «куда ушёл импульс» не влияет на величину силы.
• MenDrive: сила из реального поля — бесспорна в любой интерпретации.
«Импульс вакуума как резервуара» (материальный эфир) — это ТЕЗИС пользователя
(общий с Леоновым), нужный лишь для интерпретации «от чего отталкивается»,
но НЕ для вычисления силы. Для обеих статей достаточно ∮⟨T⟩da — величина
силы от интерпретации не зависит.
