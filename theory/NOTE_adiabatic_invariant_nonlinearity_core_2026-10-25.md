# Адиабатический инвариант, нелинейность эфира, и три пункта ядра

**Дата:** 25 октября 2026
**Контекст:** два концептуальных вопроса пользователя (адиабатичность↔инвариант;
нелинейность эфира в динамическом Казимире) + доведение трёх открытых задач
ядра (g=2, численные α/α_G, J=2 поле).

---

## ВОПРОС 1: адиабатичность и адиабатический инвариант

Пользователь справедливо указал: связь «адиабатично ⇒ мало фотонов» нужно
формулировать через АДИАБАТИЧЕСКИЙ ИНВАРИАНТ, а не расплывчато.

**Честный вывод:**
- Осциллятор ẍ+ω²(t)x=0 имеет инвариант Эренфеста **I = E/ω = ∮p dq/2π**,
  сохраняющийся при медленном изменении ω(t).
- Квантово **I/ħ = n+½**. Адиабатичность ⟺ сохранение I ⟺ n не меняется ⟺
  вакуум (n=0) остаётся вакуумом ⟺ **фотоны НЕ рождаются**.
- Рождение квантов = НАРУШЕНИЕ инварианта, только при неадиабатичности
  γ=|ω̇|/ω²≳1. При γ≪1 подавление экспоненциальное (Ландау-Дыхне, ~e^{-πωτ}).
- Дело НЕ в «числе мод» (прежняя неряшливость), а в сохранении I=ħ(n+½).

## ВОПРОС 2: нелинейность эфира в динамическом Казимире

Швингер/Степановский брали ЛИНЕЙНЫЙ осциллятор. Нелинейный эфир
(ẍ+ω²x+βx³=0) даёт три эффекта:

**Эффект 1 — адиабатическая защита ВЫЖИВАЕТ:** инвариант I=∮p dq существует
для ЛЮБОГО потенциала (общая теорема). Нелинейный эфир при адиабатическом
схлопывании тоже не рождает квантов. Вопросы 1 и 2 связаны: адиабатическая
защита вакуума УНИВЕРСАЛЬНА.

**Эффект 2 — новые каналы:** βx³ связывает моды (трёхволновое смешение
k₁+k₂→k₃, гармоники ω→2ω, параметрический распад) — у Швингера моды
независимы. Новые пути рождения при БЫСТРОМ схлопывании (γ≳1). Но для оптики
γ~1e-6 (адиабатично) → для СЛ вряд ли спасёт.

**Эффект 3 (ГЛАВНОЕ) — солитоны:** нелинейное волновое уравнение допускает
СОЛИТОНЫ (устойчивые локализованные возбуждения), которых нет в линейной
теории. Это фундамент ядра: **частица = солитон нелинейного эфира**. Линейный
эфир не удержал бы частицу (расплылась бы); нелинейность удерживает (баланс
дисперсии и нелинейности). Деформация на ядре дефекта (b/r при r~r_e) ~ O(1)
→ нелинейность СИЛЬНА именно там, где живёт частица.

→ Нелинейность эфира — НЕ для СЛ, а для ЯДРА: существование частиц как
солитонов. Вот куда её развивать.

## ЯДРО, ПУНКТ 1: g=2 (классика g=1 → Дирак g=2)

- Классическое кольцо: μ/L=q/2m → g=1 (векторная степень свободы).
- g=2 из тождества Паули (σ·π)²=π²−qħσ·B — АЛГЕБРА гамма-матриц Клиффорда,
  не подгонка. Требует СПИНОРНОЙ (не векторной) степени свободы.
- Мост: твист b(θ)=cos(θ/2) (v6/v7) даёт период 4π = спинорная
  антипериодичность = полу-дисклинация Франка Ω=π. Это НЕОБХОДИМОЕ условие g=2.
- Осипов: спинор на фоне дисклинации (SO(3)) удовлетворяет уравнению Дирака
  → g=2 автоматически.
- ОТКРЫТО: строгий вывод, что эфф. уравнение на твист-контуре ИМЕННО
  дираковское (1-й порядок, спинор), а не Клейн-Гордона. Структурно обосновано,
  формально не завершено.

## ЯДРО, ПУНКТ 2: численные α, α_G — ГЛАВНАЯ СТЕНА

- α = r_e/λ_C = 1/137.036; α_G = (m_e/m_P)² = 1.75e-45; α/α_G = 4.2e42.
- Новый угол (от вчерашнего α·ħ): α = S(r_e)/S(λ_C) = отношение действий
  магнитного (r_e) и квантового (λ_C) масштабов. Кольцо r_e суб-квантово
  (∮p dl=2πα·ħ, n=α не целое); квантуется кольцо λ_C (n=1: m_e c λ_C=ħ).
- ЭЛЕГАНТНО, но НЕ выводит число 137 — переформулировка, не вывод.
- α_G — та же стена (m_e/m_P, иерархия). СТЕНА СТОИТ. Главная нерешённая
  задача; α, α_G остаются входными (эквивалент иерархии m_e/m_P).

## ЯДРО, ПУНКТ 3: J=2 поле (сдвиговый канал) — НЕОЖИДАННАЯ СВЯЗЬ

- Неприводимое разложение SO(3): u_ij = ⅓δ_ij θ (спин-0) + σ_ij (спин-2) +
  ω_ij (спин-1). Строгое (теория групп).
- Энергия: E = ½Kθ² + μσ_ijσ_ij + (γ/2)ω_ijω_ij. Квадруполь Q_ij ↔ σ_ij
  (сдвиг, спин-2). J=2 гравитон = квант СДВИГОВЫХ (поперечных) колебаний.
- **НОВОЕ РАЗРЕШЕНИЕ ПАРАДОКСА:** почему гравитация и скалярна (статика 1/R²),
  и спин-2 (волны)?
  - J=0 (скалярная статика, ⟨W²⟩, 1/R²) = ПРОДОЛЬНЫЙ канал (дилатация θ,
    быстрый/скрытый сектор c_L);
  - J=2 (квадруполь, гравитационные волны LIGO) = ПОПЕРЕЧНЫЙ сдвиговый канал
    (σ_ij, скорость c).
  → ДВА СЕКТОРА эфира = ДВА ЛИЦА гравитации (статика продольная, излучение
    поперечное). Соединяет с сегодняшним разбором продольного/поперечного.
- ОТКРЫТО: вывести полевое уравнение σ_ij из лагранжиана Лазара и получить
  квадрупольную формулу Эйнштейна с правильным G. Структура есть, G не выведен.

## ЧЕСТНЫЙ ИТОГ

- Вопрос 1: адиабатическая защита вакуума = сохранение инварианта I=ħ(n+½).
  Строго, универсально.
- Вопрос 2: нелинейность не ломает адиабатическую защиту (СЛ не спасает), но
  даёт солитоны — фундамент существования частиц. Главная ценность — для ядра.
- g=2: структурный мост через спинорность твиста 4π; строгий вывод уравнения
  Дирака из T(3)+SO(3) открыт.
- α, α_G: главная стена стоит; новый угол (отношение действий) элегантен, но
  не выводит числа.
- J=2: строгое разложение + НОВОЕ — два сектора эфира объясняют два лица
  гравитации (скалярная статика = продольный, спин-2 волны = поперечный).

## Честные оговорки

- Адиабатический инвариант для нелинейного осциллятора — классическая теорема
  (действие ∮p dq), но квантовая связь I/ħ=n+½ для сильно нелинейного случая
  требует аккуратности (уровни неэквидистантны); для слабой нелинейности верно.
- g=2: перенос вывода Осипова (дисклинация) на твист-контур пользователя —
  структурно обоснован, формально не доказан.
- α как отношение действий — точное соотношение (r_e/λ_C), но физический
  источник числа 137 не найден. Не выдаю за вывод.
- J=2↔поперечный, J=0↔продольный — красивое структурное соответствие;
  полевые уравнения и связь с G НЕ выведены. Это гипотеза с сильной структурой,
  не доказанная теория гравитационных волн.
- Солитонная природа частицы — качественный аргумент (нелинейность удерживает
  локализацию); конкретное солитонное решение для дислокационного кольца в
  T(3)+SO(3) эфире НЕ построено.
