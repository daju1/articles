# v3-vector: калибровка под электрон, v=c/2, честные поправки (24 окт 2026)

Проект «Единая геометродинамическая модель». Модель: пара скользящих (glide)
колец, особые точки в противофазе, q_m=Δb (разрыв), плоскости неподвижны.

## Поправки к прежним утверждениям (вскрыты прогоном C-кода)

1. МАГНИТНЫЙ МОМЕНТ (токовый) μ_z ПАРЫ = 0, НЕ -0.5.
   При противофазе оба кольца бегут в одну сторону (r×v одинаков), заряды
   противоположны (±Δb) → μ_top=+0.5, μ_bot=-0.5 СОКРАЩАЮТСЯ. C-версия права,
   прежний Python -0.5 был ошибкой нормировки. J_z складывается (=2).
   => физический магнитный момент электрона = ДИПОЛЬНЫЙ p_z=q_m·d, НЕ токовый.

2. СТАБИЛЬНОСТЬ пары: обеспечивает СОХРАНЕНИЕ МОМЕНТА ИМПУЛЬСА (центробежный
   барьер J²/d³), а НЕ вихревой член силы Пича-Кёлера. Точный расчёт: central
   и vortex оба ~1/d² → сумма не даёт равновесия на конечном d. Равновесие
   d_eq=J²/(m·A), как боровская орбита (механизм v5). Прежнее "вихревой барьер
   стабилизирует" (kg 4ea9f762ce4d) — ИСПРАВЛЕНО.

## v=c/2 — точное следствие калибровки

J=m·a²·ω=ħ/2, a=λ_C=ħ/(m c) → v=ωa=c/2 РОВНО. Не c (не zitterbewegung),
а средняя орбитальная скорость c/2.
СВЯЗЬ С g=2: проверена и ОПРОВЕРГНУТА. Даже с вращающимся диполем μ/L=0.5 (g=1).
Фактор 2 между v и c НЕ переносится на g. v=c/2 и g=2 — разные двойки.

## Калибровка под электрон (самосогласованная, но подгонка)

Формула массы: m = K·μ_shear·q_m²·a/c² (энергия самодействия петли, K~O(1)).
ЕСТЕСТВЕННАЯ калибровка:
  • a = λ_C (комптоновская длина) = 3.862e-13 м — размер кольца;
  • q_m = r_e (классический радиус электрона) = 2.817e-15 м — магнитный заряд;
  • тогда q_m/a = r_e/λ_C = α = 0.007296 — ПОСТОЯННАЯ ТОНКОЙ СТРУКТУРЫ выходит
    ЕСТЕСТВЕННО (встроенное отношение заряд/размер);
  • μ_shear = m_e c²/(q_m² λ_C) = 2.67e28 Па (модуль сдвига эфира, из m_e);
  • спин ħ/2 → ω=3.88e20 рад/с, v=c/2.

КРАСИВО: r_e = α·λ_C, поэтому q_m=r_e даёт α=q_m/a автоматически.

ЧЕСТНО: это ПОДГОНКА (a, q_m выбраны под известные масштабы), не вывод масс
из первых принципов. μ_shear определяется из m_e, не предсказывается.
Воспроизводятся: m_e (по построению), α (встроено), спин, v=c/2.
НЕ выводится: G (нужен планковский масштаб, барьер ~40 порядков).
