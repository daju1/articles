# unified_model_channels — расчётные файлы всех каналов для всех типов частиц

Моделирование ВСЕХ шести каналов взаимодействия для ВСЕХ типов частиц единой
геометродинамической модели. Строго по UNIFIED_THEORY_consistent_2026-10-24.md
(упругий базис L,T,M, без СИ-ампер).

## Типы частиц (§2 теории)
- glide-диполь   — пара обычных glide-колец, противофаза, период 2π → БОЗОН
- мёбиус-диполь  — пара (кольцо+анти), период 4π → ФЕРМИОН (электрон), спин-½
- одиночное кольцо — ссылочное (монополь-подобное)
- кварк (b/3)    — частичный Бюргерс, сильный сектор (конфайнмент)

## Шесть каналов (§5 теории)
| Канал | Закон | Источник в модели |
|-------|-------|-------------------|
| кулон      | 1/R²       | произведение зарядов-Бюргерсов |
| магнитное  | 1/R⁴       | диполь-диполь q_m·d (статический) |
| гравитация | 1/R²       | плёнка Ферми, σ~⟨W²⟩>0 (притяжение) |
| обмен      | 1/R³       | фаза прецессии cos2Δφ |
| слабое     | e^(-R/R_W) | киральность твиста (нарушение чётности) |
| сильное    | линейный   | частичный b/3 + лента (конфайнмент) |

## Файлы
- unified_channels.h / .c   — C-ядро (расчёт полей, каналов, свойств частиц)
- unified_channels_bind.py  — Python-биндинг (ctypes) к .so
- unified_channels_tests.py — тесты: свойства частиц, все каналы×пары, законы, чётность
- unified_channels_py.py    — НЕЗАВИСИМОЕ Python-зеркало (проверка без .so)
- build.sh                  — сборка gcc + запуск тестов

## Сборка/запуск
    cd unified_model_channels
    sh build.sh
    # или вручную:
    gcc -O3 -shared -fPIC unified_channels.c -o unified_channels.so -lm
    PYTHONIOENCODING=utf-8 python3 unified_channels_tests.py
    # перепроверка независимым зеркалом (без .so):
    PYTHONIOENCODING=utf-8 python3 unified_channels_py.py

## Три слоя проверки
1. C-код (unified_channels.c) — истина, компилируется gcc.
2. Биндинг (ctypes) — тестирует РЕАЛЬНЫЙ C через .so.
3. Python-зеркало (unified_channels_py.py) — независимые те же формулы.
Совпадение слоёв 2 и 3 подтверждает корректность реализации.

## Честные оговорки (из теории, §8)
- Законы спадания (1/R², 1/R³, 1/R⁴, лин., эксп.) — структурны (не подгонка).
- Абсолютные значения — в МОДЕЛЬНЫХ упругих единицах (a=ω=b=c=1), НЕ реальные
  α, G. Воспроизводятся иерархия и законы, не числовые константы.
- g=2 требует спинорного уровня (в классике колец g=1).
- α_W, α_s, натяжение σ — параметры, не выведены из теории.
- G вложен в жёсткость эфира (принято, не выводится).
