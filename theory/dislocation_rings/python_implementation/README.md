# независимая Python-реализацияы C-кода dislocation_rings

Чистые Python/numpy реализации эталонного C-кода, использованные для
проверки логики без компиляции (on-device песочница блокирует ctypes и
компилятор C). Логика 1:1 соответствует dislocation_rings_v4.c/.h.

## Файлы
- `impl_v4_field.py`      — ядро поля v4: кинематика кольца, каналы
                            central (кулон) / vortex (Пич-Кёлер), три режима
                            Ферми (PLAIN/FILM_RETARDED/FILM_INSTANT), мёбиусов
                            знак cos(theta/2); конструкторы электрона (диполь)
                            и мёбиус-частицы (одно кольцо).
- `impl_v4_stability.py`  — энергия кольца с натяжением T=mu*b^2 и равновесный
                            радиус (ring_total_energy, ring_equilibrium_radius).
- `impl_mobius_analysis.py` — асимптотика поля, мультиполи, регуляризация
                            особой точки кинком; показатель p закона 1/R^p.
- `impl_tests.py`         — воспроизведение всех численных результатов сессии.

## Запуск
    cd python_ports
    python3 impl_tests.py

## Соответствие C-коду
Эти реализации НЕ заменяют C-код — они дублируют его логику для верификации.
Эталон — ../dislocation_rings_v4.c (+ .h). Для нативной скорости собирайте
C: gcc -O3 -shared -fPIC -o dislocation_rings_v4.so dislocation_rings_v4.c -lm
и используйте ../dislocation_rings_bind_v4.py.

## Ключевые воспроизводимые результаты
- Диполь-диполь: F*R^2 -> плато (хвост 1/R^2) + 1/R^4 на малых R.
- Мгновенный закон: F ~ -K (v/c)^2 cos(dphi)/R^2, K->4 на больших R/a.
- Мёбиус-частица: поле ~1/R (p~1.00), период 4pi; электрон ~1/R^2, 2pi.
- Устойчивость: a_eq ~ 1/sqrt(T), устойчивый минимум.
