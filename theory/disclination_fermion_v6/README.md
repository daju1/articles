# disclination_fermion_v6 — фермион как ОДНА диспирационная петля

Развитие v5: вместо двух точечных монополей — ОДИН контур с твистом вектора
Бюргерса b(θ)=cos(θ/2) (период 4π). Диспирация = дислокация (Бюргерс→кулон)
+ дисклинация (Франк Ω=π за обход → спин-½, g=2).

## Что нового против v5
- Магнитный заряд = вектор Бюргерса контура (не точка); "пара ±q_m" = дипольный
  момент твиста (монополь=0, |диполь|=8/3 — проверено численно).
- Спин из дисклинационной части: S/L_орб=1/2, g=2 — ИЗ периода 4π (не постулат).
- Три канала (кулон cosΔφ-тип, обмен, гравитация) из ОДНОГО твиста, без ручных
  фазовых множителей (в отличие от v5).

## Сборка/запуск
    gcc -O3 -shared -fPIC disclination_fermion_v6.c -o disclination_fermion_v6.so -lm
    python3 disclination_fermion_v6_tests.py

## СТАТУС
Каркас. Поле строится корректно (запаздывающее, central+vortex, радиац. член
всегда). Твист→диполь и спин-½/g=2 — численно/геометрически подтверждены.
G по-прежнему НЕ выводится (барьер планковского масштаба, общий для проекта).
Фазовая подпись кулона — cos(Δφ/2) (тонкость периода 4π), требует уточнения.
