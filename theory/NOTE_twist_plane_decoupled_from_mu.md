# Отмена критерия «μ≠0 только t–r»: плоскость твиста развязана с μ (24 окт 2026)

Проект «Единая геометродинамическая модель». Важная методологическая поправка
(инициирована пользователем 24 окт 2026).

## Что отменяется
Прежний результат v7 (kg entity 7275a9c3b972): «магнитный момент μ≠0 ТОЛЬКО для
плоскости твиста t–r, μ_z=0.5·cosβ». Этот результат был получен для ПОТОКОВОЙ
(дисклинационной) μ — μ ∝ поток спин-связности ∮ω dφ, который ≠0 только когда
ось Франка (нормаль плоскости твиста) ∥ оси обхода.

С тех пор мы ПЕРЕОПРЕДЕЛИЛИ:
- магнитный заряд q_m = разрыв Бюргерса Δb в особой точке (скаляр, [q_m]=длина);
- магнитный момент = СТАТИЧЕСКИЙ диполь μ=q_m·d (не ток, не поток).

## Почему критерий t–r больше не применим
Дипольный μ=q_m·d зависит ТОЛЬКО от величины заряда |Δb| и плеча d (разнос
полюсов). НЕ зависит от направления/плоскости вектора Бюргерса.
ЧИСЛЕННО ПОДТВЕРЖДЕНО: μ=q_m·d=1.0 одинаков для всех плоскостей (t–r, r–z, t–z,
наклон). Плоскость твиста выпала из магнитного момента.

## На что плоскость твиста влияет ТЕПЕРЬ
Плоскость задаёт угол b относительно линии дислокации (t̂) → ТИП дефекта →
УПРУГИЕ свойства (масса), через k-фактор:
- винтовая (b∥t̂): k_screw=1 (Markenscoff-Ni);
- краевая glide (b⊥t̂ в плоскости): k_glide=5/6 (ν=¼);
- краевая climb (b⊥t̂ из плоскости): k_climb=3/2 (ν=¼).

РАЗДЕЛЕНИЕ характеристик:
- магнитный момент μ = q_m·d — от заряда и плеча (геометрия ПАРЫ);
- масса m ~ μ_shear·q_m²·a·k(плоскость)/c² — от типа дефекта (ПЛОСКОСТЬ твиста).

## Пересчёт комбинаторики мёбиус-пар
Без фиксации плоскости: 2 (относит. прецессия ↑↑/↑↓) × 2 (фаза син/проти)
× 3 (плоскость твиста) = 12 структурных пар.
Структура 12 = 4 × 3:
- 4 магнитно-спиновых состояния (одинаковый μ, разный спин/ориентация);
- × 3 массовых типа (разная масса через k-фактор).

ГИПОТЕЗА (спекуляция, НЕ вывод): 3 типа дефекта (плоскость твиста) ↔ 3
ПОКОЛЕНИЯ лептонов (e/μ/τ) — разная масса, тот же заряд/спин. Требует проверки
отношения масс e:μ:τ из k-факторов. Напоминание: прежняя гипотеза о поколениях
через winding n была ОПРОВЕРГНУТА (n давал разные спины, не массы). Эта —
другая (через тип дефекта), тоже требует проверки.

## Честные оговорки
- Независимость μ от плоскости — прямое следствие дипольного определения μ=q_m·d.
- Старый t–r критерий не неверен в рамках потоковой μ, но к дипольной μ не применим.
- «3 плоскости = 3 поколения» — спекуляция; k-факторы (1, 5/6, 3/2) НЕ дают
  наблюдаемого отношения масс e:μ:τ (1 : 207 : 3477) без доп. механизма.
