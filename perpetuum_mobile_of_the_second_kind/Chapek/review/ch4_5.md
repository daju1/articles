**Рабочий критерий (наш).** В изотермической системе стационарный ток при нулевых термодинамических силах возможен ⇔ хотя бы по одному циклу нарушено условие Вегшайдера: W = Π k₊ / Π k₋ ≠ 1. Иначе говоря, нарушено детальное равновесие (ДР). Кроме того:

## ГЛАВА 4. Low-Temperature Experiments and Proposals

### 4.1–4.2. Введение и сверхпроводимость (с. 117–121)

**Суть.** Обзорный раздел, модели в нём нет.
- Типы I/II, κ = λ/ξ, зависимость H_c(T) = H_c[1 − (T/T_c)²] (4.2).
- Магнитокалорический эффект (с. 119).
- Квантование флуксоида (4.3)–(4.4).
- Эффект Литтла–Паркса: T_c(Φ) = T_c[1 − (ξ(0)/R)²(n − Φ/Φ₀)²] (4.5), с. 121.

**Заявка (с. 121).** Наблюдение незатухающего тока при R > 0 якобы «implies power dissipation (RI_p²) and, by inference, … a direct current power source under equilibrium conditions». Это постановка задачи для §4.4.

**Критика.** Ток I_p = −∂F/∂Φ существует в равновесном гиббсовском состоянии с B ≠ 0. Это часть равновесной намагниченности (как диамагнетизм), а не транспортный ток. Формула джоулевых потерь RI² относится к току, который поддерживается силой. Для равновесной компоненты она неприменима: в состоянии Гиббса средний поток энергии в фононы резистора равен нулю — это ФДТ, пункт (3). Подробнее — в §4.4.

### 4.3. Двигатель Кифа на когерентном магнитокалорическом эффекте (CMCE) (с. 121–125)

**Суть модели.** Маленький сверхпроводящий «якорь» (Sn, d ≈ 10⁻⁷ м), который переходит без промежуточного состояния, обходит цикл в плоскости H–T (рис. 4.1–4.2, с. 122–123):
- **A → B → C**: поле растёт, якорь переходит в нормальное состояние и адиабатически охлаждается. Уравнение (4.6): L_{H1} = T₁(S_{n1} − S_{s1}) = V∫C_n dT.
- **D**: поле уменьшается, обратный переход и нагрев. Уравнение (4.7): L_{H2} = T₂(S_n − S_s) = V∫_{T₂}^{T₃} C_s dT.
- **D → E → F**: мейсснеровское выталкивание совершает работу W₁ = μ₀(H₂² − H₃²)V/2 (4.8) и W₂ = μ₀(H₃² − H₁²)V/2 (4.9).
- **F → A**: единственный контакт с термостатом, поглощается теплота Q = V∫_{T₃}^{T₁} C_s dT (4.10).

Отсюда авторы получают ΔS = −∫ dQ/T < 0 (4.11), с. 124.

Числа для Sn (с. 124):
- вершины (T₁, H₁) = (0.6T_c, 0.64H_c), (T₂, H₂) = (0.186T_c, 0.965H_c), (T₃, H₃) = (0.407T_c, 0.834H_c);
- L_{H1} = 340 Дж/м³, L_{H2} = 50 Дж/м³, W₁ = 88, W₂ = 107, Q = 195 Дж/м³;
- оценка мощности — ≈ 2·10¹² Вт/м³.

**Откуда, по авторам, нарушение.** Теплота поглощается только на одном участке, а работа совершается на других. Значит, по первому началу теплота превращается в работу.

**Критический анализ — ошибка найдена.**

1. Ключевое допущение на с. 122: «(The magnetodynamic work to move the armature is assumed to be zero.)». Уравнения (4.6) и (4.7) — это **баланс энергии** («скрытая теплота = теплота нагрева/охлаждения решётки и электронов»). Для адиабатического процесса нужен **баланс энтропии**: для обратимой адиабаты S = const, для необратимой S растёт.
2. Независимый от модели аргумент. В мейсснеровском состоянии S_s зависит только от T: G_s(T,H) = G_s(T,0) + μ₀H²V/2, и поправка от поля от T не зависит. Точки A (T₁, H₁) и F (T₃, H₁) обе сверхпроводящие, весь путь A → F адиабатический. Второе начало для адиабатических участков требует S(F) ≥ S(A), то есть T₃ ≥ T₁. У Кифа T₃ = 0.407T_c < T₁ = 0.6T_c. Следовательно, **энтропия образца уменьшается уже на адиабатических участках**, и (4.11) лишь «возвращает» это уменьшение. Новый эффект для этого не нужен: ошибка внутренняя.
3. Численная проверка. Модель: электроны по Гортеру–Казимиру (S_n = γT, S_s = γT³/T_c²) и дебаевская решётка (βT³/3). Параметры Sn: γ = 109 Дж/(м³К²), β = 14.9 Дж/(м³К⁴), T_c = 3.72 К.

```js
const g=109,b=14.9,Tc=3.72, Sn=T=>g*T+b*T**3/3, Ss=T=>g*T**3/Tc**2+b*T**3/3;
// L=T(Sn-Ss); ∫Cn, ∫Cs — по (4.6),(4.7),(4.10)
```
Вывод:
```
L(T1)=348 L(T2)=50 (book 340, 50)
energy balance (4.6): int Cn T2..T1 = 337  (4.7) int Cs T2..T3= 48  Q(4.10)= 188 (book 195)
S(A)= 142.8  S(C)= 77.1  S(F)= 44.6  J/m3K
isentropic T2' = 1.226 K = 0.330 Tc ; return isentrope gives T3'=T1
int dQ/T (F->A) = 98.2 = S(A)-S(F) = 98.2
```
   - Модель воспроизводит все числа Кифа: 340/50/337/48/188 против 340/50/195. Значит, T₂ и T₃ получены именно из баланса энергии.
   - При этом на «адиабатическом» участке A → C энтропия падает со 143 до 77 Дж/(м³К), на D → F — с 77 до 45.
   - Суммарное падение 98 Дж/(м³К) в точности равно ∫dQ/T, которое затем «забирается» у термостата.
   - Обратимая адиабата дала бы T₂′ = 0.33T_c, а на обратном пути T₃′ = T₁. Тогда Q = 0, и по первому началу работа за цикл равна нулю.
4. Физически пропущена работа источника поля при входе и выходе потока (S ↔ N при H = H_c). Именно поэтому энергетический баланс не совпадает с энтропийным.
5. Размерности: L/V, W/V, Q/V в Дж/м³ — верно. Проверка Клапейрона–Клаузиуса L = −μ₀TH_c dH_c/dT·V с μ₀H_c0²(Sn) ≈ 740 Дж/м³: при t = 0.6 получается ≈ 341 Дж/м³ — верно.

**Возражения в книге (с. 124–125).** Только практические: вихревые токи, омический нагрев, дипольное излучение, обратная реакция магнита, флуктуации, гистерезис, сложность изготовления. Термодинамическая несогласованность (4.6)–(4.7) в тексте не отмечена. Ответа Кифа на возражения нет.

**Эксперимент.** Только подготовительные работы в Москве: сферы In, r ≈ 1.25·10⁻⁷ м, баллистический холловский микромагнетометр, 2.5–3 К (с. 125). Двигатель не испытывался, результатов в тексте нет.

**Вердикт: (а) ошибка найдена.** Уравнения (4.6)–(4.7) — баланс энергии при нулевой магнитной работе вместо баланса энтропии. Числа самого Кифа означают уменьшение S образца на адиабатических участках. Скрытого источника нет — есть арифметическая несогласованность. Оценка авторов («theoretically compelling», с. 125) не подтверждается.

### 4.4. Неоднородная петля Никулова (с. 125–134)

**Суть модели.**
- «Квантовая сила» (с. 126): ∮F_q dl = (p_cl − p_un) f dl = h(⟨n⟩ − Φ/Φ₀) f (4.14). Это скорость изменения циркуляции импульса при переключениях петли между состояниями «замкнута» и «разомкнута» с частотой f. Энергетический спектр — (4.12)–(4.13).
- Напряжение на сегменте неоднородной петли (с. 127): V_{ls} = (R_{ls}/l_s − R_l/l) l_s I_p(Φ/Φ₀) (4.15).
- Предельный случай (сегмент b переключается, a всегда сверхпроводящий): (4.16), а на низкой частоте V_b = (hf/2e)(⟨n⟩ − Φ/Φ₀) l_b/l (4.17).
- Ограничение мощности (с. 128): P_p < P_thermal ≈ (kT)²/ħ (4.18).

**Откуда, по авторам, нарушение (с. 128).** Сегмент l_b переключают **тепловые флуктуации** при T ≈ T_cb. Тогда V_b — «persistent voltage», а P_p = R_b I_p² — постоянная мощность, извлечённая из тепла. По Никулову это нарушает «postulate of randomness under equilibrium conditions» (с. 127).

**Критический анализ.**

1. Что измеряет вольтметр. Он измеряет разность **электрохимических** потенциалов между контактами. В гиббсовском равновесии электрохимический потенциал однороден при любом B, в том числе при нарушенной T‑инвариантности. Поэтому V_dc = 0 строго. Конденсатор вольтметра — часть замкнутой системы; в состоянии Гиббса его заряд стационарен, и постоянный ток через нагрузку невозможен.
2. Равновесный I_p бездиссипативен — он термодинамический (−∂F/∂Φ), а не транспортный. Утверждение «RI_p² — диссипация» смешивает транспортный коэффициент R с равновесным орбитальным током.
3. В нашей терминологии: переключения «замкнута ↔ разомкнута» плюс выбор n при замыкании образуют цикл в пространстве (связность, n, заряд). Если переключает тепло при той же T, ДР выполняется в совместном пространстве, W = 1 и тока нет. Вывод (4.14) учитывает изменение импульса при замыкании, но не учитывает микроскопически обратные процессы. Это пункт (2) нашей схемы: флуктуация «без обратного влияния».
4. Формула (4.17) — по сути формула выпрямителя: напряжение пропорционально частоте переключений f, задаваемой извне. Это Джозефсон‑подобный храповик, и авторы сами ссылаются на него: [38–40], с. 133.
5. Размерности и числа. (kT)²/ħ имеет размерность Дж²/(Дж·с) = Вт. При T = 10 К это ≈ 1.8·10⁻¹⁰ Вт, при 100 К ≈ 1.8·10⁻⁸ Вт — совпадает с книгой. V_b < (R_b(kT)²/ħ)^{1/2} при 1 К и 10 Ом даёт ≈ 4 мкВ (в книге «≈10 мкВ», тот же порядок). hf/2e = Φ₀f — вольты, верно. Сама оценка — верхняя граница, а не аргумент в пользу ненулевого эффекта.

**Эксперимент (с. 129–133).**
- **Серия I.** Одиночные петли из Al: 2R = 1–4 мкм, w = 0.2–0.4 мкм, T ≈ 0.988–0.994T_c. На асимметричной петле при нулевом внешнем токе V₃ ≈ 0.1 мкВ, на симметричной эффекта нет. Оговорка авторов (с. 130): «The researchers raise the caution that external noise — rather than purely thermal fluctuations — cannot be ruled out as a cause for the observed dc voltages.»
- **Серия II.** Массивы из 3 и 20 петель с **внешним** переменным током ΔI до 50 мкА, f = 10²–10⁶ Гц. Порог ΔI_cr; V не зависит от f_ac; напряжения последовательных петель складываются: до 40 мкВ (3 петли) и до 300 мкВ (20 петель).
- Итог авторов (с. 133): «Neither result directly contradicts the second law because the source of the observed dc power is not equilibrium thermal fluctuations.»
- Бергер [30]: модель петли с двумя неравными слабыми звеньями. Согласие качественное, «the quantitative agreement is poor» (с. 134). Выполнено ли в его модели ФДТ для шума при одной T, нет в тексте.
- Оговорки самих авторов (с. 134): измерена только одна из переменных, нужных для диссипации; диссипация напрямую не измерялась; «Third, in no experiment has it been clearly established that thermal fluctuations were the source of the experimentally measured voltage oscillations».

**Вердикт: (а) для теоретической заявки, (в) для эксперимента.**
- Теоретическая заявка противоречит однородности электрохимического потенциала в состоянии Гиббса. «Квантовая сила» не учитывает обратных процессов.
- Эксперимент — выпрямление внешнего шума или переменного тока, что признают сами авторы. Это наш пункт (2).
- Что проверить:
  - зависит ли V_dc от температуры подмешанного *отфильтрованного* шума T_noise; ожидается V_dc ∝ (T_noise − T_образца);
  - остаётся ли V_dc ≠ 0 при T_noise = T_образца в полностью экранированной схеме с холодными фильтрами;
  - есть ли прямая калориметрия.

### 4.5. Бозе–эйнштейновская конденсация и второе начало (с. 134–135)

**Суть.** Модели нет — только эвристика. Кифа и Никулова называют «quantum thermal ratchets». Тезис (с. 135): бозонная статистика «intrinsically moves a multiparticle system toward a state of low entropy (single wavefunction)».

**Критика.** БЭК и сверхпроводящий переход — равновесные фазовые переходы. Они минимизируют свободную энергию; при переходе энтропия конденсата уходит в термостат как скрытая теплота. Цикла с извлечением работы не предложено. Утверждение о «противоположных тенденциях» бозонов и фермионов к второму началу отношения не имеет: обе статистики дают гиббсовские равновесные состояния и подчиняются ДР.

**Эксперимент:** нет в тексте.

**Вердикт: (а).** Спекуляция без модели. Два частных случая, на которых она построена (Киф, Никулов), разобраны выше.

### 4.6. Квантовая когерентность и запутанность (с. 135–140)

#### 4.6.2. Спин‑бозонная модель (Помбо, Аллахвердян, Ньивенхейзен) (с. 136–137)

**Суть.**
- Гамильтониан H = H_S + H_B + H_I (4.19), где H_S = (ε/2)σ̂_z + (Δ(t)/2)σ̂_x, H_B = Σħω_k a_k†a_k, H_I = ½Σg_k(a_k† + a_k)σ̂_z (4.20).
- Короткий сильный импульс Δ(t) поворачивает спин вокруг оси x на угол Θ = −δ₁Δ/ħ = −π/2.
- Работа (4.21): W₁ = għΓ/(2π) + (gkT/2)⟨σ̂_x(0)⟩ e^{−t/τ₂}. При ⟨σ̂_x(0)⟩ = −1 и (kT/2)e^{−t/τ₂} > ħΓ/2π получается W₁ < 0.

**Откуда «нарушение».** Отрицательная работа извлекается из «локально равновесного» термостата.

**Критика.** Это прямая иллюстрация нашего пункта (3).
- Начальное состояние — произведение ρ_S ⊗ ρ_B^{Gibbs} при **когерентном** спине (⟨σ_x⟩ = −1). Оно не гиббсовское для полной системы. Неравновесная когерентность — запас свободной энергии.
- Авторы сами говорят (с. 137): «However, it is applicable if the whole system — i.e. the spin and bath together — starts in equilibrium before applying the first pulse.»
- Сноска 4 (с. 135): «Allahverdyan, et al. have never claimed violation of the Thomson formulation, but rather, have proved its inviolability for systems starting in equilibrium».
- Критика авторов (с. 139): «the work and entropy generation required to prepare the ⟨σ̂_x(0)⟩ = −1 state has not been assessed».
- Размерности (4.21): g безразмерно, ħΓ и kT — энергии; верно.

**Эксперимент:** не проводился; предложены ЯМР, ЭПР, квантовые точки (с. 137).

**Вердикт: (а).** Скрытый источник — неравновесное (когерентное, негиббсовское) начальное состояние. Цикла с повторяемым извлечением работы без затрат на приготовление нет.

#### 4.6.3. Мезоскопический LC(R)-контур (Аллахвердян–Ньивенхейзен) (с. 137–139)

**Суть.**
- Гамильтониан H_s = Φ²/2L + Q²/2C (4.22); «фазовый объём» Σ = ΔΦΔQ/ħ (4.23).
- Гиббсовские дисперсии (4.24). Квантовые дисперсии из квантового ланжевеновского уравнения с найквистовским шумом (4.25), где k(ω) = ħRω coth(ħω/2kT).
- При медленном изменении L: dQ = ħR dL/(2πL²) > 0 (4.26), а dΣ/dL < 0. Это нарушение неравенства Клаузиуса, причём даже при T = 0.

**Откуда «нарушение».** Энергия «облака» мод, запутанного с контуром, относится к термостату. Цитата (с. 139): «Appealing to the first law, one concludes that the bath is not in its ground state.»

**Критика.**
1. Это нарушение неравенства Клаузиуса для **редуцированной** энтропии подсистемы, определённой через Σ, при сильной связи. Формулировка Томсона (работа за цикл ≤ 0 из гиббсовского начального состояния полной системы) не нарушается — это теорема тех же авторов (§3.4 книги, сноска на с. 135).
2. Положительная dQ при увеличении L «возвращается» при уменьшении L. Цикла с суммарной работой > 0 нет, и в тексте он не предложен.
3. Размерность (4.26): ħR dL/L² = Дж·с·Ом/Гн = Дж·с·Ом/(Ом·с) = Дж — верно.
4. **Опечатка в (4.24) (с. 138):** напечатано tanh(βħω₀/2), а должно быть coth. С tanh при высоких T получается ⟨Φ²⟩ → 0 вместо LkT. С coth: (Lħω₀/2)·coth(βħω₀/2) → LkT — верный классический предел.
5. Утверждение «quantum dispersions include damping (R), whereas the classical dispersions do not» (с. 138) — именно признак того, что редуцированное состояние сильно связанной подсистемы не гиббсовское по H_S. Гиббсовость предполагается для полной системы, а не для подсистемы. Наш пункт (3).
6. Сами авторы (с. 140): «for the quantum LRC circuit no thermodynamic assessment has been made of the dL-varying agent».

**Эксперимент:** нет. Есть лишь косвенные измерения ⟨Q²⟩ в туннельных переходах [53, 54] (с. 139).

**Вердикт: (а) как вечный двигатель второго рода.** Эффект реален, но касается определения теплоты и энтропии при сильной связи. Работа из цикла не извлекается.

### 5.2. Мембранные модели Гордона (с. 146–154) — прямой аналог наших асимметричных мембран

Общая установка авторов (с. 146): «Using plausible chemical structures and reaction mechanisms, Gordon posits a breakdown in the principle of detailed balance.»

Контрольный факт на с. 147: «Experiments find that the maximum glucose transfer rates are the same in both directions across the membrane in the absence of concentration gradients.» Там же: «Gordon's challenges should properly be considered theoretical», и «no experiments are recommended».

#### 5.2.2. Мембранный двигатель (с. 147–150)

**Суть (рис. 5.1, с. 148).** Канал с затвором X (X1/X2) и сужением Y (Y1/Y2) — 4 состояния C₁₁, C₂₁, C₁₂, C₂₂. Молекула M в N‑лопастном клатрате при X1 → X2 «запирается» в одной лопасти, и Y2 становится выгоднее на kT ln N. Уравнения:
- h₂₁/h₁₂ = exp(−ΔG/RT) (5.1) — переходы Y при X1;
- h†₂₁/h†₁₂ = exp(−(ΔG + RT ln N)/RT) (5.2) — переходы Y при X2;
- h†₂₁/h†₁₂ = (h₂₁/h₁₂)(1/N) (5.3);
- при этом, по тексту (с. 148), «the rate constants linking the X states (k12 and k21) are independent of the channel configuration Y»;
- кинетика (5.4)–(5.7). В (5.7) напечатано «C = … = 0», хотя по смыслу C = const (опечатка);
- поток R = W(k₁₂C₁₁ − k₂₁C₂₁) = W(C/Δ)k₁₂k₂₁h₁₂h†₂₁(N − 1) (5.8), с. 149.

Поток останавливается при отношении давлений N : 1, ΔS = −nR ln N. Цитата: «The flux is driven entirely by thermal energy» (с. 149).

**Откуда, по авторам, нарушение.** Асимметрия, вносимая молекулой M.

**Критический анализ — ровно наш критерий.**
1. Цикл C₁₁ → C₂₁ → C₂₂ → C₁₂ → C₁₁. Отношение Вегшайдера: W = (k₁₂h†₁₂k₂₁h₂₁)/(h₁₂k₁₂h†₂₁k₂₁) = (h₂₁/h₁₂)/(h†₂₁/h†₁₂) = **N** по (5.3).
2. Значит, множитель (N − 1) в (5.8) — это в точности (W − 1). Поток Гордона пропорционален отклонению от условия Вегшайдера, и именно оно — его «топливо». Сродство цикла kT ln W = kT ln N совпадает с работой сжатия газа до N : 1.
3. Где ошибка. Если свободная энергия — функция состояния, то G(X2Y2) − G(X2Y1) − [G(X1Y2) − G(X1Y1)] = RT ln N (из (5.1)–(5.2)). Обязано выполняться тождественно и G(X2Y2) − G(X1Y2) − [G(X2Y1) − G(X1Y1)] = RT ln N. То есть **k₁₂/k₂₁ при Y2 должно быть в N раз больше, чем при Y1**. Взаимодействие X–Y через M симметрично: если M делает Y2 выгоднее при X2, то X2 выгоднее при Y2. Гордон считает k не зависящими от Y, и функция G(X, Y) не может существовать.
4. Численная проверка (4‑уровневая марковская цепь):
```js
// K[0][1]=k12 ... K[1][3]=h†12, K[3][1]=h†21=h21/h12/N*h†12; consistent: K[2][3]=k12*N
```
```
N=1 Gordon: W=1.000 J=0.000e+0 | consistent: W=1.000 J=0.00e+0
N=2 Gordon: W=2.000 J=2.837e-2 | consistent: W=1.000 J=5.55e-16
N=6 Gordon: W=6.000 J=5.249e-2 | consistent: W=1.000 J=1.94e-16
```
   С термодинамически согласованными константами (k₁₂ при Y2 умножено на N) W = 1 и ток равен нулю с машинной точностью.
5. Оценка мощности авторов: Q̇ ≈ −RT ln N/(L²τN_A) = −8.314·300·ln 6/(10⁻¹⁶·10⁻³·6.02·10²³) ≈ −0.07 Вт/м² — арифметика верна, книга даёт ≈ −0.1 Вт/м².

**Возражения в книге.** Конкретных возражений против мембранного двигателя нет. Авторы считают «химический» тип заявок Гордона «robust» (с. 147).

**Эксперимент:** нет. Контрольный факт с глюкозным транспортёром (равные максимальные скорости в обе стороны, с. 147) согласуется с ДР.

**Вердикт: (а) ошибка найдена.** Нарушение Вегшайдера внесено в константы скорости вручную (W = N); оно несовместимо с существованием свободной энергии как функции состояния. Это ровно наша теорема: ток при нулевых силах ⇔ W ≠ 1, а физический W ≠ 1 без внешнего источника невозможен.

#### 5.2.3. Молекулярный «люк» (trapdoor) (с. 150–152)

**Суть (рис. 5.2).** Пора с шарнирной дверцей (открыта TD_o / закрыта TD_c). Из B в A молекула проходит только через открытую дверь. Из A — ещё и через закрытую, с вероятностью X, если ударит достаточно сильно («doggy-door»). Потоки:
- J_AB = k_AB[G_A](τ_o + Xτ_c)/τ (5.9);
- J_BA = k_AB[G_B]τ_o/τ (5.10);
- [G_B]/[G_A] = 1 + Xτ_c/τ_o > 1 (5.11), с. 151.

**Возражение в книге (с. 151).** «The crucial claim of this paradox is that a gas molecule G can force the trapdoor open from the right, but not from the left. This is questionable.» Авторы утверждают, что время в состояниях TD_o и TD_c «should be unaffected by the presence of the gas», поэтому член Xτ_c/τ_o надо убрать. Упомянуты симуляции Скордоса–Зурека [16] без нарушения и разбор схемы Варнера [17]. Ответ Гордона (сноска 2, с. 151): «stereochemical modifications to the trapdoor might overcome this objection by introducing chiral asymmetry into its chemical dynamics».

**Критический анализ (точнее, чем в книге).**
1. Канал «силового прохода» A → B через закрытую дверь — микроскопический процесс. У него обязан быть обращённый во времени партнёр: молекула из B проходит через закрывающуюся дверь, которая отдаёт ей энергию шарнира. В модели (5.9)–(5.10) скорость обратного процесса равна нулю, то есть W = ∞ — экстремальное нарушение ДР.
2. Численная проверка (4 состояния: дверь × сторона):
```
X=0.2: Gordon (no reverse) [GB]/[GA]=1.8571 (5.11 predicts 1.6000), W=inf | reverse=forward: ratio=1.0000, W=1 | reverse=0.5*forward: ratio=1.2951, W=2
X=0.5: Gordon (no reverse) [GB]/[GA]=3.0000 (5.11 predicts 2.5000), W=inf | reverse=forward: ratio=1.0000, W=1 | reverse=0.5*forward: ratio=1.4865, W=2
```
   - Перепад концентраций есть ⇔ W ≠ 1; при W = 1 он исчезает при любой асимметрии формы двери.
   - Попутно: даже внутри своей модели формула (5.11) неточна (1.6 против точного 1.857). Она неявно считает доли времени TD_o и TD_c не зависящими от положения молекулы.
3. Хиральность ответа Гордона не спасает. ДР следует из T‑инвариантности, а хиральность нарушает P, а не T. Хиральные системы подчиняются ДР: равновесие реакций энантиомеров тоже детально сбалансировано.
4. Связь с нашей работой: это классическая асимметричная мембрана (дверца Смолуховского). Асимметрия *геометрии* (W = 1) даёт выпрямление при Δμ ≠ 0, но не даёт тока при Δμ = 0 — наш пункт (1).

**Эксперимент:** нет, ни одной попытки (с. 151).

**Вердикт: (а).** Ошибка — отсутствие обратного микропроцесса, W = ∞. Книга приходит к тому же выводу, но через более слабый аргумент.

#### 5.2.4. Молекулярный ротор (с. 152–154)

**Суть (рис. 5.3).** Глобулярный белок в мембране с двумя конформациями A и B и разными моментами инерции I_A и I_B. Центробежные силы на боковые группы X и Y якобы асимметризуют переходы: «it is argued that the A-B transition rates are asymmetrized and detailed balance is destroyed at all ω» (с. 153). Получается насос тепла или частиц.

**Возражения в книге (с. 153–154).**
- ω ≈ √(kT/I) ≈ 10⁸ рад/с — на 4 порядка меньше, чем у малых молекул; центробежные эффекты ничтожны.
- Доля массы X, Y ~ 10⁻³.
- Неясно, как мембрана остаётся адиабатически развязанной на временах 10⁻³–10⁻⁴ с.
- Итог: «its physical aspects are not compelling».

**Мой анализ.**
1. Порядок величины: m = 10⁶ а.е.м., ρ ≈ 1.35 г/см³ ⇒ r ≈ 6.6 нм, I ≈ 2.9·10⁻³⁸ кг·м², ω ≈ 3.8·10⁸ рад/с. Оценка книги верна.
2. Главное — принципиальное, а не количественное. Центробежные силы выводятся из гамильтониана H = L²/2I(q) + U(q). Тогда распределение Гиббса exp(−H/kT) по (q, L) стационарно, а переходы A ↔ B с сохранением L удовлетворяют ДР в совместном пространстве (конформация, L) с весами exp(−L²/2I_{A,B}kT). Любая зависимость скоростей от ω сверх этой — постулат, несовместимый с гамильтоновой динамикой. Детальное равновесие здесь не выведено как нарушенное, а просто объявлено нарушенным.

**Вердикт: (а).** Нарушение ДР постулировано, механизма нет. Количественные возражения книги верны, но вторичны.

#### 5.2.5. Обсуждение (с. 154)

Авторы считают подход «undermining detailed balance through thoughtful asymmetrization of reaction mechanisms and kinetics» убедительным и связывают его с термосинтетической жизнью (§10.2). Наш ответ: асимметризация *механизма* при W = 1 даёт только диод. Асимметризация *констант* с W ≠ 1 в изотермической системе без внешнего источника несовместима с существованием G(состояние) — это и показывают обе модели Гордона.

#### 5.3.2. Доплеровский демон (с. 155–156)

**Суть.** Демон у дверцы по доплеровскому синему смещению чернотельного излучения атомов «предвидит» быстрые атомы: δν_m/ν_m ≈ v_x/c (5.12), под реалистичными условиями ≈ 10⁻⁶.

**Возражения в книге.**

- Шарден [20]: отдача при излучении тормозит атом.

- Сам Денур, по книге, признаёт: «the first [18] appears to have yielded to the second law [19, 20]» (с. 155).

**Вердикт: (а).** Равновесное излучение в полости не несёт информации о микросостоянии. Гиббсовость поля плюс ФДТ — наш пункт (3).

#### 5.3.3. Храповик с собачкой (линейный, доплеровский) (с. 156–159)

**Суть (рис. 5.4).**
- Диск (масса M) скользит по стержню, собачка (m) — справа, зубья высотой H.
- Распределение скоростей — максвелловское (5.13).
- Лобовая сторона видит радиационную температуру T₊ ≈ T₀(1 + 2|V|/3c) (5.14), тыльная — T₋ ≈ T₀(1 − 2|V|/3c) (5.15).
- Вероятность перескока собачки: P(z > H | ±|V|) = exp[−mgH/kT₀(1 ± 2|V|/3c)] (5.16) ≈ (1 ± 2A|V|/3c)e^{−A}, где A = mgH/kT₀ (5.17).
- R₁ = 1 + 2A|V|/c (5.18), R₁² ≈ 1 + 4A|V|/c (5.19), V_net = 4A⟨V²⟩e^{−A}/c (5.20)–(5.21).
- Максимум при A = 1: V_net,max = 4⟨V²⟩/(ec) = 4kT₀/(Mec) (5.22). Мощность (5.23): (dW/dt)_max = [1/(Lec²)]·[(2kT₀)⁵/(πM³)]^{1/2}.
- Ключевая гипотеза Денура (с. 157): «the leading and trailing sides of a microscopic disk can assume the temperature of the radiation field during the characteristic time interval of Brownian fluctuations».

**Откуда, по авторам, нарушение.** Тепловое движение диска коррелирует с «температурой» собачки через доплеровский сдвиг. Это фейнмановский храповик, где разность температур собачки и храповика создаётся самим движением. Авторы (с. 155): «remains a viable challenge».

**Проверка чисел.**
- (5.22) при T = 2500 К, L = 6·10⁻⁵ м, ρ = 10³ кг/м³ (M = 2.16·10⁻¹⁰ кг): V_net ≈ 7.8·10⁻¹⁹ м/с (в книге ≈ 2·10⁻¹⁸).
- (5.23): ≈ 1.5·10⁻⁴⁷ Вт (в книге ≈ 10⁻⁴⁷).
- Размерность (5.23): [Дж⁵/кг³]^{1/2}/(м·м²/с²) = кг·м²/с³ = Вт — верно.
- Время дрейфа на свою длину ≈ 3·10¹³ с ≈ 10⁶ лет — совпадает с книгой.
- Коэффициент 2/3 в (5.14) верен: для плоской грани ⟨cos²θ⟩/⟨cosθ⟩ по полусфере = (2π/3)/π = 2/3.

**Критический анализ — найдено пропущенное обратное влияние.**
1. **Общая теорема.** Возьмём замкнутую гамильтонову систему (диск + собачка + храповик + поле излучения в полости) в каноническом или микроканоническом равновесии. Её стационарное распределение — гиббсовское, импульсы распределены чётно, следовательно ⟨V⟩ = 0 строго. Дрейф порядка ⟨V²⟩/c возможен только при негиббсовском стационарном состоянии, а для эргодической системы из него не следует.
2. **Где конкретно ошибка.** Денур учитывает прямую связь: движение V нагревает лобовую сторону, ∂P_погл/∂V = (8/3)εσAT⁴/c. Но он не учитывает обратную, взаимную по Онсагеру–Казимиру: перегретая лобовая грань сильнее излучает вперёд, и отдача тормозит диск. F = −(8/3)εσAT³θ/c, где θ = T_грани − T₀. Это обратное влияние флуктуации на источник — наш пункт (2).
3. **Линейная модель.** Переменные V (нечётная) и θ (чётная):
   - dV = (−γV + βθ)dt + шум, dθ = (aV − θ/τ)dt + шум;
   - условие стационарности гиббсовской ковариации diag(kT/M, kT²/C) — это β = −a·σ_V²/σ_θ²;
   - подстановка физических a = (∂P/∂V)/C и β = (∂F/∂θ)/M даёт **тождественно** β = −(8/3)εσAT³/(cM) = −a·σ_V²/σ_θ². Радиационная отдача ровно удовлетворяет условию взаимности.

   Численно (уравнение Ляпунова):
```
beta=0.000:   <V^2>=1.0000 <V*dT>=1.54e-1 <dT^2>=0.0808
beta=-13.333: <V^2>=1.0000 <V*dT>=0.00e+0 <dT^2>=0.0500
```
   Без отдачи ⟨V·θ⟩ ≠ 0 — это и есть «асимметрия Денура» (5.17). С отдачей, согласованной по Казимиру, ⟨V·θ⟩ = 0: условная температура собачки не зависит от знака скорости, R₁ = 1, V_net = 0.
4. Связь с Фейнманом. Храповик Фейнмана работает только при T_собачки ≠ T_храповика. Денур пытается получить разность температур «бесплатно», из флуктуации V. Но эта разность — неравновесный отклик, который при учёте обратной связи в стационаре исчезает. Это ровно наш вывод (2): флуктуации дают ток, только если они не испытывают обратного влияния.
5. Учтена ли отдача от теплового излучения граней в работах Денура — нет в тексте. В книге этого возражения нет.

**Возражения в книге против храповика.** Только практические: ничтожная мощность (P* ≈ 10⁻³⁴ Вт/м³; даже масса Солнца из таких устройств дала бы ≈ 10⁻⁷ Вт), трение, «stiction», условие L ≫ λ_тепл, T_max ≈ 2500 К (с. 158–159). Вариант с газом вместо излучения: выигрыш ×10⁵ по скорости и ×10¹⁰ по мощности (с. 159). Итог авторов: «As a realizable second law violator, Denur's ratchet and pawl is an unlikely candidate» (с. 159).

**Эксперимент:** нет.

**Вердикт: (а), с оговоркой.** Ошибку я нахожу в пропуске обратного влияния — теплового излучения нагретой грани, — которое требует взаимность Онсагера–Казимира. Строго решает вопрос гиббсовость полной системы. Это мой анализ, не книги. Для полного закрытия стоит проверить, учтена ли эмиссионная отдача в оригинальных статьях (Phys. Rev. A 40, 5390 (1989); Entropy 6, 76 (2004)); в данном файле этого нет.

### 5.4. Адиабатический поршень Кросиньяни–Ди Порто (с. 159–164)

**Суть.**
- Адиабатический поршень массы M_p в цилиндре длины L; по N атомов идеального газа с каждой стороны, M_g — масса газа одной стороны.
- По тексту (с. 160): «Between the two regions T may vary, but P and N remain fixed.»
- Уравнение (5.24): Ẍ = −√C[1/√X + 1/√(L−X)]Ẋ + (M_g/M_p)[1/X − 1/(L−X)]Ẋ² + A(t), где C = 16nRT₀M_g/(πLM_p); белый шум (5.25).
- Линеаризация при μ ≡ M_p/M_g ≪ 1 и замене Ẋ² → kT₀/M_p (с. 161): Ẍ + 8√(2NkT₀/(πμM_pL²))Ẋ + (8kT₀/(μM_pL²))X = A(t) (5.26). Это броуновский осциллятор (5.27).
- Отсюда ⟨x²⟩ = (μ/2)(L/2)² и ⟨ΔS⟩/k = −(C_p/2R)(Nμ) (5.28).
- Численно при μ = 0.5, N = 3·10⁴: ξ_rms ≈ 0.2 и ΔS/k ≈ −10⁴ (5.30), с. 162.
- Цикл (рис. 5.6, с. 163): работа W_T = nRT₀ ln[V₀²(T₀²)^{1/(γ−1)}/(V₁V₂(T₁T₂)^{1/(γ−1)})] > 0 (5.31).

**Откуда, по авторам, нарушение.** Мезоскопические флуктуации поршня якобы на порядки больше термодинамических.

**Критический анализ — ошибка найдена.**
1. **Точный результат.** Для замкнутой гамильтоновой системы «идеальный газ + поршень» микроканоническое распределение положения поршня P(X) ∝ Ω(X) ∝ X^N(L−X)^N. Фактор импульсов от X не зависит. Отсюда ξ_rms = 1/√(4(2N+3)) — **не зависит от M_p**, убывает как N^{−1/2}, и выполняется формула Эйнштейна ⟨ΔS⟩/k = −1/2 на одну степень свободы.
2. По (5.26) жёсткость K = M_pω² = 8kT₀/(μL²) **не содержит N**. Сравнение с Эйнштейном: ⟨x²⟩_Crosignani/⟨x²⟩_Gibbs = μNC_p/R. Именно этот множитель стоит в (5.28). Значит, уравнение (5.24) теряет восстанавливающую («энтропийную») силу порядка NkT/L², связанную с энергообменом сторон через поршень. Его стационарное распределение не гиббсовское, то есть ФДТ нарушено самой моделью.
3. Авторы сами дают ключ (с. 161): «As shown by van Kampen [35], the Langevin approach fails, in general, for nonlinear dynamical systems such as this.»
4. **Молекулярная динамика** (1D, газ без взаимодействия между частицами, упругие удары о поршень и стенки, 3 прогона по 6·10⁵ шагов):
```
N=20 mu=0.5: MD xi_rms=0.0780 | Gibbs/microcanonical 1/sqrt(4(2N+3))=0.0762 | Crosignani sqrt(mu/8)=0.2500
N=50 mu=0.5: MD xi_rms=0.0433 | Gibbs/microcanonical 1/sqrt(4(2N+3))=0.0493 | Crosignani sqrt(mu/8)=0.2500
N=20 mu=0.1: MD xi_rms=0.0763 | Gibbs/microcanonical 1/sqrt(4(2N+3))=0.0762 | Crosignani sqrt(mu/8)=0.1118
```
   МД согласуется с гиббсовским результатом: убывает с N и не зависит от μ. С формулой (5.27) не согласуется. Для N = 50 прогон не полностью сошёлся, 0.043 против 0.049. Оговорки: 1D, малые N. Но аргумент через Ω(X) ∝ [X(L−X)]^N годится для идеального газа в любой размерности. Для N = 3·10⁴ гиббсовское ξ_rms ≈ 0.002, а не 0.2.
5. Цикл (5.31). При правильной статистике |⟨ΔS⟩| ≈ k/2, так что извлекаемая работа порядка kT за цикл. Она не превышает затрат на «защёлку», то есть на измерение и фиксацию положения (Сцилард). Проверку на машине Сциларда авторы не обсуждают (нет в тексте).
6. Цитируемый «корollary» Каллена (с. 161) относится к равновесным значениям. Флуктуации ΔS порядка −k ему не противоречат.

**Опубликованные работы в книге.** МД [37, 38] (Renne и др., 2001; White и др., 2002) «appear to corroborate … that temperature differences spontaneously evolve … and that it undergoes spatial oscillations» (с. 162). Подтверждают ли они *величину* ξ_rms ≈ 0.2 — нет в тексте. Разности температур и колебания совместимы с обычной релаксацией. Итог авторов (с. 163): «The adiabatic piston appears to be a robust theoretical challenge to the second law in the mesoscopic regime.»

**Эксперимент:** нет. Обсуждается лишь реализация на нанотрубках (с. 164).

**Вердикт: (а).** Ланжевеново уравнение (5.24) несовместимо с теоремой Лиувилля и гиббсовским распределением: нет восстанавливающей силы, пропорциональной N. Отсюда завышение ⟨x²⟩ в μNC_p/R раз. Наша МД это подтверждает.

### 5.5. Электрокалорический цикл Труппа (с. 164–168)

**Суть.**
- Сила между точечными зарядами в жидком диэлектрике F = q²/(4πε₀κr²) = 4πε₀κV² (5.32).
- Утверждение Труппа: для **одноимённых** зарядов F = q²/(4πε₀κ²r²) = 4πε₀V² (5.33) — при постоянном V сила не зависит от κ.
- Цикл на сферическом конденсаторе (рис. 5.7): зарядка; сжатие внутренней сферы r₁ → r₃ при постоянном заряде, причём заявлено, что электрокалорический нагрев новой области «exactly counterbalanced» охлаждением от работы сжатия; разряд на нагрузку; восстановление радиуса.
- ΔW_elec = ∫_{ΔV}(κε₀/2)E²dV (5.34), W_mech = −∫(ε₀/2)E²dV (5.35), −ΔQ = ΔW = ∫(κ−1)(ε₀/2)E²dV (5.36), с. 166–167.

**Откуда «нарушение».** Асимметрия шага 2, вытекающая из аномальной силы (5.33).

**Критический анализ.**
1. **Энергетическая теорема.** Для линейного диэлектрика при постоянной T существует свободная энергия F(Q, r₁) = Q²/2C(r₁), C ∝ κ. Сила на проводник равна −∂F/∂r₁ при Q = const, или +∂(CV²/2)/∂r₁ при V = const. Она обязана быть ∝ κ при фиксированном V. Тогда в любом изотермическом цикле ∮đW = ∮dF = 0. Утверждение (5.33) означает силу, не выводимую из F. Это не новый эффект, а нарушение закона сохранения энергии для квазистатических процессов.
2. **Эксперимент (с. 167–168) объясняется релаксацией заряда в «утечном» диэлектрике.**
   - Сфера в воздухе: 3·10⁻³ Н против теоретических (π/2)ε₀V² = 2.6·10⁻³ Н. Проверено: (π/2)·8.854·10⁻¹²·(1.36·10⁴)² = 2.57·10⁻³ Н.
   - В парафине сила **сначала 5·10⁻³ Н**, то есть примерно κ‑кратная (стандартная), и за ≈ 20 мин падает до 3·10⁻³ Н. Пластины: от 0.1 Н растёт до 0.128 Н за 120 мин.
   - Время максвелловской релаксации заряда τ = κε₀/σ. Для τ ≈ 20 мин и κ ≈ 2.2 нужно σ ≈ 1.6·10⁻¹⁴ См/м. Это обычный порядок для минеральных масел; диапазон 10⁻¹²–10⁻¹⁵ См/м — моя оценка, не из книги.
   - Значит, «аномальное» значение — это стационарный режим с током проводимости. Поле там определяется проводимостями, а не κ: в книге сказано «small steady-state currents were established». Это не равновесная электростатическая сила, и её нельзя подставлять в обратимый цикл.
   - Объяснение книги: «This decrease is ascribed to the subsiding of transient charge waves in the resistive dielectric» (с. 167). Мы утверждаем обратное: равновесное (диэлектрическое) значение — начальное.
3. Странность: для пластин в воздухе измерено 0.047 Н, а идеальная формула ε₀AV²/(2d²) даёт ≈ 0.018 Н (r = 10.5 см, d = 4 см). Это в 2.7 раза меньше. Теоретическое значение для пластин в книге не приведено, калибровку надо проверять.
4. Сами авторы признают (с. 168): «it requires an external power supply to drive it, rather than being driven solely by ambient heat». Также перечислены вязкий и омический нагрев и потери источника питания. Кроме того, проверено лишь 4 из 12 комбинаций условий и 2 значения потенциала (с. 168).

**Эксперимент.** Измерена только сила (Ben Weins Energy Science, по проекту Труппа). Цикл не испытывался. Цитата (с. 164): «no claim of second law violation has been made». Ферромагнитный вариант «currently being pursued» (с. 168).

**Вердикт: (а).** (5.33) противоречит существованию электростатической свободной энергии. Наблюдаемая «аномалия» количественно совместима с омической релаксацией в утечном диэлектрике, то есть с неравновесным стационаром.

### 5.6. Трёхканальный бильярд Либоффа (с. 169–170)

**Суть (рис. 5.8).** Три канала под 60° с общей вершиной, по одному диску в каждом. После снятия перегородки все диски уходят в канал B и остаются там: ΔS = −k ln 3 (5.37). Вывод Либоффа (с. 170): «the second law of thermodynamics is not valid in general for idealized irreversible systems».

**Возражения в книге (с. 170).** Идеализации нереализуемы. Система заперта «into a phase space of measure zero» и чувствительна к бесконечно малым возмущениям. Аналогия — все молекулы воздуха в одной половине зала.

**Мой анализ.** Строже — через теорему Лиувилля. Гамильтонов поток сохраняет фазовый объём, поэтому множество меры 3Ω не может отобразиться в множество меры Ω. Заявленная «концентрация» возможна только для начальных данных меры нуль или на конечное время (возврат Пуанкаре). Термостата нет, изотермичности нет, ΔS = −k ln 3 — это изменение крупнозернистого объёма, а не термодинамической энтропии.

**Эксперимент:** нет («beyond realistic test at any size scale»).

**Вердикт: (а).** Не термодинамическая система; согласен с книгой.

## Общий вывод

1. Ни одна модель глав 4–5 не устояла: для 13 из 14 найдена конкретная ошибка или скрытый источник. Газовые циклы (§5.7) проверить нельзя — в тексте нет содержания. Неясными, но сильными заявками не остаётся ничего.
2. Модели Гордона (мембрана, люк, ротор) — прямое подтверждение нашего критерия. Ток в (5.8) пропорционален (N − 1) = (W − 1). Нарушение Вегшайдера в них не выведено, а вписано в константы скорости, и оно несовместимо с существованием свободной энергии как функции состояния. При W = 1 ток исчезает: проверено численно для обеих мембранных моделей.
3. Храповик Денура и петля Никулова — случаи нашего пункта (2). Асимметрия появляется, только если отброшено обратное влияние: радиационная отдача у Денура, обратные переходы и электрохимическое равновесие у Никулова. Ток Никулова наблюдается лишь при внешнем ac‑токе или неисключённом внешнем шуме, что признают сами авторы.
4. Квантовые предложения (спин‑бозон, LC) — случаи пункта (3). Работу дают негиббсовское начальное состояние или редуцированное определение энтропии. Теорема Томсона для гиббсовского начального состояния полной системы не нарушается, и сами Аллахвердян–Ньивенхейзен на большее не претендуют.
5. Модели Кифа, Кросиньяни и Труппа содержат внутренние технические ошибки. У Кифа — баланс энергии вместо баланса энтропии, что видно по его собственным числам. У Кросиньяни — ланжевеново уравнение без гиббсовского стационара; авторы сами ссылаются на ван Кампена. У Труппа — сила, не выводимая из свободной энергии, плюс неравновесный режим измерений.
6. Экспериментально нигде не измерены одновременно поток тепла и работа в замкнутом изотермическом цикле. Единственные данные — напряжения Никулова и силы Труппа — объясняются внешней накачкой или релаксацией в утечном диэлектрике.
7. Для нашей работы это общий шаблон проверки: (i) записать цикл состояний и вычислить W; (ii) проверить, гиббсовское ли стационарное распределение у предложенной динамики (ФДТ, взаимность Онсагера–Казимира); (iii) найти, кто задаёт частоту или фазу (внешний шум, приготовление состояния, источник питания).
