# Масса мёбиус-частицы через характерные длины Lazar

**Дата:** 23 октября 2026
**Источники:** Lazar & Anastassiadis, arXiv:0802.0670 (T(3)-теория,
статические дислокации, 4 характерные длины); Lazar, arXiv:0903.0990
(механизм Хиггса, естественное ядро).

---

## 1. Четыре характерные длины Lazar (точные формулы)

Из решения мастер-уравнения T(3)-калибровочной теории (ур. 2.49–2.52):

    ℓ₁² = a₁/(2μ)                     — масштаб сдвига (как в градиентной упругости)
    ℓ₂² = (1−ν)a₂ / [2μ(1+ν)]         — масштаб дилатации (зависит от ν)
    ℓ₃² = (μ+γ)(a₁+a₂) / (8μγ)        — длина изгиба (микрополярная упругость)
    ℓ₄² = (a₁+2a₃)/(6γ)               — длина кручения

связь: ℓ₃² = (μ+γ)/(4γ)·[ℓ₁² + (1+ν)/(1−ν)·ℓ₂²]

aᵢ — материальные постоянные РАЗМЕРНОСТИ СИЛЫ. Для ВИНТОВОЙ дислокации
(anti-plane strain) ℓ₁=ℓ₄, остаётся ОДНА длина ℓ₁²=a₁/(2μ).

## 2. Естественное ядро (ключевое для core мёбиуса)

Решение винтовой дислокации в калибровочной теории:
- поля НЕ сингулярны (ядро возникает естественно, без обрезания);
- модифицированный Бюргерс: b(r) = b·[1 − (r/ℓ₁)·K₁(r/ℓ₁)];
- максимум напряжений при r ≃ 1.114·ℓ₁;
- радиус ядра дислокации: **r_core ≃ 6·ℓ₁**.

Это прямо решает проблему "неизвестного core" мёбиус-частицы: ширина
кинка/ядро определяется ОДНОЙ длиной ℓ₁=√(a₁/2μ), а не свободным параметром.

## 3. Формула массы мёбиус-частицы (ВЫВОД, не постулат)

Масса = энергия ядра (линейная плотность × размер):
    m c² ~ μ b² ℓ₁ = μ b² √(a₁/2μ) = b²·√(μ a₁/2)

    ┌─────────────────────────────────────┐
    │   m = b²·√(μ·a₁/2) / c²              │
    └─────────────────────────────────────┘

где b — вектор Бюргерса, μ — сдвиговый модуль вакуума, a₁ — модуль
размерности силы (ТОТ ЖЕ, что управляет кулоном в central-канале!).

Численно: если m=m_e и b=1 (натур. ед.), то √(μa₁/2)=m_e c²=8.19e-14 Дж/м,
т.е. μ·a₁ = 1.34e-26 (Дж/м)² — фиксирует ПРОИЗВЕДЕНИЕ модулей.

## 4. Статус

ПРОГРЕСС против вчерашнего: масса больше НЕ "подвешена" на произвольной
обрезке core. Теперь:
- форма массы ВЫВЕДЕНА: m = b²√(μa₁/2)/c²;
- размер ядра ВЫВЕДЕН: w ≃ 6ℓ₁ = 6√(a₁/2μ);
- оба выражены через КОНКРЕТНЫЕ материальные модули вакуума (μ, a₁), а не
  через загадочный core.

ОСТАЁТСЯ: зафиксировать μ и a₁ по отдельности. Модуль a₁ связан с кулоном
(central-канал), поэтому его можно калибровать по e; тогда масса мёбиуса
станет ПРЕДСКАЗАНИЕМ. Это чёткая, выполнимая программа — в отличие от
барьера G (который требует отдельного планковского сектора).

## 5. Важная связь каналов
Длина ℓ₁ строится из a₁ — модуля КУЛОНА. Значит масса и размер мёбиус-
частицы, кулоновский канал электрона и ядро дислокации управляются ОДНИМ
модулем a₁. Это связывает ранее раздельные куски модели в одном параметре.
