# v3-glide: природа магнитного заряда из размерного анализа

Дата: 24 окт 2026. Проект «Единая геометродинамическая модель».
Модель: пара скользящих (glide) дислокационных колец, особые точки в ПРОТИВОФАЗЕ,
плоскости колец НЕПОДВИЖНЫ, «прецессия» = бег особой точки по кольцу с частотой ω.
Заряды ВЕКТОРНЫЕ (вектор Бюргерса), не скалярные.

## Размерный анализ решает природу q_m (ключевой результат)

По соответствию Лазара (Таблица 1, lazar2010): B↔T^a, магнитный поток ↔ ∮T^a=b.
=> размерность магнитного заряда = [b] = ДЛИНА (L).

Проверка четырёх кандидатов на q_m:
| Кандидат            | Размерность | Заряд [L]? |
|---------------------|-------------|------------|
| Поток b через петлю | L           | да, НО в glide поток=0 |
| Разрыв Δb в точке   | L           | ДА — работает в glide |
| Циркуляция ∮b·dl    | L²          | нет — это ДИПОЛЬНЫЙ момент |
| Поворот ∮dθ_b(Франк)| безразмерн. | нет — топологический индекс |

ВЫВОД: размерность отсекает циркуляцию (L²=диполь) и поворот (индекс).
Заряд [L] дают только ПОТОК и РАЗРЫВ. В glide-геометрии (поток=0) остаётся
=> q_m = РАЗРЫВ вектора Бюргерса Δb в особой точке (размерность длины).

Это ВОЗВРАЩАЕТ к исходной гипотезе пользователя: особая точка = локальный
разрыв Бюргерса, и этот разрыв Δb и есть магнитный заряд.

ВАЖНО: это ИЗМЕНИЛО предыдущий вывод (kg entity 8228b5efcb9d), где по геометрии
+ критериям e-/e+ была выбрана циркуляция. Размерность показала, что циркуляция
= L² = дипольный момент, НЕ заряд. Размерный критерий строже.

## Роли величин (размерно самосогласованно)
- q_m = Δb (разрыв в особой точке)                [L]   — магнитный заряд
- p (диполь) = q_m·(плечо); циркуляция ∮b·dl       [L²]  — дипольный момент
- осевой диполь p_z = q_m·d = const (вдоль оси)
- поперечный диполь p_xy прецессирует с ω (вращается в плоскости)

## Числа (пара колец, противофаза, a=d=Δb=ω=1)
- p_z = q_m·d = 1.0 (постоянный осевой диполь) ✓ размерность L²
- p_xy = 2a·q_m = 2.0, вращается с частотой ω (прецессирующий поперечный диполь)
- μ_z = -0.5 (в единицах q_m·a²·ω)
- J_z = +1.0 (в единицах массы·a²·ω)
- μ_z/J_z = -0.5 → классическое g=1 (как в v5; НЕ g=2)

## Размерность гиромагнитного
[μ]=[q_m]·[r×v]=L·L·(L/T)=L³/T; [J]=[масса]·[r×v].
Если масса~[b²]=L², то [μ/J]=1/L. Чтобы g было безразмерным (как в ЭД, μ/L=q/2m),
масса должна входить как m~q_m²/(длина) — это НАКЛАДЫВАЕТ связь заряд-масса.

## Статус
- Природа q_m решена размерно: РАЗРЫВ Δb (не циркуляция, не поворот).
- g=1 классически (пара колец), g=2 по-прежнему не выходит из μ/J классически.
