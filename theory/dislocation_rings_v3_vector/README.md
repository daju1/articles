# dislocation_rings_v3_vector — пара glide-колец, векторный Бюргерс, q_m=Δb

Возврат к модели v3 (пара скользящих дислокационных колец) с ВЕКТОРНЫМ
вектором Бюргерса и размерно-корректным магнитным зарядом q_m=Δb (разрыв
в особой точке). Геометрия уточнена пользователем 24 окт 2026.

## Модель
- Два кольца, плоскости НЕПОДВИЖНЫ, разнесены по оси z (±d/2).
- "Прецессия" = бег ОСОБОЙ ТОЧКИ по кольцу с частотой ω (не шатание плоскостей).
- Особые точки в ПРОТИВОФАЗЕ (Δφ=π).
- Вектор Бюргерса в плоскости кольца (glide), векторный.
- q_m = Δb (разрыв в особой точке), [q_m]=[b]=длина (размерно корректно).
  Противоположные знаки: e⁻=интерстициал(+), e⁺=вакансия(−).

## Результаты (численно)
- Осевой диполь p_z=q_m·d=const; поперечный p_xy прецессирует с ω.
- μ_z/J_z=-0.5 → классическое g=1 (g=2 требует спинора Дирака, не классики).
- Масса m~μ_shear·q_m²·a/c²; g~c²/(μ_shear·q_m·a) — не фикс. 2, зависит от параметров.
- Стабильность: вихревой барьер (ωa/c)²/d² vs притяжение 1/d → минимум d_eq(ω).
- e⁻/e⁺: два независимых знака (ω + знак Δb), переворот вместе (CP).
- Аннигиляция: b(e⁻)+b(e⁺)=0 (рекомбинация Френкеля → идеальная решётка).

## Сборка/запуск
    gcc -O3 -shared -fPIC dislocation_rings_v3_vector.c -o dislocation_rings_v3_vector.so -lm
    PYTHONIOENCODING=utf-8 python3 dislocation_rings_v3_vector_tests.py

## Честные оговорки
- q_m=Δb размерно корректен (длина), но ВЕЛИЧИНА разрыва — параметр особой точки.
- g=1 классически; g=2 НЕ выводится без спинорного (Дирак) уровня.
- Связь масса~q_m² из размерности — структура, не фикс. число.
- G не выводится (планковский барьер, общий для проекта).
