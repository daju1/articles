# Предсказание массы мёбиус-частицы: статус калибровки

**Дата:** 23 октября 2026

## Формула массы (выведена из характерных длин Lazar)
    m = b²·√(μ·a₁/2) / c²,     w_core ≃ 6·ℓ₁ = 6·√(a₁/2μ)
где b — вектор Бюргерса, μ — сдвиговый модуль вакуума, a₁ — модуль силы
(central/кулон канал).

## Можно ли предсказать число? — ПОКА НЕТ
Попытка калибровки (ℓ₁=a_compton + a₁=ke²/a_c) дала m~10^10 m_e — абсурд.
Причина: это ДВА несовместимых произвольных условия.

Правильный диагноз: формула содержит ДВА неизвестных (μ, a₁), а кулон даёт
лишь ОДИН якорь. Система НЕДООПРЕДЕЛЕНА — для любой целевой массы есть своя
пара (μ,a₁):
    m=1 m_e    → μ=0.21 Па,   a₁=6.3e-26 Н   (при ℓ₁=a_c)
    m=206 m_e  → μ=43.7 Па,   a₁=1.3e-23 Н
    m=1836 m_e → μ=389 Па,    a₁=1.2e-22 Н

## Честный статус
- ФОРМА массы и размерная структура ВЫВЕДЕНЫ (не постулат обрезки).
- ЧИСЛО массы НЕ предсказывается: не хватает ОДНОГО независимого уравнения
  на μ (второй якорь помимо кулона, напр. сдвиговая жёсткость вакуума).
- Это МЯГЧЕ барьера G: не требует планковского сектора, лишь второй якорь.
- Итог: масса остаётся свободным параметром (как в Стандартной модели),
  но её геометрическое происхождение и формула установлены.
